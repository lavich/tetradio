# Голоса аудирования

Реплики диалогов аудирования озвучены заранее облачным синтезом и поставляются как медиа урока: файл на реплику.
Без записи на устройстве (не озвучена, не скачана и нет сети) реплика звучит синтезом речи устройства.
Решение и устройство — `openspec/changes/dialogue-voices/design.md`.

## Сервис и формат

- **Google Cloud Text-to-Speech, голоса Chirp 3 HD**: `languageCode: el-GR`, голос `el-GR-Chirp3-HD-<Голос>`,
  REST `POST https://texttospeech.googleapis.com/v1/text:synthesize`.
- **MP3 прямо из API** (`audioEncoding: MP3`): моно, 24 кГц, 32 кбит/с, ~4 КБ на секунду речи. Модуль 01 —
  20 реплик, 646 символов, 216 КБ; весь курс (~44,5 тыс. символов) — ~15 МБ.
- Медленный режим — тот же файл с `playbackRate` 0,8.

## Карта голосов

[`content/voices.yaml`](../content/voices.yaml): у каждого персонажа пол и голос; `source` — подпись записи
(`{voice}` — имя голоса), `narrator` — голос реплики без говорящего.

- Пулы: женские — Aoede, Callirrhoe, Achernar, Autonoe, Despina, Erinome, Gacrux, Kore, Laomedeia, Leda, Sulafat,
  Vindemiatrix, Zephyr; мужские — Algenib, Algieba, Alnilam, Charon, Enceladus, Fenrir, Iapetus, Puck, Rasalgethi,
  Sadachbia, Sadaltager, Schedar, Umbriel, Zubenelgenubi.
- Пол — по окончанию имени (-ος, -ης, -ας, -ής, -άς, -ός, -ων — мужской), роль «Υπάλληλος» — мужская,
  Ραφαήλ — мужское имя.
- 27 самых частых персонажей звучат каждый своим голосом; Αντρέας — Charon, Μαρίνα — Aoede.
- Новому персонажу — голос его пола, которого нет у собеседников в его диалогах.

Сборка отклоняет урок, если у говорящего нет голоса, голос не из пула его пола или двое в одном диалоге звучат
одним голосом.

## Озвучка

```bash
GOOGLE_TTS_KEY=… npm run voices -- m02-1 m02-2   # без уроков — весь курс
npm run voices -- --check m02-1                  # что не озвучено или устарело; без ключа и сети
```

Скрипт синтезирует реплики без файла и те, у которых изменился текст или голос (`content/audio/dialogues.json`
хранит голос и хэш текста каждого файла), пишет `content/audio/<урок>/<блок>-<n>.mp3` и дописывает в реплику
`audio:`. Коммитятся файлы, манифест и урок.

**Ключ** — только в переменной окружения команды. Его не записывают в файлы, `.env` в репозитории, коммиты,
описания PR и отчёты; перед коммитом diff проверяется на префикс ключей Google API.

## Цены и условия — сверить перед озвучкой всего курса

- Цена Chirp 3 HD за миллион символов и бесплатный месячный объём — по текущему прайсу Google Cloud TTS. Весь курс —
  ~44,5 тыс. символов, переозвучка правок — сотни символов.
- Право использовать синтезированный звук в учебном приложении — по условиям Google Cloud (Service Specific Terms)
  на момент озвучки. Подпись записи в пакете: «Синтез речи Google Cloud TTS, голос Chirp 3 HD <Голос>».
