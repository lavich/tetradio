# Голоса аудирования

Реплики диалогов аудирования, слова, фразы, тексты для чтения и верные ответы заданий на перевод и пропуск
озвучены заранее облачным синтезом и поставляются как медиа урока: файл на реплику, карточку, предложение текста
или пункт задания. Без записи на устройстве (не озвучена, не скачана и нет сети) они звучат синтезом
речи устройства.
Решение и устройство — `openspec/changes/dialogue-voices/design.md`.

## Сервис и формат

- **Google Cloud Text-to-Speech, голоса Chirp 3 HD**: `languageCode: el-GR`, голос `el-GR-Chirp3-HD-<Голос>`,
  REST `POST https://texttospeech.googleapis.com/v1/text:synthesize`.
- **MP3 прямо из API** (`audioEncoding: MP3`): моно, 24 кГц, 32 кбит/с, ~4 КБ на секунду речи. Модуль 01 —
  20 реплик, 646 символов, 216 КБ; весь курс (~44,5 тыс. символов) — ~15 МБ.
- Медленный режим — тот же файл с `playbackRate` 0,8.
- Греческий вопросительный знак `;` уходит в синтез как `?`: иначе синтез читает его как точку с запятой и вопрос
  звучит утвердительно. В тексте урока остаётся `;`; хэш реплики считается по тексту для синтеза.
  Та же замена — в синтезе речи устройства: слова, фразы, упражнения и реплики без записи.
- Голос ставит ударение в «Καλώς» на первый слог, поэтому в облачный синтез слово уходит заглавными «ΚΑΛΏΣ» (κα-ΛΩΣ).
  Словарь — поле `respell` карты голосов (слово без учёта регистра → написание), замена целого слова только в облаке;
  хэш записи считается по тексту для синтеза, поэтому после правки словаря записи с этим словом переозвучиваются
  (`--check` их называет). Текст на экране и синтез устройства не меняются. IPA и произношения для el-GR сервис не
  принимает.

## Карта голосов

[`content/voices/el.yaml`](../content/voices/el.yaml) — карта греческого курса; у каждого языка своя,
`content/voices/<язык>.yaml`, сборка и озвучка берут её по языку курса урока. У каждого персонажа пол и голос;
`source` — подпись записи (`{voice}` — имя голоса), `narrator` — голос реплики без говорящего, слов и фраз,
`reader` — чтец текстов для чтения (отдельный голос: у диктора Kore тот же голос, что у Μαρία).

- Пулы: женские — Aoede, Callirrhoe, Achernar, Autonoe, Despina, Erinome, Gacrux, Kore, Laomedeia, Leda, Sulafat,
  Vindemiatrix, Zephyr; мужские — Algenib, Algieba, Alnilam, Charon, Enceladus, Fenrir, Iapetus, Puck, Rasalgethi,
  Sadachbia, Sadaltager, Schedar, Umbriel, Zubenelgenubi.
- Пол — по окончанию имени (-ος, -ης, -ας, -ής, -άς, -ός, -ων — мужской), роль «Υπάλληλος» — мужская,
  Ραφαήλ — мужское имя.
- 27 самых частых персонажей звучат каждый своим голосом; Αντρέας — Charon, Μαρίνα — Aoede.
- Новому персонажу — голос его пола, которого нет у собеседников в его диалогах.

Сборка отклоняет урок, если у говорящего нет голоса, голос не из пула его пола или двое в одном диалоге звучат
одним голосом.

### Тексты для чтения

Повествование текста читает чтец `reader`, а текст от первого лица (`narrator: Άννα`) — голос этого героя.
Строки живой речи начинаются с «—»; `speakers` перечисляет говорящего каждой такой строки по порядку, пустое имя —
реплика без говорящего («λένε οι άνθρωποι»), её читает рассказчик. Без `speakers` строки «—» тоже читает
рассказчик. Цитата внутри повествования («…») звучит голосом рассказчика. Сборка отклоняет текст, если имён меньше
или больше строк «—», у героя или рассказчика нет голоса или двое говорящих в тексте звучат одним голосом.

## Озвучка

```bash
npm run voices -- m02-1 m02-2   # без аргументов — всё, кроме реплик и ответов черновых модулей
npm run voices -- words phrases # только слова и фразы
npm run voices -- words phrases --course=greek-a2 # слова и фразы одного курса
npm run voices -- readings      # только тексты для чтения
npm run voices -- answers       # только ответы заданий
npm run voices -- --check m02-1                  # что не озвучено или устарело; без ключа и сети
```

Скрипт синтезирует записи без файла и те, у которых изменился текст или голос (`content/audio/dialogues.json`
хранит голос и хэш текста каждого файла), пишет `content/audio/<урок>/<блок>-<n>.mp3`, `audio/words/<id>.mp3`
(текст — `greek` слова), `audio/phrases/<id>.mp3` и дописывает `audio:` в реплику или файл карточки. Текст
для чтения озвучивается по предложениям (то же деление `sentencesOf`, что у «Слушать» на устройстве):
`audio/readings/<текст>/<n>.mp3`, n с 1; в файл текста ничего не пишется — сборка находит записи по манифесту,
а файлы предложений, которых больше нет, скрипт удаляет. Запись предложения, сделанная до правки текста или смены
голоса, не публикуется: предложение звучит синтезом устройства, остальные — файлами.

Ответ задания озвучивает диктор `narrator`: у перевода (`format: text`) — первая принимаемая форма, у пропуска
(`format: gap`) — предложение с ней, без русских пояснений в скобках (`spokenAnswer`). Ответ по-русски, выбор
и соединение не озвучиваются. Файл — `audio/answers/<урок>/<блок>-<пункт>.mp3`; как и у текстов, в урок ничего
не пишется: сборка находит свежую запись по манифесту и передаёт её в пакете полем `itemAudio`, а файлы пунктов,
которых больше нет, скрипт удаляет. После ответа верный ответ виден с кнопкой «Послушать ответ», с автоозвучкой
звучит сам — как фраза; на странице урока кнопка появляется у пункта после проверки. Коммитятся
файлы, манифест, уроки и карточки. Запись слова или фразы, сделанная до правки текста или смены диктора, сборкой
не публикуется — карточка звучит синтезом устройства, пока её не переозвучат.

Уроки модулей со статусом `draft` без аргументов пропускаются — сборка их записи не публикует, а синтез платный;
готовые файлы черновиков остаются. Урок, названный явно, озвучивается при любом статусе. Перед синтезом скрипт
удаляет файлы реплик, слов и фраз, которым нет соответствия в исходниках, вместе с записями манифеста (`--check`
их только называет; папка удалённого урока чистится запуском без аргументов, названный id отсутствующего урока
скрипт отвергает). Запрос при 429, 5xx и сетевой ошибке повторяется до пяти раз с паузами 1, 2, 4, 8 с;
запросы идут по одному.

**Ключ** — `GOOGLE_TTS_KEY` в локальном `.env` (он в `.gitignore`): `npm run voices` читает его сам, без `.env`
Node пишет «.env not found» и скрипт просит ключ. Не писать ключ в команду (`GOOGLE_TTS_KEY=… npm run voices`):
он останется в истории оболочки. Ключ уходит заголовком, из текстов ошибок вырезается и не записывается в файлы,
коммиты, описания PR и отчёты; перед коммитом diff проверяется на префикс ключей Google API.

## Цены и условия

- Chirp 3 HD (проверено 04.10.2026, cloud.google.com/text-to-speech/pricing): бесплатно до 1 млн символов в месяц, сверх — $30 за миллион. Весь курс — 43,8 тыс. символов, укладывается в бесплатный объём.
- Право использовать синтезированный звук в учебном приложении — по условиям Google Cloud (Service Specific Terms); перед публичным выпуском перечитать. Подпись записи в пакете: «Синтез речи Google Cloud TTS, голос Chirp 3 HD <Голос>».
