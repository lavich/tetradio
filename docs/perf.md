# Скорость первого экрана

Замер Lighthouse на мобильном профиле (150 мс, 1,6 Мбит/с, CPU ×4), mock-сборка, медиана трёх прогонов. В CI то же делает задача `lighthouse` (`npm run lighthouse`); размеры сборки держит `npm run check:bundle`.

## Протокол

Автоматически: `VITE_TELEGRAM_MOCK=1 npm run build && npm run lighthouse` — три прогона, медианы, пороги из `scripts/lighthouse-report.ts` (LCP > 3 с — предупреждение, > 4 с — ошибка; TBT ≤ 200 мс; вес ≤ 450 КиБ; вес ленивых чанков первого экрана ≤ 36 000 байт). Вручную — как ниже.

```sh
VITE_TELEGRAM_MOCK=1 npm run build
npx vite preview --port 4188 &
for i in 1 2 3; do
  npx lighthouse http://localhost:4188/app/ --only-categories=performance \
    --output=json --output-path=/tmp/lh$i.json --chrome-flags="--headless=new" --quiet
done
```

Метрики — `first-contentful-paint` и `largest-contentful-paint` в JSON, берётся медиана. Вклад отдельного ресурса — тем же замером с `--blocked-url-patterns='*literata-latin*'`.

## Ночной замер под нагрузкой

Workflow `perf-nightly.yml` (03:00 UTC и вручную; не входит в `checks`) собирает mock-сборку на настоящем курсе и с CPU ×4 измеряет установку курса (время, TBT) и отклик в уроке (p98 Event Timing нажатий, предел 100 мс). Локально: `PERF_RATE=4 npm run perf`; итоги — `test-results/perf/*.json`.

Разница строки #151 в пределах разброса замера: ожидаемый вклад по блокировке — около 0,03 с.

Замер 29.10.2026 — `npm run lighthouse` на mock-сборке, медиана 5 прогонов на той же машине, что и база того же дня (`main`: FCP 2,55 с, LCP 3,45 с). Без Manrope LCP совпал с замером блокировкой всех `*.woff2` того же дня (3,01 с): Literata приходит параллельно и в критический путь первого экрана не входит. Числа 17.10 сняты в других условиях и с ними напрямую не сравниваются.

LCP-элемент — подсказка под «Учить курс» на «Сегодня» первого запуска. Ориентир ≤ 2,5 с не достигнут: основной вес — JS стартового графа (≈200 КБ gzip, около 75 КБ первым экраном не используются).

## Вклад ресурсов (блокировка запросов, база 3,65 с)

| Что не грузится                | LCP    |
| ------------------------------ | ------ |
| все `*.woff2`                  | 3,34 с |
| `literata-latin`               | 3,50 с |
| чанк `sync` и `workbox-window` | 3,61 с |

Latin-Literata нужен любым пробелам, цифрам и знакам, а курс «Английский для IT» набран латиницей в Literata, поэтому Literata остаётся. Manrope снят 29.10.2026: интерфейс — системным шрифтом, первый экран легче на 40–48 КБ шрифтов (latin и cyrillic, с greek).

## Что осталось

Отдельный лёгкий путь первого запуска (экран «Начните с курса» без FSRS, схемы контента и лишних экранов), разрезание Dexie и ts-fsrs по маршрутам.

Замену `cn` на `clsx` не делаем (решение 29.10.2026): `cn` сливает конфликтующие классы Tailwind, а таких мест в вызовах около 55 (база и варианты `buttonVariants`, `w-auto` против `w-full`, цвета `CardDescription`); выигрыш около 10 КБ gzip и 35 мс LCP не окупает 1–2 дня работы с риском тихих визуальных регрессий.
