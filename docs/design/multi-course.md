# Несколько курсов: язык → курсы

Статус: бриф согласован пользователем 20.10.2026. Опора для трёх изменений: (а) начало курса, (б) пауза курса, (в) модель «язык → курсы» вместе с курсом для путешествий.

Курсы сейчас: «Греческий» A0 → A2 (`content/courses/greek-a2.yaml`, программа — [curriculum.md](../curriculum.md)), «Английский для IT» B1 → B2 (`content/courses/english-it.yaml`, [curriculum-english-it.md](../curriculum-english-it.md)), «Английский для путешествий и общения» B1 → B1+ (`content/courses/english-travel.yaml`, [curriculum-english-travel.md](../curriculum-english-travel.md)).

## Модель «язык → курсы»

- Учащийся учит языки, у языка бывает несколько курсов: у английского — для IT и для путешествий.
- Переключатель языка «Греческий | Английский» стоит на «Курсе», «Словах», «Чтении» и «Прогрессе». Выбор общий для четырёх экранов и запоминается.
- На «Сегодня» переключателя нет.
- Курсы одного языка видны вместе:
  - **«Курс»** — полки курсов одна под другой. У полки заголовок («Для IT · B1 → B2»), счётчик «N из M» и меню «⋯». У каждого курса своя гамма обложек.
  - **«Слова»** — общий словарь языка: у строки подпись курса, есть фильтр по курсу.
  - **«Чтение»** — тексты языка, сгруппированные по курсам.
  - **«Прогресс»** — навыки языка с разбивкой по курсам; темп и контрольные — по каждому курсу.
- Широкий экран: полки тоже одна под другой, без колонок.
- Имя курса внутри языка — `short` файла курса: «Для IT», «Для путешествий», «Греческий». Заголовок полки, группа «Чтения» и блок «Прогресса» — «Для IT · B1 → B2», подпись строки и фильтр «Слов» — «Для IT». Вне экранов языка — «Сегодня», настройки, «⋯» и строка статуса паузы — полное название курса (решение 21.10.2026).
- Гамма обложек — поле `palette` файла курса из набора гамм приложения; греческий сохраняет прежнюю гамму, цвет курса не зависит от порядка курсов. Обложки курса — в его гамме везде, в том числе на «Сегодня».
- «Прогресс» при двух курсах языка и больше: вверху «Всего по английскому» — навыки по заданиям всех курсов, слова и фразы, ошибки, проблемные карточки, итог недели; ниже блок каждого курса с путём, темпом, контрольными и навыками. Слабый навык выделяется только в блоке курса: пороги у курсов разные.
- Один начатый курс языка — «Слова», «Чтение» и «Прогресс» как прежде, без подписей курса и суммы.

## «Сегодня»

Шаг 2 изменения (в), отдельное изменение после `language-courses`; в шаге 1 «Сегодня» меняет только цвет обложек английских курсов.

- Блоки по языкам.
- Основной язык — целиком, как сейчас. Остальные языки — компактно.
- Внутри языка — одно общее повторение карточек всех курсов этого языка. Разные языки в одном повторении не смешиваются: у них разный алфавит и разные правила проверки ответа.
- Внутри языка — по строке на урок каждого курса, не больше трёх строк; дальше — «Ещё N курсов →».
- Основной язык и основной курс меняются в «Настройках и данных».

## Стартовый экран

Экран без начатых курсов — для первого запуска и для новых людей.

- Заголовок «Выберите курс» (решение 20.10.2026: «Τετράδιο» повторял логотип) и одна строка о приложении.
- Курсы сгруппированы по языкам; заголовок языка — когда у языка два курса и больше.
- Карточка курса: название с уровнем, цель одной строкой, объём (модули: «24 модуля», у частично готового — «Готов 1 модуль из 16»), кнопка «Учить курс». Нагрузку карточка не показывает: учащийся сам выбирает, сколько заниматься (решение 20.10.2026).
- Курс без опубликованных уроков — карточка с пометкой «Готовится», без кнопки.
- Начать можно несколько курсов. Первый начатый курс — основной.

## Неначатый курс

- На «Курсе» неначатые курсы языка с опубликованными уроками — те же карточки, что на стартовом экране, с кнопкой «Учить курс», под полками начатых курсов, без заголовка языка. Курс без опубликованных уроков («Готовится») на «Курсе» не показывается.
- Язык, в котором нет начатых курсов, помечен в переключателе «Курса» знаком «+»; при выборе такого языка — карточки его курсов. «Слова», «Чтение» и «Прогресс» такой язык не предлагают и показывают последний выбранный язык с начатым курсом.
- Язык, курс которого начат на другом устройстве и ещё не скачан, на «Курсе» — без «+», с полкой курса; на остальных экранах он появляется после установки первого урока.

## Пауза курса

Изменение (б).

- Где: меню «⋯» полки → «Приостановить курс»; «Настройки и данные» → «Курсы».
- Курс на паузе уходит с «Сегодня» и из повторения карточек. Прогресс остаётся.
- Полка курса на паузе приглушена, на ней «На паузе с …» и кнопка «Продолжить курс».
- После паузы просроченные повторения курса (долг паузы) доступны все сразу, без дневного предела, но занятие начинается с карточек, которые вспомнить труднее всего по FSRS; пока долг есть, новые карточки занимают только оставшиеся места. Сроки не сдвигаются. На «Сегодня», пока долг есть, — «После паузы: сначала то, что могло забыться» (решение 20.10.2026 вместо порций через дневной бюджет).
- Основной курс на паузе — основным становится следующий активный курс.
- Все курсы на паузе — на «Сегодня» «Все курсы на паузе», список курсов с кнопкой «Продолжить» и кнопка «Начать другой курс».
- Пауза синхронизируется между устройствами отдельным ключом облака на устройство (`cp_<устройство>`), мимо снимка прогресса и версий: по курсу побеждает более позднее изменение, окна выбора и потери ответов пауза не вызывает; приложения прежней версии этот ключ не видят и показывают курс идущим (решение 20.10.2026 после повторного ревью).
- Курс на паузе: модули и уроки открываются и проходятся, пауза сама не снимается; основным становится следующий курс по кругу; пауза ставится без подтверждения; календарь курса не сдвигается, на «Прогрессе» — «Курс на паузе с …».

## Что не меняется

- Вид «Сегодня» для основного курса.
- Одно слово — карточка одного курса: общих карточек между курсами нет.
- Тон без давления — как в [PRODUCT.md](../../PRODUCT.md).

## Порядок

1. **(а) Начало курса** — стартовый экран и «Учить курс» на полке неначатого курса. OpenSpec-изменение `course-start`, реализовано.
2. **(б) Пауза курса** — OpenSpec-изменение `course-pause`, реализовано.
3. **(в) Модель «язык → курсы»** — курс для путешествий (`english-travel-start`), затем два шага:
   1. Переключатель языка и четыре экрана языка — «Курс», «Слова», «Чтение», «Прогресс». OpenSpec-изменение `language-courses`, реализовано.
   2. «Сегодня» по языкам с общим повторением языка, основной язык.
