Картинки слов — готовые библиотеки

Вместо рисования кодом — настоящие иллюстрации художников из открытых библиотек. В каждой — сотни предметов в одном стиле, поэтому большинство конкретных слов курса покрываются без ручной работы. Картинки — векторные файлы по 1–3 КБ, работают офлайн.

Картинки лежат в docs/design/art-samples/. Для курса: выбранная библиотека даёт картинку конкретным существительным (дом, кофе, автобус, хлеб…); слова без предмета — без картинки. Атрибуция лицензии — на экране «Ещё → О приложении».
