# Подготовка урока агентом

Пользователь присылает материал занятия — текст, читаемое изображение или PDF — и говорит, что с ним сделать.
Агент превращает материал в исходники контента Lexi: слова (`content/words/`), фразы (`content/phrases/`)
и урок (`content/lessons/`). Приложение исходники не читает:
их собирает `npm run content` в каталог и пакеты, а клиент получает готовый пакет.

Документ описывает границы работы, формат и проверки. Шаблоны лежат в [`docs/lesson-authoring/`](lesson-authoring/);
они проходят тот же валидатор, что и настоящий контент (`tests/authoring.test.ts`). Навык, который вызывает эту
инструкцию в новой сессии, — [`.agents/skills/prepare-lesson/SKILL.md`](../.agents/skills/prepare-lesson/SKILL.md).

## Главное правило

**Только присланное и запрошенное.** Новые предложения, темы, формы, правила, переводы, объяснения
и альтернативные ответы не добавляются без соответствующей просьбы. Неясное место
обозначается в отчёте, а не достраивается догадкой. Предполагаемая ошибка преподавателя выносится на уточнение,
а не заменяется молча своей формой.

## Режимы поручения

| Режим | Что разрешает | Пример просьбы |
| --- | --- | --- |
| `extract` (по умолчанию) | перенести присланное с технической нормализацией записи | «внеси этот список слов в урок» |
| `transform` | преобразовать имеющийся материал названным способом | «разбей эту выписку на отдельные фразы» |
| `generate` | создать новый материал в заданных границах | «из этих 20 слов составь 10 предложений A1» |

Режим определяется по просьбе пользователя, а не по нехватке материала: агент **не переключается** в `generate`,
чтобы восполнить неразборчивый или неполный исходник. Упоминание генерации как будущей возможности поручением не является.
Разные операции одного поручения могут иметь разные режимы — происхождение хранится у каждой карточки.

## Порядок работы

1. **Определить место.** Найти целевой курс и урок по контексту; если однозначного соответствия нет — уточнить
   до привязки. Проверить существующие идентификаторы: повторная присылка того же материала переиспользует их.
2. **Прочитать материал.** Разобрать текст или доступные для чтения изображения и PDF. Внешний OCR не требуется:
   если фрагмент не читается надёжно, он идёт в список неясного, а не в карточку.
3. **Выделить только запрошенное.** Просьба перенести предложения разрешает взять существующие, но не сочинять
   новые и не спрягать глаголы в отсутствующих примерах.
4. **Сохранить формулировки.** Ударения, порядок слов и смысл исходника не меняются. Техническая нормализация
   (NFC, переносы, повторные пробелы) допустима.
5. **Собрать исходники и проверить.** `npm run content` проверяет форму, ссылки и дубликаты;
   `npm test` и `npm run typecheck` — остальной контракт. Успешная сборка **не** доказывает языковую корректность.
6. **Отчитаться.** Что добавлено, изменено, переиспользовано и не разобрано; какие проверки выполнены; в каком режиме
   работали. Готовность исходников и появление урока в приложении — разные состояния.

## Форматы

Идентификатор карточки — поле `id`, а без него — имя файла. Он не выводится из позиции в уроке и не является хешем текста.

### Слово

Формат слова не меняется: `content/words/<греческое-имя>.yaml`, поля `greek`, `russian`, `ipa`, `reading`, `examples`.
В примере слова `target` — **строка**, помечающая слово-цель в предложении.
Шаблон: [`word.yaml`](lesson-authoring/word.yaml).

### Разметка слов примера

Поле `words` у примера делает его слова нажимаемыми: нажатие показывает перевод слова в этом предложении,
а если у слова есть карточка на устройстве — предлагает её открыть. Приложение не сводит форму слова
к словарной статье само, поэтому связь «слово в предложении → перевод → карточка» записывается здесь.

```yaml
    words:
      - { text: "Το", russian: "артикль ср. р." }
      - { text: "σπίτι", russian: "дом", word: w12-16 }
      - { text: "μας", russian: "наш" }
      - { text: "είναι", russian: "есть" }
      - { text: "μεγάλο", russian: "большой", word: w13-20 }
```

- **Что размечать.** Когда агент сам готовит пример по поручению, он размечает каждое слово с однозначным
  переводом в этом контексте: и знаменательные, и служебные. Знаки препинания не размечаются.
- **Порядок.** Отрезки перечисляются в порядке предложения, начиная с первого вхождения: сборка ищет каждый
  после предыдущего, поэтому повтор слова размечается вторым отрезком с тем же текстом.
- **Перевод.** `russian` — перевод этой формы в этом предложении («μεγάλο — большой»), а не перевод карточки целиком.
- **Ссылки.** `word` — `id` существующей карточки каталога; у слова-цели это своя карточка. Ссылаться можно
  на слово любого урока. Новую карточку ради разметки не заводят: у `μας` и `είναι` ссылки нет, есть только перевод.
- **Пример преподавателя.** Перенесённый как есть пример размечается только по явной просьбе, и его текст ради
  разметки не меняется.
- **Происхождение.** Переводы отдельных слов — это перевод. В `source` слова или примера указывается, что
  переводы слов примера подготовлены Lexi.

Сборка отклоняет отрезок, которого нет в предложении или который стоит не по порядку, пустой перевод
и ссылку на неизвестное слово. Разметка необязательна: пример без неё собирается и показывается как прежде.
Если пользователь поменяет греческий текст примера в редакторе, разметка этого примера снимется.

### Фраза

Готовая языковая единица: приветствие, выражение, вопрос или предложение. Поля языково-нейтральные: `text`,
`translation`, `usage`, `note`. Перевод необязателен — без него и без озвучки фраза остаётся справочной
(в уроке помечается «Нет доступного упражнения») и не занимает дневную квоту. Перевод ради обхода этого
состояния не дописывается. Шаблон: [`phrase.yaml`](lesson-authoring/phrase.yaml).

### Урок

`words` — сокращение словарного урока, `items` — упорядоченный смешанный состав из пар `{kind, id}`.
Одновременно указывать оба нельзя. Порядок `items` задаёт авторский порядок знакомства.
Урок без слов допустим, если в нём есть фразы. Статус и дата занятия контентом не поставляются.
Шаблон: [`lesson.yaml`](lesson-authoring/lesson.yaml).

## Происхождение

`provenance` обязателен у каждой фразы.

| Операция | Когда | Обязательные поля |
| --- | --- | --- |
| `verbatim` | текст перенесён как есть | `sourceLabel`, `locator`, `excerpt` |
| `requested-transform` | запрошенное преобразование материала | `sourceLabel`, `request`, место в материале |
| `requested-generation` | запрошенное создание нового материала | `sourceLabel` с авторством агента, `request` |

Для `requested-generation` цитата и место в материале преподавателя **не придумываются**: `locator` и `excerpt`
указываются только при реальном опорном исходнике, а `sourceLabel` называет агента автором.

Если происхождение отдельного поля отличается от основного текста, оно указывается в `provenance.parts`:
допустимы `translation`, `usage`, `note`, `explanation`, `audio`.
У части своих частей нет, правила операций те же.

Короткие цитаты берутся только из относящегося к карточке материала: исходные файлы целиком и личная переписка
в пакет не попадают.

## Повторная обработка

Повторная присылка того же материала переиспользует существующие карточки и связи.

- Правка опечатки, перевода или примечания — тот же `id`, новая ревизия; прогресс и история сохраняются.
- Дубликатом фразы считается тот же текст с тем же переводом; фраза без перевода не равна фразе с переводом.

## Проверки и публикация

```bash
npm run content     # сборка каталога и пакетов: форма, ссылки, дубликаты, происхождение
npm run typecheck
npm test
```

Отчёт различает подготовленные исходники и опубликованный пакет: пока изменения не попали в сборку и не выложены,
урок в приложении не появился. Публикация следует обычным полномочиям текущей задачи.

## Пример отчёта

Прогон инструкции на непубликуемом примере из уже существующего материала проекта (фикстура
`tests/helpers/mixed-fixture.ts`, в каталог не попадает):

```text
Режим: extract (просьба: «внеси эти предложения в урок как фразы»).
Источник: примеры употребления из content/words/*.yaml (γράφω, το βουνό, το παιδί, η άνοιξη, ο ήλιος, το φρύδι).

Добавлено:
  фразы  p-grafo, p-vouno, p-paidi, p-anoixi, p-ilios — тексты и переводы перенесены из examples[0] соответствующих слов;
         p-silent — текст без перевода: перевода в материале нет и переводить не просили.
  примечание у p-ilios размечено по запросу «поясни правило падежа»
         (provenance.parts.note, operation: requested-transform); у остальных фраз примечаний нет.
Переиспользовано: слово w11-27 (γράφω) — уже есть в уроке 1.1, новый файл не создавался.
Не разобрано: нет.
Проверки: npm run content — успешно; npm test, npm run typecheck — успешно.
Состояние: исходники фикстуры готовы, в основной каталог не публикуются (проверочный пример, не материал пользователя).
```
