## На решение

1. **Текст `stelios` ~120 слов** — дальше сокращать можно только вместе с вопросами (q3 про уроки или q1 про вечер). Для модуля 05 длина приемлема; экзаменационный текст — 150–200 слов.
2. **πρέπει να + настоящее время** (Πρέπει να ξυπνάω νωρίς) — верно для привычки, но чаще после να стоит подчинительная форма (ξυπνήσω), модуль 16. Стоит оговорить это там, чтобы учащийся не обобщил.
3. **σηκωνόμαστε в контрольной** (`m05-test/negation/q2`): урок 2 говорит, что пока нужны «я/ты/он». Ответ находится исключением по наречию и лицу, но можно заменить на «я».
4. **τρώω** (основа на гласную, как ακούω) в модуле не упомянут — в лексиконе его нет; добавить строку в таблицу `akouo`, когда слово появится (модуль 08).
5. **Заметки карточек расходятся с лексиконом**: note у καληνύχτα и χρειάζομαι исправлены в `content/words`, а `docs/course/lexicon/05.tsv` вне зоны правки — синхронизировать.
6. Формы на «вы» для -μαι (σηκωνόσαστε, ερχόσαστε, κοιμόσαστε — разговорные варианты) не упомянуты; для A1 это нормально.
