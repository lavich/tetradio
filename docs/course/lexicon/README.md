# Лексикон курса

Слова и фразы по модулям программы ([curriculum.md](../../curriculum.md)). Лексикон — источник для карточек и уроков модуля; каждое слово вводится в одном модуле (первое появление), дальше повторяется в текстах и заданиях без нового ввода.

Файлы: `NN.tsv` — модуль `NN` (01–24).

## Формат

UTF-8 (NFC), табуляция, первая строка — заголовок:

```
id	greek	pos	forms	ru	note
```

| Поле | Правило |
|---|---|
| `id` | Короткий стабильный идентификатор карточки: `w001…` — слово, `p001…` — фраза. Выдаётся один раз и не меняется, даже если исправлено написание: по нему хранится прогресс повторений. Новые записи получают следующий свободный номер |
| `greek` | Стандартный новогреческий, монотоническая орфография с ударением. Существительное — с артиклем в им. п. ед. ч. (`ο δρόμος`); глагол — 1 л. ед. ч. настоящего (`γράφω`); прилагательное — м. р. (`μεγάλος`); фраза — целиком, с пунктуацией (`Πώς σε λένε;`) |
| `pos` | `сущ`, `глаг`, `прил`, `нареч`, `мест`, `числ`, `предл`, `союз`, `част`, `межд`, `фраза` |
| `forms` | сущ: `мн. <артикль + мн. ч.>` (`мн. οι δρόμοι`), для несчисляемых или без мн. ч. — `—`; глаг: `аор. <1 л. ед.>; буд. θα <1 л. ед. сов.>` (`аор. έγραψα; буд. θα γράψω`), при необходимости `; повел. <ед.>`; прил: три рода (`μεγάλος, μεγάλη, μεγάλο`); прочее — `—` |
| `ru` | Краткий перевод в значении, нужном модулю; синонимы через запятую |
| `note` | Необязательно: управление, стиль (`офиц.`, `разг.`), кипрская реалия, неправильность; иначе пусто |

Объём модуля (без фраз): не меньше 35 слов в 01–08, 40 в 09–21, 30 в 22–24, запас сверху — до 12 (числа, опорные слова). Фраз (`pos = фраза`) — 10–15 на модуль. Опорные частотные слова (список в `scripts/check-lexicon.ts`) должны быть введены не позже указанного модуля.

## Проверка

`node scripts/check-lexicon.ts` проверяет формат, объёмы, отсутствие повторов между модулями, греческие буквы и ударения. Языковая проверка выполняется отдельным проходом; её результат фиксируется в `REVIEW.md`.
