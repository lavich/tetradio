# Формат курса (схема 4)

Исходники курса лежат в `content/` и собираются `node content/build.ts` в неизменяемые пакеты `public/content/`. Модель и проверки — `src/content/course.ts` (общие для сборщика и клиента), сборка — `content/build.ts`, тесты — `tests/course-build.test.ts`. Клиент принимает только схему 4: каталог и пакеты другой версии отклоняются как неподдерживаемые.

## Файлы

```
content/courses/greek-a2.yaml   курс: title, modules: [m01, …, m24]
content/modules/m01.yaml        модуль программы
content/lessons/m01-1.yaml      урок модуля (m01-1, m01-2, m01-3, m01-test)
content/words/<курс>/<греческое>.yaml   слово (как в Tavelori) + forms; поле id — w001… из лексикона
content/phrases/<курс>/<греческое>.yaml фраза (как в Tavelori, с provenance); поле id — p001… из лексикона
content/audio/<file>            аудио слов, фраз и аудирования
content/audio/<урок>/<блок>-<n>.mp3  записи реплик аудирования (npm run voices), манифест — audio/dialogues.json
content/voices/<язык>.yaml      голоса персонажей аудирования по языку курса (docs/voices.md)
content/art/palette.json        палитра иллюстраций (механика, не контент)
```

**Карточки курса.** Слово и фраза лежат в папке своего курса (`content/words/greek-a2/`): курс карточки — её папка, папка называется идентификатором курса из `courses/`. Файл прямо в `words/` или `phrases/` — ошибка сборки «карточка вне курса». Общих карточек у курсов нет: одно и то же слово на двух языках — две карточки. Идентификатор (`id`, без него — имя файла) уникален во всём контенте: прогресс хранится по нему, поэтому повтор в другом курсе — ошибка с обоими путями. Урок ссылается только на карточки своего курса. Греческий курс — `w…`/`p…`, английский — свой префикс `e…`. Письменность карточки проверяется по языку её курса.

## Курс

```yaml
title: Греческий
level: A0 → A2           # необязательно: ступени на карточке курса, A0–C2 с «+», один уровень или два через « → »
goal: С нуля до …        # необязательно: цель одной фразой, до 90 символов
short: Греческий         # необязательно: имя курса в языке, до 20 символов, без повторов в языке
palette: ink             # необязательно: гамма обложек — school, ink или coast, без повторов в языке
order: 1                 # необязательно: место среди курсов, целое от 1, без повторов
modules: [m01, …, m24]
exam:                    # необязательно: экзамен, к которому ведёт курс
  title: Экзамен A2 ΚΕΓ
  date: 2027-05-11
  source: https://…
  checkedAt: 2026-09-30
  localConfirmed: false
passShare: 0.6           # необязательно: порог сдачи навыка, доля от 0 до 1; не в exam — его строго разбирает старый клиент
calendar:                # необязательно: начало и контрольные точки
  start: 2026-10-05
  checkpoints:
    - { label: K1, title: Контрольная A1, afterModule: 8, date: 2026-12-13 }
```

`calendar` — по нему считаются темп на экране «Прогресс» и подписи точек на полке и в модуле. Точки идут по датам после `start`, метки не повторяются, `afterModule` — номер модуля этого курса. Без календаря плана нет: прогресс показывает только пройденное и темп. Без `passShare` итог контрольной не говорит «сдано» и слабый навык не выделяется.

`level`, `goal`, `short` и `order` — для выбора курса: карточка на стартовом экране и на полке неначатого курса («Название · уровень», цель, объём из модулей каталога) и порядок курсов. По `order` идут курсы каталога, стартовый экран и основной курс, пока ничего не начато; курсы без `order` — после, по id. Нагрузку в неделю карточка не показывает.

`short` — имя курса внутри его языка: «Для IT», «Для путешествий». Экраны языка называют им курс в заголовке полки («Для IT · B1 → B2»), в подписи строки «Слов», в группе «Чтения» и в блоке «Прогресса»; переключатель называет язык, а «Сегодня» и настройки — полное `title`. У двух курсов одного языка `short` не совпадает без учёта регистра — иначе ошибка сборки с обоими файлами. Без `short` курс называется `title`.

### Гамма обложек: `palette`

Цвет обложки модуля — из гаммы курса по номеру модуля, на полке, экране модуля, в пути «Прогресса» и на «Сегодня». Гаммы заданы в приложении (`src/content/palettes.ts`), по шесть цветов с контрастом белого не ниже 4.5:1: `school` — яркие школьные тетради, гамма по умолчанию (её у греческого курса нет в файле); `ink` — холодные чернильные; `coast` — тёплые. Неизвестное имя — ошибка сборки. У двух курсов одного языка гаммы разные, курс без поля считается курсом с `school`: два курса языка без поля — ошибка с обоими файлами. У курсов разных языков гамма может совпадать. Клиент, которому гамма неизвестна, рисует курс гаммой по умолчанию.

## Модуль

```yaml
number: 1
title: Γνωριμία
subtitle: Знакомство
status: draft            # draft | published
goal: Прочитать слово вслух, представиться, спросить имя
grammar: [чтение и ударение, είμαι]
sessions: 3
lessons: [m01-1, m01-2, m01-3, m01-test]
crib:                    # необязательно: шпаргалка на обороте обложки
  title: είμαι — быть
  rows: [[εγώ, είμαι], [εμείς, είμαστε], [εσύ, είσαι], [εσείς, είστε]]
  note: ου [u] · αι [e]
```

`crib` — справочное ядро грамматики модуля на изнанке обложки: от 2 до 8 пар «подпись, форма». Пары идут в две колонки построчно, поэтому порядок — как читать таблицу (ед. число слева, мн. справа). Пара короткая, до ~20 знаков: колонка на телефоне узкая. `note` — одна строка памятки.

`draft` — модуль виден в каталоге описанием и статусом, его уроки собираются для проверки, но не поставляются; аудио черновика может ещё не существовать. `published` — сборка отказывает, если в уроках модуля не хватает: текста для чтения с заданием, аудирования с транскриптом и заданием, письменного и устного задания, контрольной (`kind: test`) с оцениваемыми заданиями (`graded: true`).

`partial: true` — модуль опубликован частично: только у `published`, только значение `true`. Сборка поставляет готовые уроки, даже если навыков или контрольной не хватает, и печатает модуль и недостающее строкой «Частично опубликованы» в отчёте; урок без блоков и задания без ключей отклоняются, как у полного модуля. В каталог поле не попадает: в приложении модуль выглядит обычным опубликованным, и после всех его уроков считается пройденным. Поле снимается, когда в модуль добавлены последний урок и контрольная.

`checkpoint: m15-m1` — контрольная точка программы после модуля (K1, M1–M3): урок `kind: test` с оцениваемыми заданиями, не входящий в `lessons`. `review: [m24-r1, m24-r2]` — занятия после точки (разбор пробника и слабый навык): обычные уроки `kind: lesson`, бывают только у модуля с точкой. Следующий шаг курса идёт так: уроки модуля → точка → занятия после неё.

## Урок

```yaml
title: Знакомство и είμαι
kind: lesson             # lesson | test
items:                   # карточки урока для повторения FSRS (может быть пусто у контрольной)
  - { kind: word, id: w009 }     # είμαι
  - { kind: phrase, id: p005 }   # Πώς σε λένε;
blocks:                  # порядок блоков — порядок урока
  - { type: explanation, id: eimai, title: Глагол είμαι, body: "…", table: { columns: [лицо, форма], rows: [[εγώ, είμαι]] } }
  - { type: vocabulary, id: words }
  - { type: reading, id: text, title: Η Άννα, text: "…", glosses: [{ text: Κύπρο, russian: Кипр }] }
  - type: exercise
    id: text-tf
    about: text           # задание к чтению или аудированию — навык задания
    instruction: Верно или неверно?
    format: choice        # choice | text | gap | match
    items:
      - { id: q1, prompt: "…", options: [Σωστό, Λάθος], answer: Λάθος, explanation: "…" }
  - { type: listening, id: dialogue, title: Στο καφέ, audio: m01-dialogue.mp3, source: "…", plays: 2, transcript: [{ speaker: Άννα, text: "…" }] }
  - { type: writing, id: about-me, register: friendly, prompt: "…", words: { min: 20, max: 40 }, model: "…", criteria: ["…"] }
  - { type: speaking, id: intro, part: interview, prompt: "…", seconds: 60, model: "…", criteria: ["…"] }
```

Форматы заданий: `choice` — варианты и ровно один ответ из них (верно/неверно — варианты Σωστό/Λάθος); `text` — ввод, `answer` — список допустимых ответов (регистр, лишние пробелы и конечная пунктуация `. ! ; ?` пробелы или дефисы между цифрами (номера телефонов) не учитываются, а точка, двоеточие, запятая и косая черта между цифрами равноценны (19:45 = 19.45, 7,50 = 7.50, 6/04 = 6.04), ведущий ноль числа не важен (09:30 = 9:30; после точки ноль значим: 10.05 ≠ 10.5), пропущенное ударение — «почти»; варианты «с точкой и без» не нужны); `gap` — пропуск `___` и слово из общего `bank`; `match` — соединение с вариантом из `bank` (лишние варианты допускаются, как на экзамене). Идентификаторы карточек — короткие `w…`/`p…` из лексикона: они не зависят от написания, поэтому исправление опечатки не теряет прогресс и снимок синхронизации короче. Идентификаторы блоков и пунктов — тоже ключи прогресса: `a-z`, `0-9`, дефис, уникальны в уроке и не меняются после публикации.

**Звук.** Слова, фразы и аудирование без записи озвучиваются синтезом речи устройства (греческий голос установлен у учащегося на телефоне и ноутбуке — решение 30.09.2026). `audio` у аудирования необязателен: если файл указан, нужен и `source` с правом на использование. Транскрипт обязателен всегда: по нему звучит синтез, и он открывается после ответа.

**Голоса реплик.** У реплики транскрипта может быть `audio: <урок>/<блок>-<n>.mp3` — запись голосом персонажа из карты голосов языка курса (`content/voices/el.yaml`); её пишет скрипт озвучки, а не автор руками (`npm run voices -- <урок>`, см. [`docs/voices.md`](../voices.md)). Источник записи берётся из карты голосов. Запись, сделанная до правки текста реплики, не публикуется — реплика звучит синтезом устройства, пока её не переозвучат. Сборка отклоняет урок, если у говорящего нет голоса в карте или двое в одном диалоге звучат одним голосом. В пакете записи едут полем `lineAudio` (схема 4 без смены версии: прежний клиент его не читает).

Слово получает `forms` из лексикона (`docs/course/lexicon/NN.tsv`): мн. ч., аорист и будущее, три рода.

**Спряжение.** У греческого глагола с лицами (заглавная на -ω, -ώ, -μαι и в `forms` есть «аор.» или «прош.») сборщик строит таблицу: настоящее и прошедшее в шести лицах (`paradigm` в пакете). Правила берут заглавную форму, аорист и основу будущего из `forms`. Где правила не справляются или ошибаются, таблицу задают в карточке, и она заменяет правила:

```yaml
paradigm:
  present: [λέω, λες, λέει, λέμε, λέτε, λένε]
  past: [είπα, είπες, είπε, είπαμε, είπατε, είπαν]
```

Явная таблица нужна для глаголов с гласной перед -ω (λέω, ακούω, τρώω; λύω и -εύω идут правилами), для -ώ первого типа (προτιμώ, συναντώ: правила спрягают все -ώ как μπορώ), для аориста с синизезой (ήπια) и с приращением внутри основы (προσέλαβα), а также для είμαι. Глагол, для которого правила не дают таблицу, а явной нет, не проходит сборку. Безличные (βρέχει, πρέπει) — без таблицы. У глагола, который почти не употребляется в 1–2 лице и во множественном «мы/вы» (αρέσω, υπάρχω, κοστίζω, ταιριάζω), в карточке стоит `paradigm: { third: true }` (формы строят правила, либо задаются `present` и `past` рядом): таблица показывает только «он, она» и «они». Все таблицы печатает `PARADIGM_REPORT=1 node content/build.ts`; новый глагол сверяйте по нему. Каталог несёт `paradigms` — число слов с таблицей: пакет, поставленный версией приложения без таблиц, ставится заново.

**Слова в тексте.** Сборщик ищет в объяснениях, тексте для чтения, транскрипте и образцах письма и речи карточки этого урока и всех прошлых уроков курса (по порядку программы) и кладёт найденное в пакет (`marks`); в заданиях не ищет. Совпадение — по написанию карточки с артиклем и без, по формам из `forms` (без помет «мн.», «аор.», «буд. θα») и по частым окончаниям, которые сохраняют ударение; фраза — только целиком. Однословные омографы (σε, με, του, της, μου, σου, μας, σας, τους, ένα) отдельно не ищутся. Спорные места (две равные карточки на одном написании) не размечаются и печатаются сборщиком; весь список — `MARKS_REPORT=1 node content/build.ts`. Глосса автора важнее найденного. Поле добавлено в схему 4 без смены версии: прежний клиент его не читает.

## Текст для чтения

```yaml
id: r-m03-anna            # префикс r- зарезервирован за текстами: id урока с него не начинается
title: Η Άννα στη Λεμεσό
after: m03-3              # текст открыт, когда этот урок пройден; задаёт и словарь проверки
series: anna              # необязательно
text: |-
  Γεια σας! Με λένε Άννα. …
glosses: [{ text: σπίτι, russian: дом }]
names: [Άννα, Μόσχα]      # имена собственные знакомыми считаются, но их доля печатается
narrator: Άννα            # необязательно: рассказ от лица героя звучит его голосом, иначе — чтец reader
speakers: [Νίκος, Άννα]   # говорящий каждой строки «—» по порядку; пустое имя — голос рассказчика
provenance: { operation: requested-generation, request: "…", review: none }   # none | author | native
```

Текст едет необязательным полем `readings` в пакете урока `after` со своей разметкой слов (`readings[i].marks`, блок — сам текст); схема пакета не меняется. Сборка проверяет долю знакомых слов без глосс текста: знакомы карточки уроков до `after` включительно, их формы, слова фраз и глоссы этих уроков, служебные слова, имена и слова с общей основой не короче пяти букв (общее начало, которое сводится к приставке παρα-, κατα-, μετα-, συν-/συγ-/συμ-, προ-, απο-, επι-, δια-, υπο-, ανα-, εκ-/εξ-, не засчитывается). Меньше 95 % — отказ. Глоссы больше 4 %, имена больше 10 % и длина вне коридора — предупреждения:

| Модули | Слов |
| --- | --- |
| 01–04 | 120–250 |
| 05–10 | 180–350 |
| 11–17 | 250–450 |
| 18–24 | 350–600 |

Записи предложений (`docs/voices.md`) едут полем `readings[i].audio`: id медиа предложения или `null` по каждому предложению текста; медиа — в пакете того же урока. Клиент отбрасывает поле, если число записей не совпало с числом предложений или медиа нет в пакете. Каталог сообщает число записей текстов урока (`readingAudio`): пакет, поставленный без записей, ставится заново.

Отметка «прочитано» — строка выполнения блока `<id текста>/read`; синхронизация переносит её как блок неустановленного урока.
