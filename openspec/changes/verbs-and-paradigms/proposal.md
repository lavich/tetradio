# Proposal

## Why

Решение пользователя от 18.10.2026 (дословно): «запускай на реализацию своих предложений и Таблицу спряжения надо сделать для всех». Предложения координатора: таблицы спряжения для всех глаголов greek-a2, пропущенные частотные глаголы, фраза «Πάμε για καφέ;», глаголы в модулях 03, 04, 07.

Дополнение пользователя (18.10.2026, «да»): добавить существительное «το τηλέφωνο» (модуль 04) — отдельной карточки нет, слово живёт во фразах p049, p327, заметке к δίνω и чтениях, хотя цель модуля 04 называет «телефон». Другие слова целей модулей 01–08 без карточки — списком пользователю, без добавления.

Коррекция координатора (18.10.2026): первый пункт исходил из неточной посылки — сборщик строит таблицы сам (`content/build/paradigm.ts`, #132). В собранных пакетах таблица есть у 158 из 162 греческих глаголов (явная `paradigm` — у 9); без неё только безличные πρέπει, βρέχει, χιονίζει, φυσάει. Пункт «таблицы для всех» сводится к проверке таблиц новых глаголов и сверке уже построенных 158.

Ответы пользователя (18.10.2026):

1. Безличные πρέπει, βρέχει, χιονίζει, φυσάει — без таблицы; у αρέσω, υπάρχω, κοστίζω, ταιριάζω таблица показывает только «он/она» и «они» (настоящее и прошедшее): нужна правка сборки и отображения.
2. Лимит слов модуля 04 поднять до 48 разовым исключением в `check-lexicon`; βρίσκομαι и το τηλέφωνο остаются в модуле 04.
3. νομίζω: прошедшее — имперфект νόμιζα; аорист νόμισα — в заметке.
4. Файл `docs/course/paradigms.tsv` и тест на совпадение с ним не нужны; итоговая таблица форм — в итоговом сообщении.

## What Changes

Требование пользователя: см. выше; девять новых карточек (семь глаголов, το τηλέφωνο, фраза); таблица из третьего лица у четырёх неполных глаголов; модули 03, 04, 07 получают глаголы.

Предлагаемый объём (решения по реализации):

- Семь слов: ζω, βοηθάω (модуль 03, урок m03-2), βρίσκομαι (04, m04-3), πλένω, νομίζω (07, m07-3), σκέφτομαι (16, m16-2), ζητάω (23, m23-1) — w922–w928; 03/04/07 получают 4/3/3 глагола вместо 2/2/1. Явная `paradigm` — только у ζω (правила его не строят); у остальных таблицу строят правила.
- Слово το τηλέφωνο (w929, 04, m04-2): мн. τα τηλέφωνα, «телефон; номер телефона».
- Фраза «Πάμε για καφέ;» (p330, 04, m04-3).
- Признак `paradigm.third: true` у αρέσω, υπάρχω, κοστίζω, ταιριάζω: сборка строит шесть форм и кладёт признак в пакет, схема пакета его принимает, таблица «Все формы» показывает две строки.
- Сверка 158 построенных таблиц двумя независимыми ревьюерами морфологии выполнена (отчёт — в итоговом сообщении); исправления — только по согласованию, ни одной не сделано.
- Заголовок блока словаря «Фразы урока» → «Слова и фразы урока» в m04-3 и m07-3, куда добавлены слова.

Слова целей модулей 01–08, встречающиеся только во фразах и чтениях, — список в design.md («Кандидаты»); в объём не входят.

Вне объёма: платная озвучка (`npm run voices` не запускается: у девяти новых карточек остаётся синтез устройства), озвучка форм таблицы (идёт синтезом устройства, нового аудио не требует), файл сверенных таблиц, новые типы упражнений, другие глаголы сверх списка, правка существующих id.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `course-content`: «Таблица спряжения глагола» — признак `third`.
- `app-sections`: «Лист слова» — таблица неполного глагола.

## Impact

- Контент: 8 слов в `content/words/greek-a2`, 1 фраза в `content/phrases/greek-a2`, `paradigm.third` у четырёх карточек, `items` уроков m03-2, m04-2, m04-3, m07-3, m16-2, m23-1, `docs/course/lexicon/{03,04,07,16,23}.tsv`.
- Код: `content/build/{cards,sources}.ts`, `src/content/schema.ts`, `src/domain/card-fields.ts`, `src/shared/VerbForms.tsx`, `scripts/check-lexicon.ts` (исключение модуля 04), `docs/course/format.md`.
- Пакеты: версия пакета — хэш содержимого; по сборке изменились 22 пакета (6 уроков с новыми карточками и пакеты, чьи пометки слов подхватили новые слова). Установленные пакеты обновит обычная проверка каталога; id существующих карточек не меняются, прогресс сохраняется; новые карточки в пройденных уроках план вводит как новые. Схема пакета и облако не меняются; `third` необязателен, прежний клиент покажет полную таблицу.
- Бюджеты (вывод сборки): максимум пакета 32 724 → 32 922 из 40 000 байт gzip, каталог 18 527 → 18 567 из 25 000, курс 1 406 076 → 1 409 893 из 1 600 000.
