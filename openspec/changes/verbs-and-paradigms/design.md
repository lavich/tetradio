## Context

- Таблицы строятся `content/build/paradigm.ts` (правила) либо берутся из `paradigm` в YAML; собранный пакет несёт таблицу, каталог — число таблиц `paradigms`; приложение показывает «Все формы» (`src/shared/VerbForms.tsx`, `ParadigmTable`).
- Состояние на 18.10.2026 (`PARADIGM_REPORT=1 node content/build.ts`): таблица у 158 из 162 греческих глаголов (явных 9). Без таблицы βρέχει, χιονίζει, φυσάει, πρέπει.
- Озвучка форм таблицы: `onSay` → `playText(form, undefined, profile)` (`src/shared/audio.ts:261`) — без файла, синтез речи устройства. Нового платного аудио форм не нужно и не планируется; форм в таблицах (12 на глагол) — 1 980 на 165 глаголов.
- Версия пакета — хэш канонического содержимого (`content/build/output.ts:37`); установка (`src/content/apply.ts`) добавляет новые карточки, не трогает ревизию неизменных и сохраняет прогресс; исчезнувшая карточка теряет связь с уроком, не саму запись.

## Decisions

1. **Не писать явные таблицы там, где правила верны.** Явная `paradigm` заменяет правила и теряет защиту от их изменений; она нужна только ζω. Верность дала независимая сверка (два ревьюера, 165 таблиц), а не дублирование в YAML. Файл сверенных таблиц и тест пользователь отклонил (18.10.2026).
2. **Неполные глаголы: `paradigm.third: true`.** `Paradigm.third?: true` (`src/domain/card-fields.ts`); `paradigmOf` (`content/build/cards.ts`) при `third` без `present`/`past` строит шесть форм правилами (нет вывода — ошибка сборки), при явных формах берёт их; клиентская схема (`parseParadigm`) принимает только `true`; `ParadigmTable` показывает лица с индексами 2 и 5. Безличные πρέπει, βρέχει, χιονίζει, φυσάει остаются без таблицы (`hasParadigm` и правила не менялись). Признак необязателен: схема пакета не меняется, прежний клиент показывает полную таблицу.
3. **Новые слова.** Формы (`forms`) и таблицы, сверенные двумя ревьюерами:
   - ζω — аор. έζησα; буд. θα ζήσω; явная: ζω ζεις ζει ζούμε ζείτε ζουν | έζησα έζησες έζησε ζήσαμε ζήσατε έζησαν; ru «жить (быть живым)», в note — о месте проживания чаще μένω (у μένω «проживать»).
   - βοηθάω — аор. βοήθησα; буд. θα βοηθήσω; ru «помогать», note «вариант βοηθώ».
   - βρίσκομαι — аор. βρέθηκα; буд. θα βρεθώ; ru «находиться; встречаться»; note: βρισκόμαστε — встречаемся, βρέθηκα — оказался, «находился» — βρισκόμουν.
   - πλένω — аор. έπλυνα; буд. θα πλύνω; ru «мыть, стирать»; отличается от πλένομαι (17).
   - νομίζω — прош. νόμιζα; буд. θα νομίσω (решение пользователя); ru «полагать, считать»; аорист νόμισα — «показалось» в note.
   - σκέφτομαι — аор. σκέφτηκα; буд. θα σκεφτώ; ru «думать, размышлять» (νομίζω — «полагать»: переводы различаются).
   - ζητάω — аор. ζήτησα; буд. θα ζητήσω; ru «просить, требовать»; note «вариант ζητώ».
   - το τηλέφωνο — мн. τα τηλέφωνα, без таблицы.
   У каждого слова `ipa` (тест `course-content` требует). Таблицы — вывод `PARADIGM_REPORT=1 node content/build.ts`, совпавший с перечнем выше посимвольно; те же формы закреплены в `tests/paradigm-third.test.tsx`.
4. **Размещение.** По теме и без опережения программы: ζω, βοηθάω — m03-2 (урок о семье; в тексте урока их нет, слова входят через словарь); βρίσκομαι и «Πάμε για καφέ;» — m04-3, το τηλέφωνο — m04-2; πλένω, νομίζω — m07-3; σκέφτομαι — m16-2 «Школа, курсы и экзамены»; ζητάω — m23-1 «Официальный стиль, документы и банк». Спряжение как тема — модуль 05: в 03/04/07 глаголы даны словами.
5. **Лимиты лексикона.** До правки в модуле 04 было 46 слов из 47 (35 + SLACK 12); с βρίσκομαι и το τηλέφωνο — 48. По решению пользователя `scripts/check-lexicon.ts` получает разовое исключение `EXTRA = { 4: 1 }`. Фраз в 04 становится 15 из 15: новые фразы в 04 без пересмотра лимита невозможны. Модули 03 (45 из 47), 07 (37 из 47), 16 (41 из 52), 23 (31 из 42) в пределах. Новое предупреждение «для без ударения» в `04.tsv` (p330) допустимо: 55 вместо 54.
6. **Фраза p330.** Следующий свободный номер, `pos = фраза`, в `04.tsv` и `items` m04-3. «Θέλεις να πάμε για καφέ;» (p272, модуль 21) — отдельная фраза.
7. **Установленные пакеты.** Формат пакета и схема не меняются, миграций нет; каталог несёт `paradigms` (число слов с таблицей), поэтому пакет, поставленный без таблиц, ставится заново (уже работает). Прежние карточки не перезаписываются (ревизия неизменна), новые добавляются (`tests/paradigm-update.test.ts`); прогресс не затрагивается. Изменившиеся версии — 22 пакета; контрольный список — сравнение каталога до и после.
8. **Озвучка.** `npm run voices` не запускается. Девять новых карточек звучат синтезом устройства до решения пользователя; озвучка форм таблицы — синтез устройства.
9. **Побочный эффект.** Фраза p330 закрывает в отчёте сборки строку «непройденные слова» m08-test varvara-tf.q2 «καφέ»; это затрагивает разбор отчёта в открытом изменении `question-language`, конфликта нет.

## Кандидаты на отдельную карточку (модули 01–08)

Слова, которые есть только внутри фраз (поиск по фразам лексикона 01–08 и по отчёту чтений «не нашлись»; формы известных слов отброшены вручную). В объём не входят, решает пользователь:

- επίσης (01, p011 «Επίσης.»), χαίρομαι / «Χάρηκα» (01, p010; готовая формула), σημαίνω (02, p026 «Τι σημαίνει;»), τα αδέλφια (03, p028 «Έχεις αδέλφια;»), διαζευγμένος (03, p035; цель модуля называет семейное положение), ο ύπνος (05, p066), η κατάσταση (07, p090 «σε καλή κατάσταση»), χορτοφάγος (08, p102), η όρεξη («Καλή όρεξη», 08, p104), πειράζει («Δεν πειράζει», 01, p013; формула).
- Имена собственные (Μόσχα, Λεμεσός) и формы известных слов (μήνα, χρόνο, Οκτωβρίου, χρονών, ήρθες) — не кандидаты. Страдательные формы объявлений (Νοικιάζεται, Πωλείται, λέγεται) даны как формулы во фразах.

## Risks / Trade-offs

- Ошибка в форме уйдёт учащимся как эталонная: риск снижают два независимых прохода (Opus и Fable) по 165 таблицам; пользователь не носитель, итог нужно показать преподавателю (как в `REVIEW.md`).
- Новые слова меняют пометки (marks) других уроков и их версии — ожидаемо.
- Сомнения ревьюеров, не исправленные без согласования: ударение καταπιάμε/κατάπιαμε (καταπίνω), императивы πρόσεχε/απόφευγε (несовершенный вид, остальные — совершенный), смысл аориста λυπήθηκα (λυπάμαι).

## Реализация

Отклонения и добавления по ходу:

- У ζω перевод «жить; быть живым» и заметка «Ζω στην Κύπρο — живу на Кипре; «где живёшь?» (адрес) — Πού μένεις;» (ревью данных: ζω в m24-m3 употреблено как «жить где-то»); IPA ζω — /ˈzo/, το τηλέφωνο — /to tiˈlefono/ (у всех существительных IPA с артиклем).
- Слова поставлены в `items` перед фразами (порядок словаря урока).
- Таблица неполного глагола получила скрытую подпись `<caption>`: «Только третье лицо: он, она и они».
- Известное ограничение: токенизатор пометок (`content/marks.ts`) режет слово по `**` и дефису, поэтому «δια**βά**ζω» (m05-1) и «-ζω», «ε-τοι-μά-ζω» (m14-1) ложно получают подсказку ζω. Правка токенизатора меняет пометки ещё в m15-1, m20-1, m22-1; не сделана без решения пользователя.
- `npm run lexicon:sync` показывает прежние расхождения вне этого изменения: θέλω (`02.tsv`, w066) и υπάρχω (`06.tsv`, w207); не тронуты.
- Ревью кода (два независимых ревьюера): блокирующих нет; мелкие замечания исправлены (подпись, тесты `third` с одним `present`, принятие `third: true` клиентом, обновление установленного слова до `third`, README лимита 04).
