## Context

- Каталог строится из `content/courses/*.yaml`; курс из модулей описан в `content/build/courses.ts`. Уроки черновика проверяются, но не поставляются (`content/build/courses.ts:66`); у опубликованного модуля `checkCoverage` требует полноту через `publicationGaps` (`content/build/lessons.ts:290-298`, `src/content/course.ts:575-596`): чтение и аудирование с заданиями, письмо, речь, контрольная с `graded`. Два урока t01 этому не удовлетворяют.
- Неизвестное поле модуля отклоняется (`MODULE_FIELDS`, `content/build/sources.ts:297-310`), поэтому новое поле надо явно разрешить.
- Карточки: дубль внутри всего контента сейчас — та же пара «текст + перевод» (`content/build/cards.ts:171-216`). Одно и то же английское слово с другим переводом в двух английских курсах сборка пропустит.
- Английского лексикона в TSV нет: `docs/course/lexicon/NN.tsv` и `scripts/check-lexicon.ts` — только для греческого (греческие буквы, артикли, объёмы 35–52 слов на модуль). У IT-курса лексикон — сами файлы `content/words/english-it/ew…` и `content/phrases/english-it/ep…` (35 и 25 на e01).
- Звук: у e01 IT-курса нет записей (`grep audio: content/lessons/e01-*` — 0), реплики звучат синтезом устройства (`src/shared/dialogue.ts:160-170`, голос языка `en-GB` из `src/domain/language.ts:101`); если голоса нет, кнопка пишет «Озвучка недоступна» (`src/features/learning/exercises/SpeakText.tsx:42`). Сборка требует голос у каждого персонажа в карте `content/voices/en.yaml`, даже без записей; там заняты Sarah, Daniel, Mark, Elena.
- Клиент уже умеет третий курс: стартовый экран по языкам, переключатель «Курса» с «+», пауза (`course-start`, `course-pause` в `main`). Переключатель называет курс `short ?? title` (`src/shared/CourseSwitch.tsx:113`), то же — заголовок полки (`src/features/course/ShelfScreen.tsx:58`) и выбор основного курса в настройках (`src/features/progress/SettingsScreen.tsx:146`). Уникальность `short` сборка не проверяет. Три варианта и больше на 360 px прокручиваются лентой без обрезки (`src/shared/course-switch.module.css:8-9`).
- Модуль считается пройденным, когда пройдены все его уроки каталога (`src/storage/course.ts:246`); экран модуля пишет «N из M пройдено» (`src/features/course/ModuleScreen.tsx:95`).
- e2e идут на фикстурах (`playwright*.config.ts`), настоящий контент проверяют unit-тесты: `tests/course-content.test.ts:58` закрепляет список курсов `["greek-a2", "english-it"]`.

## Goals / Non-Goals

**Goals:**

- Курс «Английский для путешествий и общения» в каталоге: виден на стартовом экране и на «Курсе», начинается «Учить курс».
- Два первых урока t01 проходятся целиком; пользователь смотрит их и решает о продолжении.
- Сборка не даёт тихо завести карточку, которая уже есть в другом английском курсе.

**Non-Goals:**

- Модель «язык → курсы» (переключатель языка, общее повторение, полки и словарь языка) и требование «Тематический курс» целиком — изменение (в).
- `t01-3`, `t01-test`, уроки `t02`–`t14`, контрольные точки.
- Записи голосов Google TTS, американские голоса, вариант языка у персонажа.
- Пометка частичного модуля в интерфейсе.

## Decisions

### 1. Частичный модуль — поле исходника `partial: true`

Модуль `t01`: `status: published`, `partial: true`, `lessons: [t01-1, t01-2]`. Сборка для такого модуля вызывает `publicationGaps` как обычно, но пробелы о навыках и контрольной не роняют сборку, а уходят в отчёт (`BuiltContent.partial: { id, gaps }[]` и строка «Частично опубликованы: t01 — нет письменного задания; нет устного задания; нет контрольной»). Пробел «урок …: нет блоков» по-прежнему роняет сборку. Поле — только `true` и только у published; в каталог не попадает (`parseModule` получает модуль без него).

Почему так: изменение остаётся в сборке, клиент, каталог и облако не трогаются; поле видно в файле модуля и снимается одной строкой, когда добавятся `t01-3` и `t01-test`.

Альтернативы:

- **Сразу полный t01** (4 урока, включая письмо, речь и контрольную): никаких правок кода, но это вдвое больше контента, а пользователь просил «пару первых уроков». Остаётся запасным вариантом (вопрос 1).
- **Новый статус модуля `preview` в каталоге**: клиент прежней версии разбирает `status` через `oneOf(["draft", "published"])` (`src/content/course.ts:600`) и отклонил бы весь каталог — нужна совместимость, правка клиента и экрана модуля. Дороже без пользы для просмотра.
- **Черновик t01 и просмотр только локально** (`npm run dev`): без правок кода, но в Telegram на телефоне курс не появится.
- **Курс из плоского списка `lessons:` без модулей**: проверки полноты нет, но пропадают модули-черновики и «Готов 1 модуль из 14» на карточке курса, а после перехода на модули курс выглядел бы иначе.

Следствие для учащегося: после двух уроков модуль t01 считается пройденным («2 из 2 пройдено»); когда придут `t01-3` и контрольная, он снова станет незавершённым («2 из 4»). Прогресс уроков сохраняется: id уроков не меняются. Календаря у курса нет, поэтому темп и отставание это не искажают.

### 2. Карточки курсов одного языка — проверка в `buildCards`

В `buildCards` уже известен язык курса каждой карточки (`languages.get(src.course)`). Добавляются два словаря «язык + нормализованный текст → файл»: для слов — нижний регистр, NFC, схлопнутые пробелы, без начального английского артикля `a/an/the` (`to` и греческие артикли не срезаются: `to book` и `a book`, `η χώρα` и `χώρα` — разные слова); для фраз — нижний регистр, без знаков препинания и лишних пробелов. Совпадение у карточек **разных** курсов одного языка — `ContentError` с обоими файлами. Внутри курса и между языками — прежние правила.

Почему здесь: программа требует «без пересечений с IT-курсом» и описывает ручную сверку; проверка в сборке стоит десяток строк и ловит ошибку до публикации. Это часть будущего требования «Тематический курс» (изменение (в)); остальное — спека о тематических курсах и расхождение с «Курс — трек языка» — остаётся (в).

Альтернатива — отдельный скрипт сверки, как `check-lexicon.ts`: лишний шаг CI ради одного правила.

### 3. Файл курса и модули

```yaml
title: Английский для путешествий и общения
level: B1 → B1+
goal: Поездка и разговор с новыми людьми на английском
short: Путешествия        # временно, вопрос 2
order: 3
language: en
source: "Программа курса: docs/curriculum-english-travel.md"
passShare: 0.6
modules: [t01, …, t14]
```

Модули `t01`–`t14` — по разделу «Модули» программы: `number`, `title` (английское название), `subtitle` (русское), `goal`, `grammar`, `sessions: 3`; `t01` — со шпаргалкой `crib` (вежливые просьбы). Контрольные `t07-c1` и `t14-c2` — позже, вместе с уроками модулей.

### 4. Короткое имя — временно «Путешествия»

С `short: Английский` у обоих английских курсов переключатель «Курса» и выбор основного курса покажут два одинаковых варианта. До изменения (в), где переключатель станет языковым, предлагается `short: Путешествия` (11 символов, лимит 14): «Греческий · Английский · + Путешествия». Язык курса виден на стартовом экране (группа «Английский») и в полном названии на карточке.

Альтернативы: «Англ. поездки» (13) — язык виден, но сокращение; переименовать IT-курс в «IT» — меняет уже показанное имя. Сборочную проверку уникальности `short` не добавляем: в (в) оба курса языка, возможно, снова получат общий ярлык языка.

### 5. Карточки t01 — 15 слов и 15 фраз

По программе первый урок вводит первую половину карточек модуля, второй — вторую, третий новых карточек не вводит; поэтому лексикон t01 вводится целиком в двух уроках, и `checkCoverage` («карточка не входит ни в один урок») не мешает. Формат — как у IT-курса: `content/words/english-travel/twNNN.yaml` (`greek` — английский текст, `russian`, `ipa`, `note`, `source`), `content/phrases/english-travel/tpNNN.yaml` (`text`, `translation`, `provenance` с `operation: requested-generation`, `sourceLabel` — агент, `request` — программа модуля t01).

Черновой список (уточняется при подготовке, сверка с `english-it` — проверкой из решения 2):

### 6. Уроки t01-1 и t01-2

Готовятся по `docs/lesson-authoring.md` и навыку `prepare-lesson` в режиме `generate` в границах программы t01; задания — блоки по `docs/course/format.md` (навык `prepare-lesson` их не пишет, они — по формату курса, как в `e01-*`).

- **t01-1 «Polite requests at the airport»** (грамматика и лексика): объяснение вежливых просьб (*Could I…, Would it be possible to…, Do you mind if…*) с таблицей и типичной ошибкой; объяснение present simple для расписания; `vocabulary`; 4–5 заданий (`choice`, `gap`, `match`, `text`) с ключами и пояснениями ошибок.
- **t01-2 «Announcements and the check-in desk»** (аудирование и чтение): чтение посадочного талона и табло вылетов с заданием; аудирование 1 — объявления (голос `narrator`) о смене гейта и задержке, `plays: 2`; аудирование 2 — разговор у стойки регистрации; задания к каждому; `vocabulary` второй половины.
- Вопросы к аудио и тексту — по-английски, как в `e01-2`; объяснения и пояснения ошибок — по-русски.
- Персонажи — новые имена в `content/voices/en.yaml`, голоса `en-GB` из пулов, разные внутри диалога: например, Priya (стойка регистрации), Marco (пассажир из Италии, речь неносителя передаётся текстом реплик), Ana, Tom. Объявления — `narrator`.
- Без записей: `npm run content` печатает число неозвученных реплик; приложение озвучивает их синтезом устройства. Записи — позже, `GOOGLE_TTS_KEY=… npm run voices -- t01-1 t01-2 words phrases --course=english-travel`.

### 7. Проверки

- `tests/course-build.test.ts` — фикстуры сборки для `partial` и дублей между курсами (решения 1 и 2).
- `tests/course-content.test.ts` — настоящий контент: список курсов, поля курса, 14 модулей, t01 частичный с двумя уроками, карточки `tw`/`tp` 15 + 15, остальные модули — черновики, у `greek-a2` нет частичных модулей.
- Языковая проверка уроков — отдельным проходом субагента-рецензента (только чтение) до PR; сборка языковую корректность не доказывает.
- Вид уроков — временный скриншот на 390 px по настоящей сборке (`npm run dev`), затем удалить.

## Risks / Trade-offs

- [Модуль «пройден» после двух уроков, затем снова «в процессе»] → приемлемо для просмотра; календаря нет. Если мешает — вопрос 3 (пометка в интерфейсе, отдельная правка клиента).
- [`partial` останется в контенте надолго и станет обходом проверки полноты] → отчёт сборки печатает каждый частичный модуль; тест на настоящем контенте запрещает `partial` у `greek-a2`; снимается вместе с `t01-3`/`t01-test`.
- [Синтез устройства: голоса нет — «Озвучка недоступна», аудирование не пройти на слух] → так уже у e01 IT-курса; транскрипт открывается после ответа. Записи — когда будет ключ.
- [Сгенерированный английский со сленгом и акцентами без носителя] → в t01 регистр нейтрально-вежливый (программа, «Регистр → модуль»); рецензия моделью до PR; носитель — до второй ступени, как в программе.
- [Нормализация дублей ловит законные пары (*check in* — фразовый глагол и *check-in* — существительное)] → дефис не убирается, это разные тексты; при ложном срабатывании карточка остаётся в одном курсе, в другом — глосса.

## Migration Plan

Только контент и сборка: формат каталога и пакетов, база и облако не меняются. Откат — удалить файлы курса; начатые уроки курса у учащегося останутся в базе, как у снятого с каталога курса.
