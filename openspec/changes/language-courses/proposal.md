## Why

«Курс», «Слова», «Чтение» и «Прогресс» сейчас показывают один выбранный курс с переключателем курса вверху (`src/shared/CourseSwitch.tsx:86-120`, выбор — `src/storage/courses.ts:210-272`). С курсом для путешествий у английского два курса: переключатель из трёх вариантов на 390 px уже не помещается и прокручивается лентой (`openspec/changes/english-travel-start/design.md`, «Реализация»), а слова, тексты и прогресс одного языка разнесены по разным курсам. Спека «Курс — трек языка» (`openspec/specs/course-content/spec.md:223`) описывает один курс на язык и расходится с тематическими курсами; `english-travel-start` отложил требование «Тематический курс» сюда. Это изменение (в) брифа `docs/design/multi-course.md`, шаг 1 из 2.

## Решения пользователя

- **20.10.2026** — бриф `docs/design/multi-course.md` согласован (весь документ): учащийся учит языки, у языка бывает несколько курсов; переключатель языка «Греческий | Английский» на «Курсе», «Словах», «Чтении» и «Прогрессе», выбор общий и запоминается; на «Сегодня» переключателя нет; «Курс» — полки курсов одна под другой, у полки заголовок («Для IT · B1 → B2»), счётчик «N из M» и меню «⋯», у каждого курса своя гамма обложек; «Слова» — общий словарь языка, у строки подпись курса, фильтр по курсу; «Чтение» — тексты языка по курсам; «Прогресс» — навыки языка с разбивкой по курсам, темп и контрольные по каждому курсу; широкий экран — полки одна под другой, без колонок; неначатый курс — на месте полки карточка с «Учить курс»; язык без начатых курсов помечен «+», при выборе — карточки его курсов; одно слово — карточка одного курса.

Вторым изменением — «Сегодня» по языкам с общим повторением языка.

## Вопросы пользователю

Ниже — умолчания, с которыми написаны спеки и задачи (обоснование — design.md). Нужно подтвердить или поправить.

1. **«+» у языка без начатых курсов** — только на «Курсе»; при его выборе — карточки курсов языка с «Учить курс». «Слова», «Чтение» и «Прогресс» такой язык не предлагают и показывают последний выбранный язык с начатым курсом. Рекомендую: так работает «+» у курса сейчас.
2. **Переключатель при одном начатом языке**, когда в каталоге есть второй язык с уроками: на «Курсе» — «Греческий | + Английский», на остальных трёх экранах переключателя нет. Рекомендую.
3. **Заголовок «Полка» и «N из M».** Рекомендую: один заголовок первого уровня «Полка» на экран; у каждой полки — заголовок второго уровня «Для IT · B1 → B2», справа счётчик «3 из 11 заполнено» и «⋯»; строка экзамена — под заголовком своей полки.
4. **Ссылка на модуль, урок или слово другого языка** (`followCourse`) — делает выбранным язык курса, без прокрутки к полке: «Назад» возвращает прежнее место. Прокрутка к курсу — только для «Начать другой курс» на «Сегодня» (экран «Все курсы на паузе»): там открывается карточка нужного курса. Рекомендую.
5. **Где хранить выбор языка** — новые ключи устройства (как выбор курса сейчас, в облако не идут); при первом запуске новой версии язык берётся из прежнего выбора курса, прежние ключи не удаляются (откат на прежнюю версию сохраняет её выбор). Рекомендую.
6. **Имя курса вне экрана языка.** `short` «Для IT» без языка непонятен. «Сегодня» (строка второго курса и «Все курсы на паузе») уже пишет полное название — не меняется. В «Настройках и данных» (выбор основного курса), в доступном имени «⋯» и в строке статуса паузы — полное название («Английский для IT»). Рекомендую.
7. **`short` у `greek-a2`.** Рекомендую оставить «Греческий»: курс у языка один, заголовок полки «Греческий · A0 → A2». Вариант по аналогии с английскими — «Для экзамена» (тогда «Для экзамена · A0 → A2»); менять стоит, когда появится второй греческий курс.
8. **«Для путешествий» — 15 символов, лимит `short` — 14** (`SHORT_MAX`, `src/content/course.ts:188`). Рекомендую поднять лимит до 20: прежний клиент отбросит такое `short` и покажет полное название. Вариант без правки лимита — «В поездки».
9. **Узкий экран 360–390 px.** Заголовок полки переносится на вторую строку, счётчик и «⋯» остаются справа целиком; переключатель из двух языков помещается без прокрутки. Рекомендую.
10. **Порядок полок, пауза и неначатый курс.** Полки — по порядку курсов (начатые по порядку начала, затем неначатые по месту в каталоге). Курс на паузе остаётся на своём месте, приглушённым, с «На паузе с …» и «Продолжить курс». Неначатый курс языка с уроками — карточкой с «Учить курс» на своём месте после начатых. Рекомендую.
11. **Карточка «Готовится»** (курс языка без опубликованных уроков) на «Курсе» не показывается — как сейчас в переключателе; она есть на стартовом экране. Рекомендую.
12. **Цвет обложки на «Сегодня».** Обложка урока на «Сегодня» и путь на «Прогрессе» берут цвет из гаммы курса, иначе один модуль выглядит по-разному на разных экранах. Это единственное видимое изменение «Сегодня» в шаге 1: у английских курсов меняются цвета. Рекомендую.
13. **Один начатый курс языка.** «Слова» без подписи курса и фильтра, «Чтение» без заголовков курсов, «Прогресс» без отдельной суммы — как сейчас; на «Курсе» у полки заголовок «Греческий · A0 → A2». Рекомендую.
14. **Итог недели на «Прогрессе»** — по языку (занятия всех курсов языка и дни повторения его карточек), в блоке «Всего по английскому». Рекомендую.
15. **Язык, курс которого начат на другом устройстве и ещё не скачан.** На «Курсе» — без «+», с полкой курса (как сейчас у курса); на «Словах», «Чтении» и «Прогрессе» язык появляется после установки первого урока — показывать там нечего. Рекомендую.
16. **Слабый навык в сумме по языку не выделяется**: у курсов языка разные пороги (`passShare`), выделение остаётся в блоке курса. Подписи суммы — в таблице текстов ниже. Рекомендую.

## What Changes

Предлагаемый объём шага 1, в рамках решений выше:

- **Переключатель языка** вместо переключателя курса на «Курсе», «Словах», «Чтении» и «Прогрессе»: названия языков из профилей, «+» и доступное имя «<язык>, не начат» у языка без начатых курсов — только на «Курсе». Выбор языка общий для четырёх экранов, запоминается на устройстве и в облако не идёт. Модуль, урок, слово или текст, открытые по ссылке, делают выбранным язык своего курса.
- **«Курс» — полки языка** одна под другой (и на широком экране): у полки заголовок «<short> · <level>», счётчик «N из M заполнено», меню «⋯» с паузой, строка экзамена своего курса, плашка паузы; неначатый курс языка — карточка с «Учить курс» на своём месте.
- **Гамма обложек** — необязательное поле курса `palette` из набора гамм клиента; без поля — нынешняя гамма (греческий её сохраняет); у двух курсов одного языка гаммы разные. Обложки курса во всех местах — полка, экран модуля, путь «Прогресса», «Сегодня» — в гамме курса.
- **«Слова»** — общий словарь начатых курсов языка: группы уроков по курсам в порядке курсов, подпись курса `short` у строки, фильтр «Курс» вместе с фильтром состояния, поиск по всему языку.
- **«Чтение»** — открытые тексты начатых курсов языка, по курсам («Для IT · B1 → B2»), внутри — по модулям; сводка «Прочитано N из M открытых» по языку, строка о закрытых текстах — у курса.
- **«Прогресс»** — вверху «Всего по английскому»: навыки языка, слова и фразы, ошибки уроков, проблемные карточки, итог недели; ниже блок на каждый начатый курс языка: заголовок, «Курс на паузе с …», путь по модулям, положение против календаря, темп, контрольные, навыки курса.
- **Имена курса.** `short` — имя курса внутри языка: «Для IT», «Для путешествий», «Греческий»; лимит — 20 символов; у двух курсов одного языка `short` не совпадает (сборка). Вне экрана языка — полное название.
- **Спека о тематических курсах:** «Курс — трек языка» больше не говорит «один курс на язык»; новое требование «Тематический курс».

**Не входит:** глоссы для слов другого курса того же языка (`english-travel-start/design.md`, вопрос 5) — слово в тексте другого курса остаётся словом по нажатию, как сейчас. **Шаг 2** (отдельное изменение): «Сегодня» по языкам — блоки языков, общее повторение карточек всех курсов языка, «Ещё N курсов →», выбор основного языка; требование learning-session «План и занятие по курсу». План, занятие, повторение, пауза и синхронизация не меняются.
