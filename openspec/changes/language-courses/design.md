## Goals / Non-Goals

**Goals:**

- Язык — единица выбора четырёх экранов; курсы языка видны вместе, без переключения между ними.
- Ни одно требование «Сегодня», плана, занятия, паузы и синхронизации не меняется; «Сегодня» отличается только цветом обложек английских курсов.
- Выбор, сделанный прежней версией, переходит в выбор языка без вмешательства учащегося.

**Non-Goals:**

- «Сегодня» по языкам, общее повторение языка, основной язык — шаг 2.
- Новая сущность «язык» в базе, каталоге или облаке: язык выводится из курсов.
- Сортировка курсов внутри языка вручную; скрытие начатого курса.

## Decisions

### 1. Язык выводится из курсов

`languages()` в `src/storage/courses.ts` группирует `courses()` по `language`: `{ code, title: PROFILES[code].names.title, started, courses }`. Язык попадает в список, если у него есть начатый курс или курс каталога с опубликованными уроками (те же условия, что у варианта переключателя сейчас); порядок языков — по первому курсу языка в `courses()`, то есть начатые по порядку начала, затем по месту в каталоге. `CourseEntry` получает `level` и `palette` из записи курса.

Почему: язык курса уже есть в каталоге и `CourseEntry`; отдельная таблица или ключ облака ничего не добавляют, а снимок и формат облака остаются прежними.

Альтернатива — поле `language` в выборе основного курса и в облаке: нужно только для шага 2 («основной язык»), и там его можно вывести из основного курса.

### 2. Выбор языка — два новых ключа устройства, прежние ключи не трогаются

Ключи `meta`: `currentLanguage` (выбор на «Курсе», бывает языком без начатых курсов) и `currentStartedLanguage` (последний выбранный язык с начатым курсом). Функции:

- «Начатый» для выбора языка «Слов», «Чтения», «Прогресса» — язык, у курса которого есть уроки на устройстве (`installed`), как у `currentCourse()` сейчас (`src/storage/courses.ts:218-222`) и у переключателя этих экранов (`useCourses`, `src/shared/courses.ts:23-24`): курс, только ждущий установки из снимка, показать там нечем. На «Курсе» такой язык — без «+» и с полкой курса (`started`), как сейчас курс.
- `currentLanguage()` — язык «Слов», «Чтения», «Прогресса»: `currentLanguage`, если у него есть установленный курс; иначе `currentStartedLanguage`, если у него есть установленный курс; иначе язык `primaryCourse()`. Пока ничего не начато — выбранный язык или язык первого курса каталога.
- `shelfLanguage()` — язык «Курса»: `currentLanguage`, если такой язык есть в `languages()`; иначе `currentLanguage()`.
- `setCurrentLanguage(code)` — как `setCurrentCourse` сейчас (`src/storage/courses.ts:254-257`): в `currentStartedLanguage` пишется `installed(code) ? code : installed(prev) ? prev : stored ?? migrated`, где `prev` — прежний `currentLanguage`, `stored` — прежний `currentStartedLanguage`, `migrated` — язык из прежних ключей курса. Так «+»-выбор не стирает начатый выбор, а прежний «+»-язык, курс которого с тех пор начат, поднимается в начатый выбор (сценарий «Несколько неначатых выборов подряд»).
- `followCourse(courseId)` — переносится на язык (пока экраны не переведены на язык, он пишет и прежний выбор курса через `setCurrentCourse`; это убирается вместе с прежними функциями): если язык курса не показан на «Слова/Чтение/Прогресс» или на «Курсе» выбран другой язык без начатых курсов, вызывает `setCurrentLanguage(язык курса)`; иначе ничего не пишет (без явного выбора экраны следуют за языком основного курса, как сейчас за основным курсом). Прокрутки к полке курса нет: «Назад» восстанавливает прежнее место (вопрос 4).
- **Миграция чтением.** Пока ключа `currentLanguage` нет, функции читают прежние ключи: язык `currentCourse` прежнего выбора — если он начат или есть `currentStartedCourse` (то же правило, что `shelfCourse()` применяет к неначатому выбору прежней версии), язык `currentStartedCourse` — для начатого выбора. Новый ключ пишется только при выборе языка. Прежние ключи остаются в базе: откат на прежнюю версию показывает её последний выбор курса.

`currentCourse`, `shelfCourse`, `selectedCourse`, `setCurrentCourse` и хук `useCurrentCourse` удаляются отдельной задачей после перевода всех экранов (их вызывают `ShelfScreen.tsx:32`, `WordsScreen.tsx:47`, `ReadingsScreen.tsx:18`, `ProgressScreen.tsx:31`, `CourseSwitch.tsx:90-95`, `AllPaused.tsx:14`); константы прежних ключей остаются для миграции.

Альтернатива — один ключ `currentLanguage` без начатого выбора: тогда «+ Английский» на «Курсе» переключил бы «Слова» на пустой язык или сбросил бы их на основной — это поведение уже отвергнуто в `course-start` («Несколько неначатых выборов подряд»).

### 3. Переключатель языка на `Segmented`

`LanguageSwitch` (вместо `CourseSwitch`, тот же файл или `src/shared/LanguageSwitch.tsx`): `Segmented` с `label="Язык"`, `testId="language-switch"`, вариант — `{ id: code, title: names.title, unstarted: !started }`. `shelf` — языки из `languages()`, иначе только с начатыми курсами; меньше двух вариантов — переключателя нет. Два языка на 360 px помещаются без прокрутки ленты (самое длинное имя — «Английский», 10 символов, против трёх курсов сейчас).

### 4. «Курс» — список полок, полка курса — отдельный компонент

`CourseScreen` читает `shelfLanguage()` и курсы языка и рисует заголовок «Полка», затем по порядку курсов: начатый курс — `CourseShelf`, неначатые курсы с опубликованными уроками — одним `FirstRun` после полок (`CourseStart` получает список курсов вместо одного `courseId`). `FirstRun` считает загрузку и главную кнопку внутри себя (`src/features/today/FirstRun.tsx:33-47`): отдельный `CourseStart` на каждый курс дал бы две главные «Учить курс» и вторую активную во время загрузки первой. Два курса одного языка `FirstRun` группирует под `h2` языка (`FirstRun.tsx:60-73`); на «Курсе» язык уже выбран, поэтому `FirstRun` получает режим без группы по языку — карточки с `h2` названия курса, на одном уровне с заголовками полок. `CourseShelf` — нынешнее тело `CourseScreen` для одного курса: строка заголовка `h2` «<short> · <level>» со счётчиком и `CourseMenu`, `ExamLine`, плашка паузы, обложки и метки контрольных. Фокус после паузы и возврата и ошибка действия — внутри полки, как сейчас на экране; строка статуса `role="status"` — одна на экран (её объявление не должно зависеть от того, какая полка перерисовалась).

Заголовок `h1` «Полка» остаётся один; счётчик переезжает в строку заголовка полки (вопрос 3). На 360 px строка заголовка — `flex-wrap` с заголовком `min-width: 0`: текст переносится, счётчик и «⋯» не сжимаются.

`AllPaused` («Начать другой курс») вместо `setCurrentCourse(id)` вызывает `setCurrentLanguage(язык курса)` и переходит на «Курс» с `state: { course: id }`; `CourseScreen` прокручивает к карточке этого курса и ставит на неё фокус (`scrollIntoView` один раз).

Альтернатива — вкладки курсов внутри языка: возвращает ту же проблему переключателя из трёх и больше вариантов и противоречит брифу («полки одна под другой»).

### 5. Гамма — именованный набор в коде, поле `palette` в курсе

Набор гамм — в `src/content/palettes.ts` (его читают и сборка, и клиент, как `parseCourseChoice`): `school` — нынешние шесть цветов `COVERS`, гамма по умолчанию; `ink` и `coast` — по шесть новых цветов (`ink` — холодные чернильные: синие, сине-зелёные, графит; `coast` — тёплые: терракота, охра, оливковый, морская волна). Конкретные цвета подбираются при реализации с проверкой контраста тестом и показываются пользователю на скриншотах. `coverColor(number, palette = "school")` и `mutedCover(number, palette)` в `src/shared/notebook.ts` берут цвет из гаммы; лендинг вызывает без гаммы и не меняется.

Контент: `greek-a2` — без поля (гамма по умолчанию, файл не меняется), `english-it` — `palette: ink`, `english-travel` — `palette: coast`. Сборка (`content/build/courses.ts`) проверяет имя и уникальность гаммы в языке вместе с уникальностью `short`. Клиент: `palette` читается как поля выбора — неверное отбрасывается (`readCourseChoice`, `CHOICE_FIELDS`), в `db.courses` хранится как `short`.

Цвет — по гамме курса везде, где рисуется обложка его модуля: полка, экран модуля, путь «Прогресса», обложка урока на «Сегодня» (вопрос 12). Для этого обложке нужен курс модуля: `ModuleView.module.courseId` уже есть; гамма берётся из `CourseEntry` хуком `useCoursePalette(courseId)` рядом с `useCourseProfile`.

Почему поле, а не цвет по порядку курса в языке: решение пользователя «цвет курса не зависит от порядка» — порядок курсов разный на устройствах, где курсы начаты в разном порядке. Почему набор в коде, а не цвета в файле курса: контраст проверяется один раз тестом, и автор курса не может завести нечитаемую гамму.

### 6. `short` — имя в языке, до 20 символов, уникально в языке

`SHORT_MAX` = 20; сборка отклоняет одинаковый `short` у двух курсов одного языка (без учёта регистра). Контент: `english-it` — «Для IT», `english-travel` — «Для путешествий», `greek-a2` — «Греческий» (вопрос 7). Прежний клиент отбросит «Для путешествий» (15 > 14) и назовёт курс полным названием — так он и так называл бы курс без `short`.

Где какое имя (вопрос 6):

| Место | Имя |
| --- | --- |
| Заголовок полки, группа «Чтения», блок «Прогресса» | `short ?? title`, затем « · » и `level`, если он есть |
| Подпись строки и фильтр «Курс» в «Словах» | `short ?? title` |
| Переключатель | название языка |
| Выбор основного курса в настройках, доступное имя «⋯», строка статуса паузы | `title` |
| «Сегодня», список «Курсы» в настройках, стартовый экран | `title`, как сейчас |

Выбор основного курса с полными названиями: три варианта на 360 px не помещаются в строку и прокручиваются лентой, как переключатель трёх курсов сейчас; e2e «выбор основного из трёх курсов… на 360 px» проверяет, что имена не обрезаны.

### 7. «Слова» — словарь языка из словарей курсов

`languageDictionary(language)` в `src/storage/dictionary.ts` собирает `dictionary(courseId)` начатых курсов языка по порядку курсов и склеивает их без копирования уроков. Курс урока — поле `courseId` самого `DictionaryLesson`, которое заполняет `dictionary(courseId)` и сравнивает `sameLesson` (`src/storage/dictionary.ts:154-164`): копия урока с добавленным курсом сломала бы возврат тех же объектов (`shown`, `:126-133`) и перерисовывала бы все строки. Имя курса для подписи берётся на экране из `CourseEntry` по `courseId`. Карточка принадлежит одному курсу (требование «Карточки курса»), поэтому склейка без дублей. Уроки старых профилей без курса (`loose`) остаются у домашнего курса, как сейчас.

`Dictionary` в `WordsScreen.tsx`: при двух курсах и больше — подпись курса у строки (мелкий текст под переводом, не обрезается) и группа кнопок «Курс» рядом с группой «Состояние», параметр адреса `course` (как `filter`); с выбранным курсом подписи остаются — так строка в поиске не теряет курс. `EntryScreen` (лист слова на развороте) показывает словарь языка карточки. `filterDictionary` получает фильтр курса.

Альтернатива — группы по курсам с заголовком курса вместо подписи строки: при поиске и фильтре состояния группа курса превращалась бы в длинный заголовок над одной строкой; пользователь выбрал подпись у строки.

### 8. «Чтение» — группы курсов из `courseReadings`

`languageReadings(language)` возвращает `{ course, readings: CourseReadings }[]` начатых курсов языка (через `courseReadings`) и сумму `open`/`unread`/`pending`. `ReadingsScreen`: сводка по языку; при двух курсах и больше — секция курса с `h2` «<short> · <level>», внутри модули (`h3`) и строка закрытых текстов курса; курс без текстов (ни открытых, ни закрытых, ни ждущих) не показывается. При одном курсе — экран как сейчас. «Следующий текст» на экране текста остаётся в пределах курса (`nextUnreadReading(courseId, …)`). «Все тексты» на «Сегодня» уже вызывает `followCourse` — после решения 2 он выбирает язык.

### 9. «Прогресс» — сумма языка и блоки курсов

`courseProgress` по курсу не меняется, кроме выделения входа навыков (`skillInputs(courseId)`), чтобы сумма языка считала `skillProgress` по заданиям всех курсов сразу, а не усредняла доли. `languageProgress(now, tz, language)` возвращает `courses: CourseProgress[]` и `total: { skills, complete, week }`: `week.lessonDays` — объединение дней занятий курсов, `reviewDays`/`cards` — события повторения карточек языка (`cardsInCourse` по курсам языка). Слова и фразы — из `languageDictionary`, ошибки — сумма `mistakeCount` по курсам, проблемные карточки — фильтр `leeches` по картам курсов языка.

`ProgressScreen`: при двух курсах и больше — `h2` «Всего по английскому» (`names.by`) с навыками, карточками и итогом недели, затем секции курсов (`h2` «<short> · <level>»): строка паузы, путь (обложки в гамме курса), положение, темп, контрольные, навыки курса с его `passShare`. На развороте — слева сумма, справа курсы. При одном курсе — прежний экран, над путём `h2` курса. Порог 60 % на шкале не рисуется, но слабый навык выделяется по `passShare` курса (`css.weak`, `src/features/progress/ProgressScreen.tsx:148`); в сумме по языку выделения нет — у курсов разные пороги. `Skills` получает режим суммы с подписями «Навыки по языку», «Доля всех начатых курсов языка…», «% по языку»; `weekLine` — «занятий по курсам языка» (прежние тексты `:118`, `:136-139`, `:153` остаются в блоке курса).

### 10. Фикстура e2e — второй английский курс

## Risks / Trade-offs

- [Словарь и прогресс языка — вдвое больше работы на экран] → словарь уже кэширует строки (`rowCache`); бюджеты Lighthouse и `check:bundle` в полном наборе CI; если «Слова» замедлятся заметно — ленивый рендер групп уже есть (`containIntrinsicSize`).
- [e2e переписывается почти целиком — риск потерять проверку прежнего поведения] → каждый тест переводится по одному с тем же намерением (в задаче — список тестов), новые сценарии отдельными тестами; прогон `--repeat-each=5`.
- [«Сегодня» меняется цветом английских обложек, хотя шаг 1 обещал не менять «Сегодня»] → вынесено пользователю (вопрос 12); без гаммы на «Сегодня» модуль выглядел бы по-разному на разных экранах.
- [Выбор основного курса с полными названиями на 360 px прокручивается лентой] → так уже работает переключатель трёх курсов; альтернатива (список с радиокнопками) — отдельная правка настроек.
- [Миграция чтением держит прежние ключи бессрочно] → два коротких значения в `meta`; убрать их можно отдельной правкой после шага 2.
- [Сумма навыков по языку смешивает курсы разного уровня] → это доля верно выполненных заданий всех начатых курсов, без порога; по курсу — в его блоке.

## Migration Plan

Схема базы, снимок, формат облака и версия каталога не меняются; в каталоге появляется необязательное поле `palette`, `short` английских курсов меняется. Выбор языка выводится из прежних ключей до первого выбора (решение 2). Откат и прежние клиенты: прежняя версия читает свои ключи выбора курса и `palette` пропускает. `short` длиннее 14 символов («Для путешествий») она отбрасывает и показывает полное название, а `short: Для IT` (6 символов) принимает — в её переключателе курса до обновления будут «Греческий», «Для IT» и «Английский для путешествий и общения». Это видно только до обновления приложения; отдельной меры не нужно.
