# Proposal

## Why

Пользователь (11.10.2026) выбрал новый вид карточек повторения — ошибки урока (`mistake-cards`). Ему нужна основа: общий перечень видов карточек и формат облака, который не теряет карточки незнакомого вида. Основа была описана внутри изменения про правила; решение пользователя — «вынеси основу в отдельное изменение». Позже пользователь удалил изменение про правила (11.10.2026), основа осталась общей для будущих видов.

## What Changes

Требование пользователя: общая основа видов карточек — отдельное изменение, на которое опирается `mistake-cards`.

Предлагаемый объём:

- **Перечень видов карточек.** Описание вида — набор функций: содержимое по id, «есть на устройстве», «ссылки пакета», число карточек, курс и язык карточки, «можно спросить», подпись, сборка карточки занятия, выбор упражнения, код в облаке. Слова и фразы переводятся на перечень без изменений для учащегося.
- **Повторения, которые нельзя спросить, не занимают места в занятии** — для всех видов. Сейчас снятое из уроков слово со сроком навсегда занимает место.
- **BREAKING (облако):** формат облака 5. Ссылки на карточки незнакомого вида и ответы незнакомого типа упражнения больше не отбрасываются: состояние, навыки и статистика хранятся и публикуются дальше без изменений. Новый вид карточек после этого добавляется без нового формата. Устройство с прежней версией приложения видит «версия другого формата — обновите приложение» и данные не меняет.
- Резервная копия принимает строки незнакомого вида.
- Нового вида карточек и нового типа упражнения это изменение не вводит. Учащийся видит только просьбу обновить приложение на старых устройствах.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `learning-session`: недоступные карточки со сроком не попадают в повторения дня.
- `account-sync`: формат облака 5 с сохранением незнакомых видов и типов; резервная копия принимает строки незнакомого вида.
