# Proposal

## Why

Issue #160 (замер 13.10.2026, перепроверен 17.10.2026 на `main` после #151): стартовый граф — 595 789 байт без сжатия (предел `check:bundle` — 620 000), 202 122 байта gzip, 177 271 brotli; CSS на старте — 93 975 байт (19 085 gzip); precache — 87 файлов, 1 443 КиБ; пакеты курса — 6,4 МБ (1,43 МБ gzip, самый большой пакет 32 724 gzip), каталог — 71 252 (18 526 gzip); аудио — 4 640 mp3, 49 МБ, все 32 кбит/с моно, самый большой 186 624 байта.

Сейчас `check:bundle` меряет только несжатый стартовый граф и CSS лендинга. Сжатый вес, CSS приложения, precache, вес и время первого экрана, размер контента и отзывчивость во время установки курса не защищены: ухудшение заметят на устройстве, а не в PR. Лёгкий путь первого запуска и замена `cn` — вне задачи (остаток #151).

Решения пользователя: отдельных по этой задаче пока нет; в задаче `/feature-flow` указано расширять #151 (`check:bundle`, `docs/perf.md`) и #157 (шардированный CI), не дублируя их. Изменений поведения для учащегося нет: всё — инструменты сборки и CI.

## What Changes

Требование пользователя — пять пунктов issue #160. Предлагаемый объём:

- `check:bundle`: пределы gzip и brotli стартового JS, CSS первого экрана (сырой и gzip), суммарный размер precache и шрифтов в precache; сводка размеров в JSON; в PR — таблица «PR против `main`» в сводке задачи CI.
- Lighthouse в CI на mock-сборке: мобильный профиль, медиана трёх прогонов; LCP > 3 с — предупреждение, > 4 с — падение; TBT ≤ 200 мс; вес ≤ 450 КиБ; число и вес ленивых чанков, которые первый экран грузит сразу.
- Бюджеты контента в `npm run content` (на настоящем контенте, не на фикстурах): пакет ≤ 40 КБ gzip, каталог ≤ 25 КБ gzip, курс ≤ 1,6 МБ gzip, mp3 — битрейт ≤ 32 кбит/с и размер файла ≤ 250 КБ. Нарушение — ошибка сборки.
- Ночной Playwright-замер с CPU ×4 (отдельный workflow по расписанию и вручную): время установки курса, TBT во время установки, p98 задержки отклика во время урока ≤ 100 мс.
- Отчёт vitest: файлы дольше 10 с отмечаются предупреждением в логе и сводке CI-задач `unit`, `unit-heavy`.

Не входит: сжатие `cn`, разрезание Dexie/ts-fsrs, перекодирование аудио, правки продуктового кода, пороги на устройстве (только эмуляция), публикация отчётов вне CI.
