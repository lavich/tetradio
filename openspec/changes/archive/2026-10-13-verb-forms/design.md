## Context

- Формы карточки — свободная строка `forms` (`content/build/cards.ts:100`, `src/content/schema.ts:411`). У глаголов греческого курса формат единый: `аор. X; буд. θα Y[; повел. Z]`, у трёх глаголов без аориста — `прош. X; буд. θα Y` (είμαι, έχω, ξέρω). У английского — `прош. X, прич. Y`. У существительных — `мн. …`, у прилагательных — три рода без помет.
- Строка выводится как есть в трёх местах: `src/features/words/WordSheet.tsx` (лист слова), `src/features/course/Vocabulary.tsx` (слова урока), `src/features/course/WordTaps.tsx` (подсказка; карточки прошлых уроков приходят через `marks.cards` с тем же `forms`).
- Неизвестные поля слова старый клиент пропускает (`parseWord` берёт поля по одному), поэтому новое необязательное поле пакета не требует смены `SCHEMA_VERSION`. Но старая версия приложения (из кеша service worker) может поставить новый пакет без `paradigm` с уже новой ревизией слова; после обновления установка пропустила бы и пакет (та же версия, `src/content/install.ts:100`, `apply.ts:95`), и слово (та же ревизия, `apply.ts:58`). Тот же случай уже решён для записей текстов (`voicedOf`, `readingAudio`).

## Goals / Non-Goals

**Goals:** ряд основных форм в трёх местах; таблица настоящего и прошедшего по лицам на листе греческого глагола; верные таблицы для всех 158 глаголов с лицами (у безличных βρέχει, πρέπει, φυσάει, χιονίζει таблицы нет).

**Non-Goals:** упражнения на формы, повторение по формам, записи форм (озвучка — синтез устройства), будущее/повелительное по лицам, таблица для английского.

## Decisions

1. **Таблица — при сборке, а не на устройстве.** `content/build/paradigm.ts` (только греческий) строит `{ present: string[6], past: string[6] }` и кладёт в `PackageWord.paradigm` / `Word.paradigm` (поставляемое поле, `SHIPPED_FIELDS`). Сборка может отказать и показать все таблицы для вычитки; клиент только рисует. Альтернатива — считать в клиенте из `forms`: ошибку правил увидел бы учащийся, а не сборка.
2. **Явная таблица в карточке** — `paradigm: { present: [6], past: [6] }` в YAML слова — заменяет правила. Обязательна там, где правила не строят таблицу (λέω, τρώω, ακούω, είμαι, πίνω, καταπίνω), и там, где строят неверно (προτιμώ, συναντώ — `-ώ` первого типа; προσλαμβάνω — приращение внутри основы). Таблица есть у глагола с лицами: заглавная на `-ω/-ώ/-μαι` и в `forms` есть `аор.` или `прош.`; безличные (`-ει`) — без таблицы. Глагол с лицами, для которого правила не дают таблицу и явной нет, — ошибка сборки с именем файла. Явная таблица у не-греческого слова — ошибка сборки.
3. **Правила настоящего** по окончанию заглавной формы: `-ω` (μένω, μένεις…), `-άω` (μιλάω, μιλάς, μιλάει, μιλάμε, μιλάτε, μιλάνε), `-ώ` второго типа (μπορώ, μπορείς…; глаголы `-ώ` первого типа отличить по формам карточки нельзя — только явной таблицей), `-ομαι` (έρχομαι, έρχεσαι, έρχεται, ερχόμαστε, έρχεστε, έρχονται), `-άμαι` (κοιμάμαι… κοιμόμαστε, κοιμάστε, κοιμούνται), `-ούμαι`, `-ιέμαι`. Гласная перед `-ω` — только явно (λέω, ακούω, τρώω), кроме одиночной υ (λύω, απολύω, все `-εύω`).
4. Синизеза в аористе (ήπια, κατάπια): правила не строят, только явно.
5. **Правила прошедшего** из формы 1-го лица (`аор.`/`прош.`): окончания `-α, -ες, -ε, -αμε, -ατε, -αν`; в единственном и 3-м множественного ударение основы как в 1-м лице, в «мы/вы» — на третьем слоге с конца. Если основа аориста отличается от основы будущего только приращением (έμεινα / μείνω, ήξερα / ξέρω, απέλυσα / απολύσω, παρήγγειλα / παραγγείλω) и ударение уходит с приращения, «мы/вы» строятся от основы будущего (μείναμε, ξέραμε, απολύσαμε, παραγγείλαμε); иначе — от основы аориста (ήρθαμε, βρήκαμε, χαθήκαμε).
6. **Ряд и окончания — в клиенте**, `src/domain/verb-forms.ts`: `principalParts(headword, forms)` — пары «форма, подпись» из помет `аор./прош./буд./повел./прич.`; без глагольных помет — `null`, и строка выводится как раньше. `splitEnding(form, language)` — для греческого самое длинное подходящее личное окончание из списка, для английского — без выделения. Подписи: заглавная — «сейчас», `аор.`/`прош.` — «было», `буд.` — «будет», `повел.` — «делай», `прич.` — «причастие».
7. **Вид.** Ряд — формы через «→», подпись мелко под формой; в списке слов урока ряд без подписей (места мало). Таблица — `<details>` «Все формы» под рядом на листе слова, по умолчанию свёрнута; лица «я, ты, он/она, мы, вы, они». Окончание — полужирным цветом текста (`--foreground`): это печать учебника, а красная ручка `pen` по DESIGN.md — только ошибка ученика. Кнопка формы — с вертикальным полем 8 px для пальца, таблица — с прокруткой по ширине вместо выхода за лист на 360 px. Подсказка «нет голоса» — одна на лист: озвучку форм передаёт лист слова (`useSay`) или подсказка слова (её `result`).

8. **Переустановка без таблиц.** Каталог несёт `paradigms` — число слов с таблицей в пакете; установка ставит пакет заново, если у поставленного слов с таблицей меньше (`install.ts`, `applyPackage`), а слово той же ревизии переписывается, если в пакете у него таблица есть, а у поставленного нет (`applyCards`, `missing`).
9. **Отчёт для вычитки** — `PARADIGM_REPORT=1 node content/build.ts` печатает все таблицы; без флага — число таблиц.
10. **Озвучка формы** — `playText(form, undefined, profile)` (синтез устройства, как слово без записи); результат `none` — строка `noVoice` под формами. Формы в списке слов урока не кнопки: строка — уже кнопка «Произнести», вложенная кнопка недопустима.

## Risks / Trade-offs

- Ошибка правил даст неверную форму на листе слова → все таблицы выводятся отчётом (`PARADIGM_REPORT=1`) и вычитываются (агент-ревьюер со знанием греческого) до мержа; спорные — явной таблицей; тест закрепляет образцы каждого класса.
- Вариативные формы (μιλάνε/μιλούν, ήμουν/ήμουνα) — показывается одна, более частая.
- Ряд длиннее строки: в узкой подсказке переносится по формам целиком.

## Реализация

- Окончание выделяется только из окончаний своего места: лица и времени в таблице, «сейчас/будет» — 1-го лица настоящего, «было» — 1-го лица прошедшего, повелительное — своих (`ENDINGS` в `src/domain/verb-forms.ts`). У неправильных форм (είμαστε, ήμουν) выделения нет: общий список окончаний выделял бы в είμαστε «-αστε».
- E2e — на είμαι демо-курса (явная таблица): правильный глагол в демо-курс не добавлен, чтобы не менять состав урока для остальных e2e; правила проверены модульными тестами и сборкой курса.
