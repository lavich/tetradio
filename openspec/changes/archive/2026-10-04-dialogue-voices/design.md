# Design

## Сервис синтеза

| | Google Cloud TTS, Chirp 3 HD | Azure Neural TTS |
|---|---|---|
| Греческие голоса | 30 (14 женских, 16 мужских) | 2: Athina (ж), Nestoras (м) |
| Хватит ли на диалог из 5–6 человек | да | нет |

**Решение (принято после прослушивания): Google Cloud Text-to-Speech, голоса Chirp 3 HD**, `languageCode: el-GR`, имя голоса `el-GR-Chirp3-HD-<Голос>`. Azure с двумя греческими голосами диалог из 5–6 человек не различит.

Пулы голосов, выбранные на прослушивании:

- женские (13): Aoede, Callirrhoe, Achernar, Autonoe, Despina, Erinome, Gacrux, Kore, Laomedeia, Leda, Sulafat, Vindemiatrix, Zephyr (Pulcherrima отклонён);
- мужские (14): Algenib, Algieba, Alnilam, Charon, Enceladus, Fenrir, Iapetus, Puck, Rasalgethi, Sadachbia, Sadaltager, Schedar, Umbriel, Zubenelgenubi (Achird и Orus отклонены).

Цены и условия использования синтезированного звука сверяются перед озвучкой всего курса и записаны в `docs/voices.md`.

## Формат файла

**MP3 прямо из API** (`audioEncoding: MP3`), без перекодирования: играет везде, включая старые WebView. API отдаёт моно 24 кГц 32 кбит/с (~4 КБ в секунду); `sampleRateHertz` размер не уменьшает — битрейт тот же, поэтому параметры по умолчанию. Модуль 01: 20 реплик, 646 символов, 216 КБ — на весь курс (~44,5 тыс. символов) выходит ~15 МБ.

## Файл на реплику, а не на диалог

- Подсветка текущей реплики работает без разметки по времени.
- Исправленную реплику переозвучиваем отдельно; версия файла (хэш в имени) меняется только у неё — после #66 устройство перекачивает именно её.
- Повтор отдельной реплики в будущем не требует нарезки.

Минус — больше запросов при первом проигрывании (до ~15 файлов на диалог); проигрыватель докачивает следующую реплику, пока звучит текущая.

## Голоса персонажей

`content/voices.yaml`: у каждого из 78 персонажей курса явно записаны пол и голос (`Δέσποινα: { gender: female, voice: Kore }`), там же пулы, источник записи (`Синтез речи Google Cloud TTS, голос Chirp 3 HD {voice}`) и голос диктора (`narrator`) для реплики без говорящего.

- Пол — по окончанию имени: -ος, -ης, -ας, -ής, -άς, -ός, -ων — мужской, остальные — женский; роль «Υπάλληλος» — мужская. Исключение по смыслу: Ραφαήλ — мужское имя. У «Κύριος …»/«Κυρία …» пол по обращению.
- Самые частые персонажи получили голоса вручную и не повторяются: 13 женщин (Δέσποινα, Μαρίνα, Ελένη, Κατερίνα, Ευτυχία, Ιρίνα, Ταμάρα, Σοφία, Χρυσταλλένη, Άννα, Ρένα, Ευαγγελία, Χαραλαμπία) и 14 мужчин (Πέτρος, Γιώργος, Στέλιος, Μάριος, Κώστας, Μιχάλης, Λάμπρος, Σωτήρης, Σταύρος, Φοίβος, Σάββας, Άρης, Υπάλληλος и Αντρέας). Пара из диалога модуля 01 «Στο πάρτι», одобренная на прослушивании, сохранена: Αντρέας — Charon, Μαρίνα — Aoede.
- Остальным голос дан детерминированно: старт в пуле своего пола по хэшу имени, первый голос, не занятый собеседниками в общих диалогах.
- Сборка падает, если у говорящего нет голоса, голос не из пула его пола или двое в одном диалоге звучат одним голосом (сейчас в диалоге до 6 говорящих: до 3 женщин и до 4 мужчин).

## Скрипт озвучки

`GOOGLE_TTS_KEY=… npm run voices -- m02-1 m02-2` (`scripts/voice-dialogues.ts`; без уроков — весь курс) — для реплик без файла или с изменившимся текстом либо голосом синтезирует MP3 через REST `text:synthesize` в `content/audio/<урок>/<блок>-<n>.mp3` и дописывает в реплику `audio: <урок>/<блок>-<n>.mp3` правкой текста (остальной YAML и комментарии не трогаются). `content/audio/dialogues.json` хранит голос и хэш (текст + голос) каждого файла: неизменённые реплики не синтезируются заново. `--check` — только отчёт о недостающих и устаревших репликах, без ключа и без сети. Ключ берётся только из переменной окружения и уходит в заголовке запроса: ни в файлы, ни в вывод он не попадает. Файлы коммитятся в репозиторий.

## Сборка и формат пакета

- Реплика с `audio` → медиа пакета `line-<урок>-<блок>-<n>`, адрес с версией по содержимому (`content/media/line-…@<хэш>.mp3`), источник — из `voices.yaml` с именем голоса. Без карты голосов или без источника запись реплики отклоняется.
- Запись, сделанная для другого текста или голоса (хэш в манифесте не совпал), не публикуется: реплика звучит синтезом устройства. Сборка не падает на неозвученных репликах, а печатает сводку «без записи N реплик в M уроках (устарело K)».
- **Схема остаётся 4.** Прежний читатель отклоняет неизвестное поле реплики и блока, но не пакета, поэтому записи едут отдельным полем пакета `lineAudio: { <блок>: [<медиа> | null, …] }` — как `marks`. Разбор пакета проверяет длину и ссылки на медиа и кладёт запись в реплику (`TranscriptLine.audioAssetId`): дальше приложение видит её в блоке. Поднятие версии схемы отрезало бы старым клиентам весь каталог ради необязательного звука.

## Воспроизведение

`playDialogue` по каждой реплике: есть файл → адрес из источника медиа (`ensureAsset`, в просмотре — прямой адрес пакета) и `<audio>` с `playbackRate` 0,8 в медленном режиме (обычный — 1); файла нет или он не скачался → системный голос (`castOf`, как сейчас). Пока звучит реплика, запись следующей уже скачивается. Все реплики играет один элемент `<audio>`, которого коснулись в жесте нажатия: iOS иначе не разрешит звук файлу, пришедшему из базы после жеста. Отказ воспроизведения файла — ошибка, а не тихая подмена голосом. Лимит прослушиваний, подсветка реплики и открытие транскрипта не меняются.

## Уборка медиа

После установки или обновления пакета (у курса — один раз после всех уроков) удаляются записи `db.assets` и ссылки `db.media`, на которые не ссылается ни один установленный пакет. Иначе каждая переозвучка оставляет копию на устройстве.

## Спецификация

Требование «Полноценные учебные модули» меняется: звук аудирования — записи реплик с источником, синтез устройства — запасной путь.
