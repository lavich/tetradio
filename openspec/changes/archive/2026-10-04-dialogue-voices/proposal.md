# Proposal

## Why

Аудирование — один из четырёх навыков экзамена ΚΕΓ A2, и на экзамене говорящих в диалоге легко различить по голосу. Сейчас реплики звучат синтезом речи устройства. На macOS, iOS и iPadOS греческий голос один (Melina), на Android в Chrome обычно тоже один, поэтому все персонажи говорят одним голосом и различаются только высотой тона — на слух почти никак (issue #58). Web Speech API не даёт ни выбора голоса на Apple-устройствах, ни пола голоса.

## What Changes

- **Записи реплик.** Реплики диалогов аудирования заранее озвучиваются облачным синтезом при подготовке контента и поставляются как медиа урока: отдельный файл на реплику, MP3 моно 32 кбит/с (Google Cloud TTS, голоса Chirp 3 HD).
- **Голос персонажа.** Каждый персонаж курса звучит одним и тем же голосом во всех уроках; говорящие одного диалога различаются голосом.
- **Воспроизведение.** Проигрыватель сначала играет файл реплики, при его отсутствии (не скачан и нет сети, не озвучена) — системный голос, как сейчас. Медленный режим — `playbackRate`, без второго набора файлов. Подсветка реплики работает как сейчас.
- **Источник.** У записи указан источник: «синтез речи <сервис>, голос <имя>»; сборка проверяет, что у каждого файла реплики он есть.
- **Уборка.** Файлы, которые установленные пакеты больше не упоминают, удаляются с устройства.

Объём: 69 диалогов, 751 реплика, ~44,5 тыс. символов; ~50–60 минут звука; ~15 МБ на курс. Первый запуск не тяжелеет: медиа скачивается при первом проигрывании.

## Capabilities

### Modified Capabilities

- `course-content`: звук аудирования — записанные синтезом реплики с указанным источником, синтез устройства — запасной путь.

## Impact

`content/lessons/*.yaml` (поле файла у реплики), `content/build/*` (медиа реплик, проверка источника), новый скрипт озвучки `scripts/voice-dialogues.ts` и карта голосов `content/voices.yaml`, `src/content/schema.ts` и `course.ts` (схема реплики), `src/shared/dialogue.ts` и `audio.ts` (воспроизведение файла), `src/content/media.ts` (уборка), `src/features/course/blocks/Listening.tsx`; тесты сборки, воспроизведения и e2e аудирования.
