# Design

## Context

Пакет поставляется на урок. Необязательные поля верхнего уровня (`marks`, `lineAudio`) уже добавлялись без смены версии схемы. `parsePackage` собирает пакет по известным полям (`src/content/schema.ts:523-552`), а запись `InstalledPackage` собирается явно (`src/content/apply.ts:115-130`): новое поле прежний клиент не видит, а новому нужно явно его сохранить. Версия пакета — хеш содержимого (`content/build/output.ts:23`), поэтому правка текста переустанавливает пакет урока целиком.

Слова по нажатию работают по `marks`: сборщик размечает греческий текст блоков карточками этого и прошлых уроков (`content/marks.ts`). Сопоставление намеренно осторожное: не найти форму лучше, чем привязать чужое слово. `parseMarks` отклоняет `marks.blocks` с id, которых нет среди блоков урока (`schema.ts:618-620`). `marks.cards` несут написание, транскрипцию и перевод карточек прошлых уроков (`schema.ts:592-602`), аудио в них нет.

Пилот (`pilot-texts.yaml`, поле `expected`) показал:
- Строгое сопоставление сборщика занижает знакомость: тексту «Анна» оно дало 93,7 %, мягкий подсчёт — 97,7 %. Падежные и личные формы (Κύπρο, δουλεύει, έχουν), слова из фраз (σημαίνει, χάρηκα) и числа из объяснений строгое сопоставление не находит.
- «Мария» (93,2 %) и «Στο μάθημα» (87,4 %, глоссы 8,6 %) порог 95 % не проходят.
- Основа из 4 букв принимает чужие слова с общей приставкой: через καταλαβαίνω (m02-1) знакомыми стали бы κατάστημα и καταστροφή, через παρακαλώ (m01-1) — παραλία и παράθυρο.

Синхронизация переносит `blocks[]` и для уроков, не установленных на устройстве (`docs/sync.md`). Восстановление копии отклоняет строку блока, чей урок не найден ни в копии, ни в каталоге (`src/features/backup/course-check.ts:81-87`).

## Goals / Non-Goals

**Goals:**
- Беглое чтение: много понятного текста без заданий.
- Автор (агент) не может опубликовать текст, который слишком труден для этого места курса.

**Non-Goals:**
- Задания и оценка к текстам. Шкала навыка «Чтение» в «Прогрессе» считает только задания уроков.
- Записанное аудио текстов: только синтез устройства.
- Генерация текстов в приложении: тексты готовятся заранее и проходят сборку.
- Тексты модулей 4–24.

## Decisions

### Источник: `content/readings/<курс>/<id>.yaml`

```yaml
id: r-m03-anna
title: Η Άννα στη Λεμεσό
after: m03-2            # урок, после прохождения которого текст открыт; задаёт и словарь проверки
series: anna            # необязательно: тексты одной серии идут по порядку
text: |-
  Γεια σας! Με λένε Άννα. …
glosses: [{ text: σπίτι, russian: дом }]
names: [Άννα, Αντρέι, Μόσχα]   # имена собственные не считаются незнакомыми
provenance: { operation: requested-generation, request: "…", review: none }   # none | author | native
```

Идентификатор `r-…` постоянный: это ключ прогресса. Префикс `r-` зарезервирован за текстами: id уроков с него не начинаются, сборка это проверяет. Текст с `review` не `native` (`none` или `author`) показывается с пометкой «Сгенерированный текст, носитель не вычитывал»: автор курса — учащийся A2, и его вычитка носителя не заменяет.

### Доставка: поле `readings` в пакете урока `after`

Пакет урока `after` получает необязательный список `readings`: каждый текст несёт свою разметку `marks` внутри `readings[i]`. В общий `pack.marks` её класть нельзя, там `parseMarks` отклонит незнакомый id блока. Поле не меняет схему пакета: пакет остаётся в текущей схеме (4), и клиент, знающий эту схему, но не `readings`, ставит урок как раньше.

Текст открыт, когда урок `after` **пройден**. Проверка знакомости включает слова урока `after`, а к первому выполненному заданию они ещё не введены в повторение. Пройденный урок означает, что учащийся видел и отработал все его слова.

Нажатие на слово показывает подсказку из `marks.cards` текста. Устанавливать прошлые уроки для этого не нужно. Аудио в `MarkCard` нет, поэтому слово озвучивается синтезом устройства.

Отвергнуто:
- отдельные пакеты текстов — это новый вид пакета в каталоге, установке и догрузке ради нескольких килобайт;
- открытие после начала урока — тогда текст опирался бы на слова, которые учащийся ещё не прошёл.

### Мягкий подсчёт знакомых слов в сборке

Отдельная функция рядом с `marks.ts`, разметку для нажатий она не трогает. Слово считается знакомым, если это:
1. найдено строгим сопоставлением (карточки уроков курса до `after` включительно);
2. служебное слово из списка грамматики (артикли, слитные предлоги, местоимения-энклитики, να, θα);
3. имя из `names`;
4. токен любой карточки, формы или фразы этих уроков либо глоссы этих уроков (без ударений и регистра);
5. совпадение основы: общее начало не короче 5 букв (без ударений и регистра) с карточкой этих уроков. Совпадение не засчитывается, если общая часть сводится к приставке из стоп-списка: παρα-, κατα-, μετα-, συν-/συγ-/συμ-, προ-, απο-, επι-, δια-, υπο-, ανα-, εκ-/εξ-.

Глоссы текста считаются отдельно. Пороги:
- знакомо без глосс текста меньше 95 % — текст отклоняется;
- глоссы больше 4 % слов — предупреждение;
- имена больше 10 % слов — предупреждение (имена поднимают долю знакомых, в «Марии» их 10,5 %).

Сборщик печатает доли (знакомые, глоссы, имена) и слова, которые не нашлись.

Пилотные тексты — регрессионная фикстура подсчёта: доли в `expected` пересчитываются реализованным алгоритмом. «Анна» проходит порог, «Мария» и «Στο μάθημα» не проходят, пока их не перепишут. Слово с ложной основой (κατάστημα при знакомом καταλαβαίνω) считается незнакомым.

Отвергнуто: ослабить сам `marks`. Тогда нажатие на слово показывало бы неверный перевод.

### Коридор длины

| Модули | Слов |
| --- | --- |
| 01–04 | 120–250 |
| 05–10 | 180–350 |
| 11–17 | 250–450 |
| 18–24 | 350–600 |

Выход за коридор — предупреждение, не отказ: короткий текст тоже бывает уместен.

### Прогресс «Прочитано»: строка `blockProgress`

Ключ — `<id текста>/read`, `done: true`. Он совместим с `blockKey` (`src/storage/course.ts:14`). Снять отметку — `done: false`. Синхронизация переносит строку как блок неустановленного урока, новый формат не нужен.

Строки текстов не учитывают:
- план и «начатый урок» (`studiedLessons`, `src/storage/queries.ts:57-60`);
- шкалы и путь в «Прогрессе» (`src/storage/progress.ts:44`).

Это проверено по коду. Ещё два места их учитывают, и их нужно исправить:
- `describeSnapshot` считает их «выполненными заданиями» в диалоге конфликта (`src/sync/snapshot.ts:326`);
- `lessonDays` без `courseId` засчитывает день чтения как учебный (`src/storage/course.ts:226-240`).

Чтение днём занятий не считается.

Восстановление копии принимает строки блоков с префиксом `r-`: это отметки текстов, урока для них нет.

Отвергнуто: новое поле в снимке. Это смена формата облака ради одного флага.

### Экран текста

Страница тетради (сетка там, где учащийся работает с языком):
- наверху название, число слов и пометка вычитки;
- ниже текст с нажатиями и глоссами в подсказке;
- кнопка «Слушать» читает весь текст синтезом в медленном и обычном темпе, как аудирование. Чтение идёт по предложениям, как реплики в `dialogue.ts`, а не одним высказыванием (`src/shared/audio.ts:97-111`): длинное высказывание синтез может оборвать без ошибки;
- в конце кнопка «Прочитано», после отметки — «Следующий текст», «К модулю» и «Снять отметку».

Нажатия и кнопки доступны с клавиатуры и экранной читалке.

### «Сегодня»

После строки занятия с карточками — одна строка «Почитать: <название>, N слов». Это первый открытый непрочитанный текст текущего курса в порядке программы. Строки нет, если таких текстов нет. При двух курсах строка относится только к курсу «Сегодня», у второго курса её нет. Счётчиков, серий и наград нет.

## Реализация

- Подсчёт — `content/coverage.ts`, проверка и разметка — `content/build/readings.ts`. Глосса не делает слово знакомым и не мешает ему быть знакомым: слово с глоссой, знакомое по основе, считается знакомым, поэтому удаление глосс долю не меняет. Пилотные доли пересчитаны этим алгоритмом (`pilot-texts.yaml`, тест `tests/reading-coverage.test.ts`).
- Основа засчитывается при общем начале не короче пяти букв и не короче приставки из стоп-списка плюс три буквы.
- Пилот: шесть текстов серии «Анна» — два после уроков m01, один после m02-3, три после m03-3 («Анна» из пилота, «Мария» и «Στο μάθημα» переписаны и проходят порог). Все с `review: none` до вычитки.
- Каталог несёт число текстов урока (`readings`): пакет той же версии, поставленный сборкой без поддержки текстов (WebView проснулся на старой сборке), ставится заново.
- Глосса должна стоять в тексте как есть (NFC), глоссой считаются только слова внутри её вхождений; лишние поля и `names` не списком отклоняются.
- Тексты — только у греческого курса из модулей: служебные слова и приставки подсчёта греческие, полка живёт в модуле. Сравнение без ударений намеренно мягкое (πότε и ποτέ совпадают).
- Экран текста — `src/features/course/ReadingScreen.tsx`, адрес `/course/<модуль>/read/<текст>`; «Слушать» — `playDialogue` по предложениям (`src/domain/sentences.ts`).

## Risks / Trade-offs

- [Ошибки греческого в сгенерированном тексте запоминаются] → пометка у любого текста без вычитки носителем; вычитка автором перед публикацией (`review: author`); носителем — когда будет возможность. Тексты с ошибками исправляются без смены id.
- [Чтение отнимает время у повторения] → полка необязательна. «Сегодня» показывает текст после карточек, а не вместо них.
- [Мягкий подсчёт пропускает трудный текст] → основа не короче 5 букв со стоп-списком приставок, предупреждения о глоссах и именах, список ненайденных слов в отчёте сборки. Автор читает отчёт.
- [Уже выпущенные клиенты получат строку `<текст>/read` синхронизацией и не восстановят собственную копию — их проверка считает её ссылкой на неизвестный урок] → исправить уже выпущенный код нельзя. После обновления копия восстанавливается. Сообщение старого клиента предлагает открыть «Курс» и повторить; это не поможет, но данные не меняются.
- [Слишком похожие тексты одной серии] → поручение генерации задаёт сюжет каждого текста, в отчёте пилота сравниваются темы.

## Migration Plan

Клиент и контент выходят вместе. Прежний клиент поле `readings` не видит, а строки `<текст>/read`, пришедшие синхронизацией, хранит и публикует как блоки неустановленного урока (восстановление копии с ними на нём не проходит, см. Risks). Откат — убрать `readings` из пакетов.
