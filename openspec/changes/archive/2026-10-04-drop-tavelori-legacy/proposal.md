# Proposal

## Why

Τετράδιο вырос из Tavelori: свои наборы слов, правка и удаление карточек, расписание занятий, уроки без модулей, курс «Мои слова». Интерфейс этого больше не показывает (свой контент убран 01.10.2026, путь без модулей и расписание — 03.10.2026), но код по-прежнему выполняется и местами ломает поведение. Техническое ревью 04.10.2026 нашло:

- **Ошибки:** слова, убранные из урока обновлением контента, попадают в новые карточки через курс «Мои слова»; сохранённые даты расписания заставляют план вводить карточки непройденных уроков.
- **Лишняя работа на устройстве:** «Сегодня» перед первым кадром делает ~600 запросов к базе ради проверки «есть ли уроки»; каждый запуск и каждый час — пустое «закрепление» уроков по расписанию в транзакции на 6 таблиц; каждая публикация читает все пакеты целиком.
- **Синхронизация:** каждый ответ публикует весь снимок (~100 записей в облако); ключи «умерших» устройств не удаляются и со временем упрутся в предел Telegram.
- **Объём:** около 2 000 строк кода и 3 000 строк тестов обслуживают то, чего в продукте нет: миграции базы с версии 1 (баз Τετράδιο ниже v7 не было), слияние правок карточек, форматы облака 1–2 и пакетов 2–3, планировщик сроков.

## What Changes

- **План дня по курсу.** Новые карточки — из пройденных уроков в порядке программы, не больше дневного предела; повторения — по сроку FSRS. Без расписания, сроков, «подготовки к занятию», бэклога и курса «Мои слова».
- **Модель данных курса.** Курс — данные каталога и экзамен плюс дневной предел новых; урок — пройден или нет. Без `schedule`, `targetDate`, `subscribed`, `origin`, `LOCAL_COURSE`.
- **Карточки только из пакетов.** Установка пакета перезаписывает поля карточек; без правок, удаления, конфликтов слияния, деления на «стандартные» и «свои».
- **База v9.** Одна миграция из v8: удаляет пустые таблицы Tavelori и лишние поля, сохраняя прогресс (состояния FSRS, ответы, навыки, задания уроков, настройки). Код миграций v1–v7 удаляется; копии данных принимаются начиная с v8.
- **Облако.** Формат 4 без полей расписания; читаются форматы 3 и 4, 1–2 — нет. Публикация — по окончании занятия и при сворачивании, а не после каждого ответа. Ключи чужих устройств, полностью вошедших в принятую версию и старше 30 дней, удаляются.
- **Пакеты контента** — только схема 4.
- **Документация** синхронизации переезжает из `docs/tavelori/` в `docs/sync.md` и описывает формат 4.

Прогресс пользователя сохраняется; сброс базы и облака не требуется. Механика упражнений, FSRS, курс, словарь и «Прогресс» не меняются.

## Capabilities

### Modified Capabilities

- `learning-session`: план дня строится по пройденным урокам курса, а не по расписанию занятий.
- `account-sync`: формат облака 4, публикация реже, уборка ключей других устройств.

## Impact

`src/domain/learning.ts`, `schedule.ts` (удаление), `types.ts`; `src/storage/db.ts`, `queries.ts`, `ops.ts`, `course.ts`, `dictionary.ts`; `src/content/client.ts`, `schema.ts`; `src/sync/*`; `src/features/backup/*`, `today`, `more`; `src/app/settle-watch.tsx` (удаление); тесты `plan*`, `schedule`, `migration*`, `sync-*`, `backup-*`, e2e-хелпер `useSchedule`. `docs/tavelori/telegram*.md` → `docs/sync.md`.
