# Design

## Профиль языка

`src/domain/language/` — `LanguageProfile` и два профиля, `el` и `en`; `profileOf(language)` по коду из каталога (`CourseCatalog.language`, уже есть в схеме). Неизвестный язык — ошибка сборки, клиент такой курс не устанавливает.

| Поле профиля | `el` (как сейчас) | `en` |
|---|---|---|
| `locale`, `lang` | `el`, `el-GR` | `en`, `en-GB` |
| `lower(text)` | `toLocaleLowerCase("el")`, `ς→σ` | `toLocaleLowerCase("en")` |
| `script` | `\p{Script=Greek}` | `\p{Script=Latin}` |
| `ending` (необязательный знак в конце ответа) | `.!;;?…` | `.!?…` |
| `answer` — что значит «почти» | разница только в ударении (U+0301); артикль и ударение | `’`/`'` и сокращения (`don't` = `do not`) — верно; одна буква на слове от 5 букв — «Почти! Проверь написание.» |
| `articles` | ο, η, το, οι, τα | a, an, the |
| `syllables` | греческие слоги, сборка из слогов, ударение на карточке | нет: сборка из слогов не предлагается, строки ударения нет |
| `morphology` (подсветка форм в тексте) | нынешние `inflect`/`conjugate` | `-s/-es`, `-ed`, `-ing`, `-er/-est` + неправильные формы из `forms` карточки |
| `names` в текстах | «греческий», «по-гречески», «по греческому» | «английский», «по-английски», «по английскому» |
| `letters` вариантов ответа | α β γ δ (`lower-greek`) | a b c d (`lower-latin`) |
| `date` на странице | `el-GR`, заглавные | `en-GB` |

`normalize()` из `refs.ts` и прочие `toLocaleLowerCase("el")` (ключи в базе, разбор ошибки, варианты ответа) не меняются: на латинице правила `el` и `en` дают одно и то же, поэтому миграции базы нет.

«Почти» для фразы и слова: в английском сокращения и `’` приводятся к полной форме до сравнения; опечатка — одна буква в одном слове от пяти букв (в коротком слове это уже другое слово). Знак в конце ответа необязателен и для ответа-слова, как с #86 для фразы.

## Где язык берётся в клиенте

- Урок, модуль, словарь урока — язык своего курса (`useCourseLanguage(courseId)`), `lang` — из профиля.
- Карточка вне урока (повторение, словарь, лист слова) — язык по письменности текста (`languageOfText`): у греческого и английского письменности разные. Курс у карточки (по `items` уроков) понадобится изменению «два курса» и любому второму курсу на той же письменности.
- Голос синтеза: по языку профиля вместо `greekVoice()`. Занятие получает `hasVoice` функцией языка: упражнение карточки — по её языку, план (фразы без перевода) — «есть голос хоть одного языка».

## Данные курса вместо констант

`content/courses/<курс>.yaml` получает `start` (дата начала, сейчас `COURSE_START`), `checkpoints` (метка, название, после модуля, дата — сейчас `CHECKPOINTS`) и `passShare` (сейчас `PASS_SHARE = 0.6`; поле курса, а не `exam`: клиент до этого изменения строго разбирает `exam` и не загрузил бы каталог). Каталог передаёт их в клиент; `coursePace`, полка, модуль и прогресс читают их из курса. Тексты ΚΕΓ («дата на Кипре не подтверждена», «по итогам M3») — из данных экзамена курса.

## Сборка

- `LANGUAGE = "el"` в `content/build/common.ts` — только значение по умолчанию для курса без `language`.
- Проверки текста по письменности профиля: «нет греческих букв» → «нет букв языка курса»; смешение письменностей — любая чужая для курса и кириллицы письменность.
- `content/marks.ts`: токенизатор и формы — из профиля.
- Голоса: `content/voices.yaml` → `content/voices/el.yaml`, у английского — `content/voices/en.yaml`; `npm run voices` берёт файл по языку курса урока.
- `scripts/check-lexicon.ts` и `lexicon-*` остаются греческими (лексикон греческого курса); для английского — позже, вместе с контентом.

## Риски

- Тихая деградация вместо ошибки: при английском тексте прежний код находил бы «один слог» и «нет ударения». Тест профиля `en` проверяет, что сборка из слогов не предлагается и строки ударения нет.
- Хэш ревизии пакета (`SHIPPED_FIELDS`) не меняется: поля карточек прежние, новые поля — у курса.

- Календарь и порог приходят с каталогом: до первой удачной загрузки каталога после обновления их у курса нет (темп без плана, итог контрольной без «сдано»). Каталог в предкэше той же сборки и загружается при каждом запуске, поэтому окно — только при сбое этой загрузки.
- Экраны прогресса, полки и «Сегодня» берут курс по первому модулю (`views[0]`): верно, пока курс один; выбор курса — изменение «два курса».

## Проверка

- Все существующие unit- и e2e-тесты проходят без изменения ожиданий для греческого.
- Новые: тесты профиля `en` (ответы, апострофы, сокращения, опечатка, отсутствие слогов), подсветка английских форм, сборка фикстуры английского курса из одного урока, `coursePace` с точками из данных курса.
