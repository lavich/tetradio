# Proposal

## Why

Пользователь (11.10.2026) о шести пилотных текстах полки «Чтение»: «Тексты мне нравятся, надо нагенерировать для других уроков, а также добавить им звуковое озвучку нормальную, правильную, корректную». Сейчас тексты есть только у модулей 1–3, а «Слушать» читает их синтезом речи устройства: голос зависит от телефона, на части устройств греческого голоса нет вовсе.

Решения пользователя (11.10.2026): два текста на модуль; реплики — голосами персонажей, как в аудировании; поставка блоками по 4–6 модулей; повествование — голосом рассказчика текста (герой, если текст от его лица, иначе чтец), цитаты в повествовании читает рассказчик, живая речь в новых текстах — строками «—». Шесть пилотных текстов одобрены.

## What Changes

Требования пользователя: тексты для модулей 4–24, по два на модуль; озвучка записями, реплики — голосами персонажей.

Предлагаемый объём:

- **Говорящие в тексте.** У текста необязательный список `speakers`: по одному имени на каждую строку диалога (строка, начинающаяся с «—»), по порядку; пустое имя — реплика без говорящего. Остальной текст читает рассказчик.
- **Рассказчик текста** — поле `narrator` текста (персонаж, от лица которого рассказ), иначе чтец — новое поле `reader` в карте голосов языка (`content/voices/el.yaml`). Диктор карты `narrator` (слова и фразы) остаётся как есть: у него голос Μαρία.
- Цитаты в пилотных текстах («Η Μαρία λέει: «…»») переписываются строками «—», чтобы звучать голосом героя.
- **Записи по предложениям.** Файл на предложение: `content/audio/readings/<текст>/<n>.mp3`, голос — говорящего строки или чтеца. `npm run voices -- readings` озвучивает новые и изменившиеся предложения; манифест хранит голос и хэш, как у реплик аудирования. Запись, сделанная до правки предложения или смены голоса, не публикуется — предложение звучит синтезом, пока его не переозвучат.
- **«Слушать»** проигрывает записи по предложениям; предложение без записи звучит синтезом устройства. Медленный режим — тот же файл в темпе 0,8.
- **Новые голоса** персонажей серии (Χριστίνα, Τζον, Όλγα, Αντρέι и следующие) — в карте голосов по её правилам; пол Τζον и Αντρέι — явно, правило окончаний им не подходит.
- **Каталог** сообщает, что тексты урока озвучены: пакет, поставленный версией без записей, ставится заново (как счётчик `readings`).
- **Контент блоками:** m04–m08 (до K1), m09–m15, m16–m20, m21–m24 — по два текста на модуль серии «Анна», каждый блок — отдельный PR с озвучкой. Шесть пилотных текстов получают `review: author` и озвучку в первом блоке.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `course-content`: озвучка текстов для чтения (говорящие, голос чтеца, записи по предложениям); тексты по всему курсу.
- `app-sections`: «Слушать» на экране текста проигрывает записи.

## Impact

- **Зависит от `reading-shelf`** (в `main`, не архивирован): требования этого изменения добавляются рядом с его требованиями; архивировать после него.
- Сборка: `content/build/readings.ts` (говорящие, записи, медиа пакета), `content/build/voices.ts` (`reader`, проверка голосов текста), `content/build/sources.ts` (`speakers`); `src/content/schema.ts` (`PackageReading.audio`), `src/domain/sentences.ts` (общее разбиение для сборки и клиента).
- Озвучка: `scripts/voice-dialogues.ts` (цель `readings`), `content/voices/el.yaml` (`reader`, новые персонажи), `content/audio/readings/`, `content/audio/dialogues.json`.
- Клиент: `src/features/course/ReadingScreen.tsx` (записи в `playDialogue`, источник медиа), `src/storage/readings.ts` (медиа текста).
- Контент: `content/readings/greek-a2/` (42 новых текста, `speakers` у пилотных), `docs/voices.md`, `docs/course/format.md`, `docs/lesson-authoring.md`, навык `prepare-lesson`.
