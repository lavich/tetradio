# Design

## Карточки по курсам

- Папки: `content/words/<courseId>/*.yaml`, `content/phrases/<courseId>/*.yaml`. Курс карточки — папка. Карточка в корне `words/` — ошибка сборки («карточка вне курса»).
- Идентификатор (`id` или имя файла) уникален во всём контенте: повтор между курсами — ошибка с обоими путями. Греческие `w…`/`p…` не меняются.
- Урок ссылается только на карточки своего курса: чужая — ошибка «карточка w012 из курса english-b2 в уроке greek-a2».
- Язык карточки для проверок сборки (письменность, подсветка) — язык курса её папки; `cardLanguagesOf` из шага 1 больше не нужен.
- Лексикон: `docs/course/lexicon/` остаётся греческим; `scripts/lexicon-*` и `check-lexicon.ts` читают `content/words/greek-a2/`.

## Курс карточки в приложении

- `courseOfCards(unitKeys)` — по `lessonItems` (индекс `unitKey`) → урок → `lessons.courseId` (или `catalog.courseId` для неустановленного урока). Новая таблица и миграция не нужны.
- Профиль карточки — `profileOf(language курса)`; `languageOfText` удаляется вместе с оговоркой о письменностях.
- Занятие хранит `courseId`; активное занятие ищется в пределах курса. Прежние занятия без `courseId` считаются занятиями основного курса.

## Основной курс и выбранный курс

- `meta.coursesOrder` — порядок курсов; основной — первый. По умолчанию — порядок установки (греческий установлен первым). В «Настройках» — «Основной курс», если курсов больше одного.
- `meta.currentCourse` — курс, выбранный на «Курсе», «Словах» и «Прогрессе»; один на три экрана, по умолчанию основной.
- Пока курс один, переключателя и второго блока нет — экраны выглядят как сейчас.

## План и занятие

- `makePlan(source, now, { courseId })`: `studiedLessons(courseId)`, порядок программы по номерам модулей этого курса, повторения — `dueStates` с курсом карточки = `courseId`. Карточка в уроках двух курсов невозможна (сборка).
- Варианты ответа (`optionPool`, близкие слова) — слова своего курса.
- «Сегодня» строит план для каждого курса; «Повторить» основного курса — главная кнопка, второго — вторичная.

## Экраны

- «Сегодня»: основной курс — как сейчас; ниже строка второго курса: название, следующий урок, «Повторить N» (или «повторений нет»).
- «Курс», «Слова», «Прогресс»: сегментированный переключатель с названиями курсов («Греческий A2», «Английский B2») над заголовком; данные — выбранного курса. Ссылка на урок/модуль/слово другого курса переключает выбранный курс.
- `views[0]`-допущения уходят: курс экрана — выбранный, а не первый модуль.

## Синхронизация и копия

- Снимок облака не меняется: идентификаторы карточек и уроков глобально уникальны. `meta.coursesOrder` и `meta.currentCourse` — настройки устройства, в облако не идут.

## Проверка

- Существующие тесты — без изменения ожиданий для одного курса.
- Новые: сборка (карточка вне курса, повтор id между курсами, чужая карточка в уроке), план двух курсов (новые и повторения не смешиваются, порядок программы своего курса), варианты из своего курса, «Сегодня» с двумя курсами, переключатель на трёх экранах, занятие повторения одного курса, прежнее занятие без `courseId`.
- e2e: фикстура с двумя курсами (греческий демо + английский из одного урока).
