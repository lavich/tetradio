# Design

## Нажатие на слово

`WordTaps.tsx`: значение контекста (`marks`, `cards`, `show`, `close`, `hint`, `dismissHint`) стабильно; `open` живёт в маленьком хранилище (`useSyncExternalStore`). `TapWord` подписывается на булев снимок «моё слово открыто» — перерисовывается только при смене этого значения; лист слова подписывается на сам `open`. До правок — счётчик перерисовок `TapWord` в тесте на тексте из 200 слов; после — не больше двух слов.

## Часы «Сегодня»

`makePlan` уже читает кандидатов до конца учебного дня (`dueStates(cutoff - 1)`): карточки Review зависят только от дня, карточки обучения — от минуты. План возвращает `wakeAt` — ближайший срок ещё не наступившей карточки не в состоянии Review, иначе конец учебного дня (плюс запас в несколько мс). `usePlan(courseId)` не принимает `now`: счётчик перезапуска растёт по таймеру на `wakeAt` и на `visibilitychange`, а сам запрос берёт `new Date()` — пересчёт от изменения данных (синхронизация, другая вкладка) тоже видит свежее время. Каждому курсу — свой таймер, лишнее пробуждение безвредно. Действия («Начать», `startSession`) берут `new Date()` в момент нажатия; `studyDay(now)` в `CourseToday` — из плана или `new Date()` при отрисовке. `useStats` зависит только от учебного дня (`stats.ts` минуту не использует): ключ — `studyDay` и `visibilitychange`; `wakeAt` ему не нужен. `useNow` остаётся для `ResultScreen` и листа слова. Тесты: план в момент `wakeAt` равен плану по минутам; граница учебного дня (4:00); смена часового пояса.

## Размытие

`backdrop-filter` в `@media (hover: hover) and (pointer: fine)` и `@supports`, общим классом/значением для трёх панелей; `--nav-bg` без размытия плотнее (`color-mix(... 96% ...)`) в `theme.css`; проверить тёмную тему.

## Черновик

`Writing.tsx`: таймер 2000 мс. Запись по таймеру — тихая (`markChanged` в той же транзакции, без `announceChange`): перерисовку `LessonScreen` даёт live-запрос по `blockProgress`, а не событие, поэтому выигрыш — от паузы. Облако при этом не должно терять черновик: `announceChange()` вызывается один раз при blur, при уходе в фон/`pagehide` и при «Сравнить с образцом» (после записи), так что координатор получает `soon()`, а `hidden()` при уходе в фон видит ожидающий обмен. «Готово» объявляет, как сейчас.

## Речь

Двойной «Начать» в интерфейсе недостижим: `setLeft` синхронно заменяет кнопку таймером, а повтор после «Закончить» уже защищён `attempt`; новый флаг не вводится. Утечка другая: `recorder.stop()` при размонтировании вызывает `onstop` уже после него, и тот создаёт `createObjectURL`, которого никто не освободит. Исправление: в `onstop` при `id !== attempt.current` адрес не создаётся.

## Упражнение

Применение — только на переходе `progress.done` false→true (эффект по предыдущему значению), когда `answers` пусты и «Ещё раз» не идёт (ref `resetting`, снимается после записи): иначе эффект сразу вернёт `checked` после retry. Применяется как сейчас для «на другом устройстве»: счёт из `progress`, разбор ответов — при переоткрытии. Приход `done: false` ничего не меняет.

## Нажатие на слово

`WordTaps.tsx`: хранилище на экземпляр `WordTaps` (не синглтон) держит `open` и `hint`; значение контекста (`marks`, `cards`, `show`, `close`, `dismissHint`, хранилище) стабильно — первый тап вызывает `dismissHint`, поэтому `hint` в контексте перерисовал бы все слова. `TapWord` и лист слова подписываются через `useSyncExternalStore`: слово — на булев снимок «моё слово открыто» по ссылке на `anchor`, `TapHint` — на `hint`. Смена страницы закрывает лист через `store.close`. До правок — счётчик перерисовок `TapWord` на тексте из 200 слов, после — не больше двух слов, и на первом тапе тоже (с невиданной подсказкой). Тест: при смене `lesson` контекст пересоздаётся один раз.

## Загрузка

Навигация React Router 7 идёт в `startTransition`: старый экран остаётся, `Suspense fallback` при переходах не показывается. Поэтому индикация строится на загрузке чанка: `loadScreen` ведёт счётчик ожидающих загрузок, `LazyLoading` подписывается и через 300 мс показывает тонкую полосу (живая область, без текста-метафор, `prefers-reduced-motion` — без анимации). Первичная загрузка тем же счётчиком. У необязательных частей (`optional`) — без индикации.

## Реализация

- Замер: тап по слову на тексте из 200 слов — 203 вызова рендера слов до правок, менее 10 после (слово, прежнее слово и лист).
- Черновик: пауза 2 с оставлена по решению пользователя; ревью указало, что тихая запись могла бы идти чаще (0,8 с) без нагрузки на синхронизацию, но перерисовку `LessonScreen` даёт именно запись в `blockProgress`.
- Индикатор загрузки — живая область `aria-live` (не `role="status"`: постоянный `status` ломает локаторы e2e и соседние области), элемент стоит последним в `.app`: `.app > .screen:first-child` ждёт экран первым.
- `usePlan`: таймер перезапускается и по счётчику, `wakeAt` с нечисловым сроком отбрасывается.
