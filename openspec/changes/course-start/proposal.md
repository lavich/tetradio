## Why

После первого курса второй начать нельзя. Переключатель курса показывает только начатые курсы (`src/shared/CourseSwitch.tsx:65-67`, `useCourses` фильтрует `installed` — `src/shared/courses.ts:20-21`), а кнопка «Учить курс» есть только на «Сегодня» без уроков (`src/features/today/TodayScreen.tsx:15`, `FirstRun.tsx:52`) и на полке, когда у выбранного курса нет модулей (`src/features/course/ShelfScreen.tsx:34-40`). Выбрать неначатый курс нельзя и в общем выборе: `currentCourse()` пропускает выбор, если курс не начат и хоть один курс начат (`src/storage/courses.ts:133-140`). Единственный путь сейчас — открыть модуль второго курса по прямому адресу: экран модуля сам ставит его уроки (`src/features/course/ModuleScreen.tsx:36-43`). Стартовый экран показывает только название курса и число уроков и карточек — по нему не понять, какой курс подходит.

Это изменение (а) из брифа `docs/design/multi-course.md`; (б) пауза и (в) модель «язык → курсы» идут следом и опираются на него.

## Решения пользователя

- **20.10.2026** — бриф `docs/design/multi-course.md` согласован целиком; порядок: (а) старт и «Учить курс» на полке — сейчас, (б) пауза, (в) «язык → курсы» вместе с курсом для путешествий.
- **19–20.10.2026, вариант «а»** — на «Курсе» переключатель показывает и неначатые курсы каталога с пометкой «+»; на «Словах», «Чтении» и «Прогрессе» — только начатые.
- **20.10.2026** — стартовый экран: заголовок «Τετράδιο», одна строка о приложении, курсы по языкам; карточка курса — название с уровнем, цель одной строкой, объём (модули), нагрузка (занятий в неделю), «Учить курс» (нагрузку позже убрали, см. ниже); курс без опубликованных уроков — «Готовится», без кнопки. Начать можно несколько; первый начатый — основной.
- **20.10.2026** — неначатый курс на «Курсе» — та же карточка на месте полки.
- **20.10.2026** — нагрузку (занятий в неделю) на карточке курса не показывать: «пользователь сам выберет, как ему удобно».
- **20.10.2026** — тексты таблицы «Тексты на утверждение» утверждены: уровни, цели, `short`, `order`, строка под «Τετράδιο», объём частично готового курса со склонениями. Баги с основным курсом (порядок на новом устройстве, два «Учить курс» подряд) закрываются в этом изменении.
- **20.10.2026** (после код-ревью) — заголовок стартового экрана «Выберите курс» вместо «Τετράδιο»: не повторяет логотип и не тянет греческий набор шрифта на первый экран. Объём частично готового курса — «Готов 1 модуль из 16», «Готовы 2 модуля из 16», «Готово 5 модулей из 16»; полностью готового — «24 модуля».
- **20.10.2026** — не меняются: вид «Сегодня» для основного курса, «одно слово — карточка одного курса», тон без давления.

## What Changes

Предлагаемый объём (а), в рамках решений выше:

- **Переключатель на «Курсе»** — начатые курсы, затем неначатые курсы каталога, у которых есть опубликованные уроки; у неначатого — знак «+» и доступное имя «<название>, не начат». В переключателе — короткое имя курса (новое поле `short`, например «Английский»), чтобы два-три варианта помещались на 360 px. Курс без опубликованных уроков в переключатель не попадает (начинать нечего), он виден только на стартовом экране как «Готовится».
- **Полка неначатого курса** — заголовок «Полка», переключатель и карточка курса с «Учить курс» вместо обложек. После установки первого урока на том же месте — обложки курса. Остальные уроки догружаются, как сейчас после «Учить курс»: при открытии модуля и при следующем запуске.
- **Модуль неначатого курса по прямому адресу** — карточка курса с «Учить курс» вместо тихой установки уроков: курс начинается только кнопкой.
- **«Слова», «Чтение», «Прогресс»** — переключатель только из начатых курсов. Если на «Курсе» выбран неначатый курс, эти экраны показывают последний выбранный начатый курс, а если такого нет — основной. Пустого экрана нет; выбор неначатого курса на «Курсе» не стирает запомненный выбор начатого. Когда выбранный неначатый курс начат, он становится выбранным для всех четырёх экранов.
- **Стартовый экран** (на устройстве нет уроков) — заголовок «Выберите курс», строка о приложении, один раз подсказка о загрузке без сети, карточки курсов по языкам (заголовок языка — когда у языка два курса и больше). Главная кнопка — у первого курса, у остальных — второстепенная. Карточка — та же, что на полке. Пока ставится первый урок нажатого курса, «Учить курс» у остальных недоступна с пояснением — так первый нажатый курс и есть первый начатый.
- **Данные курса** — новые необязательные поля файла курса `content/courses/*.yaml`: `level` (ступени, например «A0 → A2»), `goal` (цель одной фразой), `short` (короткое имя для переключателя), `order` (место курса среди курсов). Сборка проверяет их и кладёт в каталог; клиент хранит их у курса. Объём карточки считается из модулей каталога. Поля нет — строки карточки нет; без `order` курс идёт после курсов с `order`.
- **Первый начатый — основной и на новом устройстве.** Сейчас на новом устройстве курсы ставит синхронизация пакетами по id (`src/sync/coordinator.ts:533-541` → `src/sync/index.ts:27-29` → `installPackages`; id отсортированы, `src/sync/snapshot.ts:165`), `e01-*` раньше `m01-*`, и `rememberCourses` (`src/content/install.ts:132` → `src/storage/courses.ts:104-107`) записывает английский курс первым и домашним. Предлагается: начатыми для порядка считаются и курсы уроков, ждущих установки из снимка, а новые курсы встают в порядок по самой ранней дате своих уроков. Уже записанные порядок и домашний курс не перезаписываются.
- **Синхронизация и формат облака не меняются.** Новые настройки выбора — ключи `meta` базы аккаунта (как `currentCourse` и `coursesOrder`, `src/storage/courses.ts:1-4`): в облако не идут, в локальную копию данных входят, как прочие ключи курса. Поля карточки — из каталога; снимок курсы не содержит.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `app-sections`: «Основной и второй курс» — переключатель на «Курсе» с неначатыми курсами и коротким именем, правило выбора для «Слов», «Чтения», «Прогресса», первый начатый курс основной и на новом устройстве; новое требование «Начало курса» — стартовый экран, карточка курса, «Готовится», «Учить курс» на полке и на модуле неначатого курса.
- `course-content`: новое требование «Данные курса для выбора» — поля `level`, `goal`, `short`, `order`, их проверка сборкой и каталог.
