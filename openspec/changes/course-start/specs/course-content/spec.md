## ADDED Requirements

### Requirement: Данные курса для выбора
Файл курса SHALL допускать необязательные поля, по которым учащийся выбирает курс: `level` — ступени курса строкой из уровней A0–C2 с необязательным «+», один уровень или два через « → »; `goal` — цель курса одной фразой без перевода строки, не длиннее 90 символов; `short` — короткое имя курса для переключателя, без перевода строки, не длиннее 14 символов; `order` — место курса среди курсов: целое больше нуля, у двух курсов одного контента место MUST NOT совпадать. Сборка MUST отклонять поле другого вида с `ContentError`, в сообщении — путь файла курса и имя поля. Каталог SHALL перечислять курсы по `order`, курсы без `order` — после них по id, и передавать заданные поля клиенту; отсутствующее поле в каталог не попадает. Каталог с новыми полями MUST читаться прежним клиентом без ошибки, версия схемы каталога не меняется. Клиент MUST NOT отклонять каталог из-за неверного поля выбора курса: такое поле отбрасывается, остальной каталог применяется.

#### Scenario: Поля курса в каталоге
- **WHEN** в `courses/greek-a2.yaml` заданы `level: A0 → A2`, `goal`, `short: Греческий` и `order: 1`
- **THEN** у курса `greek-a2` в `catalog.json` те же поля

#### Scenario: Порядок курсов в каталоге
- **WHEN** у `greek-a2` `order: 1`, у `english-it` `order: 2`
- **THEN** в `catalog.json` курс `greek-a2` идёт раньше `english-it`, хотя файл `english-it.yaml` по алфавиту первый

#### Scenario: Поля не заданы
- **WHEN** в файле курса нет ни одного из новых полей
- **THEN** сборка проходит, у курса в каталоге этих полей нет, курс идёт после курсов с `order`

#### Scenario: Неверный уровень
- **WHEN** в файле курса `level: B3` или `level: "A2 -> B1"`
- **THEN** сборка падает с `ContentError`, в сообщении `courses/<файл>` и `level`

#### Scenario: Цель в несколько строк
- **WHEN** `goal` содержит перевод строки или длиннее 90 символов
- **THEN** сборка падает с `ContentError`, в сообщении путь файла и `goal`

#### Scenario: Длинное короткое имя
- **WHEN** `short: Английский для IT`
- **THEN** сборка падает с `ContentError`, в сообщении путь файла и `short`

#### Scenario: Одно место у двух курсов
- **WHEN** у двух курсов `order: 1`
- **THEN** сборка падает с `ContentError`, в сообщении оба файла и `order`

#### Scenario: Прежний клиент
- **WHEN** клиент прежней версии читает каталог с новыми полями курса
- **THEN** каталог разбирается без ошибки, поля пропускаются

#### Scenario: Неверное поле в каталоге
- **WHEN** клиент получает каталог, где у курса `level: Pre-A1 → A1` и `short` из 20 символов
- **THEN** каталог применяется, у курса нет `level` и `short`
