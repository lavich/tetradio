# Design

## Context

Реплики аудирования озвучены заранее облачным синтезом (Google Cloud TTS, Chirp 3 HD, `docs/voices.md`): у каждого персонажа голос из карты `content/voices/el.yaml`, сборка отклоняет урок, если у говорящего нет голоса или двое в одном диалоге звучат одним голосом (`checkDialogueVoices`, `content/build/voices.ts:82`). Скрипт `npm run voices` пишет файл на реплику и манифест `content/audio/dialogues.json` (голос и хэш текста); сборка публикует запись, только если она сделана для нынешнего текста и голоса (`content/build/lessons.ts:57-110`), и кладёт её медиа в пакет урока (`lineAudio`). Плеер `playDialogue` (`src/shared/dialogue.ts:132`) проигрывает реплики по очереди: файл, если есть, иначе синтез устройства.

Экран текста (`reading-shelf`) уже читает текст по предложениям (`sentencesOf`, `src/domain/sentences.ts`) через `playDialogue`, но без файлов. Диктор карты — Kore, у персонажа Μαρία тот же Kore (`el.yaml`): в тексте, где говорит Мария, голос диктора для повествования нарушил бы правило «разные голоса».

Объём: два текста на модуль 4–24 — около 42 текстов, ~15 тыс. слов, ~98 тыс. символов синтеза (бесплатно до 1 млн в месяц) и ~2 часа речи, ~28 МБ.

## Goals / Non-Goals

**Goals:**
- Каждый текст полки звучит записями: повествование — чтецом, реплики — голосами персонажей.
- Правка одного предложения переозвучивает только его.

**Non-Goals:**
- Подсветка звучащего предложения и повтор отдельного предложения (основа для них появляется, но экран не меняется).
- Вычитка текстов носителем.
- Озвучка английского курса.

## Decisions

### Говорящие: список `speakers` по строкам диалога

```yaml
text: |-
  Είναι Τρίτη και η Άννα είναι στο μάθημα.
  — Καλησπέρα! λέει η Χριστίνα.
  — Καλησπέρα!
speakers: [Χριστίνα, Άννα]   # по строке «—» на имя, по порядку
```

Строка диалога — строка текста, которая после пробелов начинается с «—». Число имён должно совпасть с числом таких строк; пустое имя (`""`) — реплика без говорящего (хор, «λένε οι άνθρωποι»): звучит голосом рассказчика. Без `speakers` все строки читает рассказчик. Ремарка внутри реплики («λέει η Χριστίνα») звучит голосом говорящего — так короче и привычнее для диалога в учебнике. Цитата в кавычках внутри повествования звучит голосом рассказчика; живая речь в текстах пишется строками «—».

Отвергнуто: имя в самом тексте («Χριστίνα: — …») — оно попало бы на экран; разметка по номерам строк — ломается при вставке строки.

### Рассказчик: `narrator` текста или `reader` карты

Повествование звучит голосом рассказчика: персонажа из поля `narrator` текста (рассказ от первого лица — «Με λένε Άννα…»), иначе чтеца — нового поля `reader` карты. Диктор карты (`narrator`, Kore) остаётся голосом слов, фраз и реплик аудирования без говорящего: у Μαρία тот же голос, поэтому повествованию он не годится.

Проверка голосов текста — своя, не `checkDialogueVoices`: в ней «голос без говорящего» — голос рассказчика, а не диктора карты, и сообщения называют текст и строку. Рассказчик участвует как ещё один говорящий: разные говорящие — разные голоса. Карта без `reader` при тексте без `narrator` — отказ сборки.

### Записи по предложениям

- Единица — предложение (`sentencesOf` по каждой строке; общая функция для сборки и клиента, поэтому деление совпадает). Голос — говорящего строки или чтеца.
- Файл — `content/audio/readings/<текст>/<n>.mp3`, `n` — номер предложения в тексте; манифест — тот же `dialogues.json` с голосом и хэшем текста предложения (вопросительный `;` уходит в синтез как `?`, как у реплик).
- Пакет: `PackageReading.audio` — по предложению id медиа или `null`; медиа — в `media` пакета открывающего урока. Устаревшая или отсутствующая запись — `null`, предложение звучит синтезом. Разбор пакета проверяет, что длина `audio` равна числу предложений текста и что каждый id есть в `media` (как `parseLineAudio`); иначе `audio` отбрасывается и текст звучит синтезом.
- Сборка: `buildReadings` получает карту голосов, манифест и общий словарь медиа и вызывается до `packLessons`; медиа текстов попадают и в `media` пакета, и в общий словарь файлов.
- Каталог: `CatalogEntry.readingAudio` — число предложений с записью в текстах урока; установка ставит пакет заново, если у установленного записей меньше (как `readings`).
- Файлы нумеруются с 1; скрипт удаляет `<n>.mp3` сверх числа предложений, когда текст стал короче. `npm run voices` без аргументов озвучивает и тексты.
- Номера меняются, если вставить предложение в середину: следующие переозвучиваются (хэш не совпадёт). Это дешевле, чем хранить устойчивые id предложений, и честно: озвучка проверяется сборкой.

Отвергнуто: один файл на текст — правка любой фразы переозвучивает весь текст, нельзя подменить синтезом одно предложение.

### Клиент

`Aloud` передаёт в `playDialogue` строки `{ text, audioAssetId }` и источник медиа (`useAssetSource`), как аудирование. Пакет текста хранится в установленном пакете урока, медиа скачивается при прослушивании.

`playDialogue` сейчас обрывает весь текст, если файл не сыграл (`error`) или на строке без записи нет голоса устройства (`none`, `src/shared/dialogue.ts:157-167`). Для текстов — откат по строке: файл не сыграл — эта строка синтезом; нет голоса — строка пропускается, остальные звучат записями; итог «none» — только если не прозвучало ничего. Аудирование уроков ведёт себя как раньше.

### Новые персонажи

Голоса героям серии без голоса даются по правилам карты (`docs/voices.md`): голос своего пола, которого нет у собеседников в их текстах. Τζον и Αντρέι — мужские явно (правило окончаний их не покрывает). Список растёт с блоками контента.

### Контент блоками

Каждый блок (m04–m08, m09–m15, m16–m20, m21–m24) — отдельный PR: тексты по два на модуль, `speakers` и `narrator`, озвучка, отчёт долей, проверка грамматики по урокам модуля (доля знакомых слов проверяет только лексику), выборочное прослушивание и вычитка пользователем. Тексты пишутся из лексики и грамматики уроков до `after` (`after` — последний урок модуля или его контрольная), длина — по коридору модуля, серия «Анна» продолжает героев пилота. Новые тексты — `review: none`, после одобрения пользователем — `author` отдельной правкой.

## Risks / Trade-offs

- [Ошибки греческого в 42 сгенерированных текстах] → пороги сборки, вычитка пользователем по блокам, пометка «сгенерированный» до вычитки носителем.
- [Объём медиа растёт на ~28 МБ] → медиа скачивается при прослушивании конкретного текста, а не с пакетом.
- [Ключ Google API в коммите] → ключ только в окружении (`.env` в `.gitignore`); перед коммитом diff проверяется на префикс ключей Google API.
- [Синтез ошибается в ударении редкого слова] → прослушать выборочно каждый блок; при ошибке — правка текста или повтор синтеза.
- [Деление по предложениям рвёт интонацию: «Πόσων… χρονών…» звучит отдельными файлами с паузой] → многоточие внутри строки не граница предложения; для текстов граница — `.`, `!`, `?`, `;` и конец строки.

## Migration Plan

Первый блок — механизм, озвучка пилота и тексты m04–m08. Поле `audio` в `PackageReading` необязательное: клиент `reading-shelf` без поддержки звучит синтезом, как сейчас.

## Реализация

- Откат по строке — флаг `lenient` у `playDialogue`; без него аудирование уроков ведёт себя как раньше.
- План озвучки текстов — чистая `planReadingVoices` (что озвучить, что удалить); скрипт только исполняет его.
- Многоточие из точек в тексте — отказ сборки: точка делит текст на предложения, а записи идут по предложениям.
- Экран берёт записи, только если их столько же, сколько предложений, — защита от пакета, поставленного до смены деления.
- Сборка сверяет число записей до и после разбора пакета: молча отброшенное `audio` вызывало бы переустановку при каждом запуске.
