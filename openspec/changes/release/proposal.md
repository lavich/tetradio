# Proposal

## Why

Приложение опубликовано на GitHub Pages и открывается из бота `@TetradioBot`. Чтобы выпустить его для учащегося, остаются приёмка пилота и проверка на реальных клиентах Telegram.

## What Changes

- Приёмка пилота: пройти модуль целиком, вернуться к сохранённому прогрессу, восстановить копию.
- Статический хостинг Mini App и собственный бот без токенов Tavelori (сделано).
- Проверка на iOS, Android и Desktop: запуск, кнопка «Назад», тема, синтез речи, синхронизация.
- Итоговые команды проверки и выпуск.

## Capabilities

### New Capabilities

- `delivery`: размещение и запуск Mini App.

## Impact

Конфигурация сборки и деплоя, документация запуска (`docs/telegram.md`); код приложения — только исправления по итогам проверки.
