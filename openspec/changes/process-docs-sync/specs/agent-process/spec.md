# agent-process

## ADDED Requirements

### Requirement: Навык подготовки урока отражает форматы приложения
Навык `prepare-lesson` SHALL NOT утверждать, что приложение не поддерживает формат задания, который принимает сборщик контента, и SHALL указывать, по какому документу готовятся задания уроков.

#### Scenario: Просьба о задании с пропуском
- **WHEN** агент по навыку получает просьбу подготовить задание с пропуском
- **THEN** навык не велит отклонять просьбу как неподдерживаемую, а отсылает к `docs/course/format.md`

### Requirement: Полная проверка feature-flow совпадает с CI
Раздел полной проверки навыка `feature-flow` SHALL перечислять каждую npm-команду, которую запускает `.github/workflows/ci.yml`, кроме диагностических (`check:flaky`) и частей `npm test` (`test:unit`, `test:heavy`), и обе копии навыка (`.claude/skills`, `.agents/skills`) SHALL быть идентичны.

#### Scenario: В CI добавлена проверка
- **WHEN** в `ci.yml` появляется новая команда `npm run <имя>`, которой нет в навыке
- **THEN** тесты падают, пока навык не обновлён

#### Scenario: Копии навыка разошлись
- **WHEN** файл навыка `feature-flow` изменён только в одной копии
- **THEN** тесты падают
