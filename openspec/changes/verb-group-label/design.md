## Decisions

### 1. Классификация по таблице настоящего времени

Функция `verbGroup(present)` рядом с `conjugate` в `content/build/paradigm.ts`, на вход — шесть форм настоящего из готовой таблицы:

| Признак (по порядку) | Группа | Глаголов |
| --- | --- | --- |
| «я» на -μαι, кроме είμαι | `mid` | 26 |
| «ты» на -άς | `B1` | 24 (вкл. προτιμώ, συναντώ) |
| «ты» на -είς/-εις и «мы» на ударное -ούμε | `B2` | 14 (вкл. ζω) |
| «я» на безударное -ω, «ты» на безударное -εις, «мы» на безударное -ουμε | `A` | 98 |
| иначе | `null` — нужна явная группа | 4 |

Почему по таблице, а не по заглавной: προτιμώ и συναντώ записаны на -ώ, но спрягаются как αγαπάω (προτιμάς); ζω без ударения спрягается как μπορώ (ζεις, ζούμε). Таблица у них явная и уже проверена (`PARADIGM_REPORT`), группа следует из неё. Отвергнуто: группа по окончанию заглавной (ошибётся на προτιμώ, συναντώ, ζω) и отдельная ручная разметка всех 166 карточек (две истины о спряжении).

Внутренние значения — `A`, `B1`, `B2`, `mid`, `other`: короткие, латиницей, не зависят от текста метки.

### 2. Явная группа — только там, где таблица молчит

Поле карточки `group` (в `WORD_FIELDS`, `content/build/sources.ts`) разрешено, только если у карточки есть таблица и `verbGroup` вернул `null`. Иначе — отказ («группа выводится из таблицы: A»): одна истина, и правка таблицы не оставит устаревшую ручную группу. Четыре явные:

| Карточка | `group` | Основание |
| --- | --- | --- |
| λέω | `A` | ударение на основе (λέ-ω) — по правилу m05-1 группа A; «неправильный» в m02-2:51 — про сжатое настоящее (λες), о котором метка не говорит; прошедшее είπα — «неправ. прош.» (решение 3) |
| τρώω | `A` | то же: τρώ-ω, «неправильный» в m08-1:150 — про τρως; прошедшее έφαγα — «неправ. прош.» |
| ακούω | `A` | m05-1 (`which-group`) прямо называет α**κού**ω группой A; прошедшее άκουσα правильное — метка «гр. A» (решение пользователя) |
| είμαι | `other` | настоящее είμαι, είσαι, είναι, είμαστε, είστε, είναι не следует ни одному образцу -μαι (нет -εται, -όμαστε, -ονται), m05-2 («Глаголы на -μαι») είμαι не включает: метка — только «неправ. прош.» (ήμουν) |

Таблица у λέω, τρώω, ακούω «сжатая» (λες, τρως, ακούς) — правило решения 1 её не узнаёт, поэтому группа явная. Тексты уроков изменение не правит: «неправильный» в m02-2 и m08-1 говорит о настоящем, метка — о группе и прошедшем, и они не спорят.

Безличные (βρέχει, πρέπει, φυσάει, χιονίζει) — без группы: таблицы у них нет, а правило m05-1 («посмотрите на форму „я“») к ним не применимо. Неполные (`third`: αρέσω, υπάρχω, κοστίζω, ταιριάζω) — группа по шести формам таблицы, как у всех (`A`): формы строятся обычно, `third` только скрывает строки.

### 3. «Неправ. прош.» — окончание прошедшего плюс явные исключения

Решение пользователя: метка «<группа> · неправ. прош.» у глаголов с неправильным прошедшим (смысл m15-1). Критерий — честно, как он работает: функция `irregularPast(headword, past)` рядом с `verbGroup` смотрит **только на окончание** первой формы прошедшего в таблице, основу не выводит:

- глагол на -μαι: правильное, если форма кончается на -θηκα или -τηκα (κοιμήθηκα, σκέφτηκα, βιάστηκα);
- остальные: правильное, если форма кончается на -σα, -ξα или -ψα (αγόρασα, άνοιξα, δούλεψα, μίλησα, πέρασα, κάλεσα) либо равна основе настоящего + -α, где основа — заглавная без -ω/-ώ/-άω, а приращение έ- в начале отбрасывается (περίμενα, νόμιζα, σήμαινα — карточка даёт «прош.» как имперфект; πρότεινα; σέρβιρα — заимствование на -ίρω);
- иначе — неправильное.

Окончание не говорит, выведена ли основа по m14-1: у δίνω → έδωσα окончание правильное, а основа меняется; у βρίσκομαι → βρέθηκα, πλένομαι → πλύθηκα — правильное -θηκα, но основа та же, что у неправильных βρίσκω → βρήκα и πλένω → έπλυνα; κάνω → έκανα совпадает с «έ- + основа + -α». Эти случаи — явное поле карточки `irregular`, которое заменяет правило и отклоняется, если совпадает с ним:

| Карточка | `irregular` | Почему |
| --- | --- | --- |
| κάνω | `true` | m15-1 в таблице неправильных, m14-2:97 — «Έκανα — аорист от κάνω, неправильный» |
| δίνω | `true` | έδωσα: основа δίν- → δωσ-; m15-1 в таблице неправильных |
| βρίσκομαι | `true` | βρέθηκα: основа βρίσκ- → βρε-, как у βρίσκω → βρήκα; последовательно с βρίσκω |
| πλένομαι | `true` | πλύθηκα: основа πλέν- → πλυ-, как у πλένω → έπλυνα; последовательно с πλένω |
| υπάρχω | `false` | υπήρχα — имперфект с внутренним приращением (υπ-άρχω → υπ-ήρχα), образуется регулярно |

Итог — 36 глаголов «неправ. прош.», каждый сверен с греческим (первая форма прошедшего по таблице сборки):

| Группа | Глаголы |
| --- | --- |
| A (31) | βλέπω → είδα, βρίσκω → βρήκα, βγαίνω → βγήκα, πηγαίνω → πήγα, πίνω → ήπια, καταπίνω → κατάπια, παίρνω → πήρα, λέω → είπα, τρώω → έφαγα, κάνω → έκανα, δίνω → έδωσα, φέρνω → έφερα, φεύγω → έφυγα, αποφεύγω → απέφυγα, μαθαίνω → έμαθα, καταλαβαίνω → κατάλαβα, ανεβαίνω → ανέβηκα, κατεβαίνω → κατέβηκα, βγάζω → έβγαλα, αναβάλλω → ανέβαλα, επαναλαμβάνω → επανέλαβα, παραλαμβάνω → παρέλαβα, προσλαμβάνω → προσέλαβα, μένω → έμεινα, στέλνω → έστειλα, παραγγέλνω → παρήγγειλα, πλένω → έπλυνα, παχαίνω → πάχυνα, έχω → είχα, θέλω → ήθελα, ξέρω → ήξερα |
| на -μαι (4) | έρχομαι → ήρθα, γίνομαι → έγινα, βρίσκομαι → βρέθηκα, πλένομαι → πλύθηκα |
| вне групп (1) | είμαι → ήμουν |

Сверка по-гречески:

- Сильные и супплетивные аористы (είδα, βρήκα, βγήκα, πήγα, ήπια, κατάπια, πήρα, είπα, έφαγα, έφερα, έφυγα, απέφυγα, έμαθα, κατάλαβα, -λαβα, -βηκα, έβγαλα, ανέβαλα, ήρθα, έγινα) неправильны в любой грамматике. φέρνω → έφερα и καταπίνω → κατάπια правило ловит: основа φέρν-, καταπίν- + -α ≠ φερα, καταπια.
- Аористы с чередованием основы на -να (έμεινα, έστειλα, παρήγγειλα, έπλυνα, πάχυνα) по m14-1 не строятся и запоминаются. Внутри -αίνω это последовательно: αρρωσταίνω → αρρώστησα и παχαίνω → πάχυνα расходятся в самом греческом (первый — на -ησα по правилу, второй — нет), как и μαθαίνω → έμαθα.
- έχω → είχα, θέλω → ήθελα, ξέρω → ήξερα: аориста в употреблении нет, прошедшее — имперфект с приращением ει-/ή- вместо έ- из правила m14-1. m15-1 особыми называет έχω и είμαι («аориста у них нет»); θέλω и ξέρω — тот же случай (единственное прошедшее с η-), поэтому тоже «неправ. прош.», хотя таблица m15-1 их не перечисляет.
- Правильные по правилу и по смыслу (проверено): χάνω → έχασα, αφήνω → άφησα, φτάνω → έφτασα (-νω теряет ν, как πληρώνω → πλήρωσα в m14-1), κλείνω → έκλεισα (пример m14-1), αρρωσταίνω → αρρώστησα, ακούω → άκουσα, ζω → έζησα, περνάω → πέρασα, καλώ → κάλεσα, μπορώ → μπόρεσα, καταθέτω → κατέθεσα, προτείνω → πρότεινα, σερβίρω → σέρβιρα, νομίζω, περιμένω, σημαίνω, υπάρχω; у -μαι — χάνομαι → χάθηκα (как χάνω → έχασα), ντύνομαι → ντύθηκα, ευχήθηκα, υποσχέθηκα.
- μπαίνω (μπήκα) из примера пользователя в курсе карточки не имеет.

Отвергнуто: только явное поле у 36 карточек (новый глагол с неправильным прошедшим без поля молча получил бы метку правильного; правило ловит большинство само) и вывод основы аориста из настоящего (основу курс берёт из `forms`; надёжно её не вывести — это и есть то, что запоминает учащийся).

### 4. Поля `group` и `irregular` в пакете, одна сборка карточки подсказки, переустановка без поля каталога

`PackageWord.group`/`irregular` и `MarkCard.group`/`irregular` — необязательные, значения проверяются при разборе (`ContentError` на незнакомое; `irregular` в пакете только `true`). Оба поля входят в `SHIPPED_FIELDS`: ревизия глаголов меняется, и `applyCards` перезапишет их у клиента, который ставит новую версию пакета.

Карточка подсказки сейчас собирается двумя копиями одного литерала (`mark-courses.ts:84-96` и `readings.ts:352-363`). Обе заменяются одной функцией `markCard(ref, card, lesson)` рядом с `cardDescriber` в `content/build/mark-courses.ts`: `cardDescriber` отдаёт `group` и `irregular`, `markCard` кладёт их в `MarkCard`. Так подсказка в тексте для чтения получает метку тем же кодом, что в уроке; `TapCard` получает поля из `pack.words`, `pack.marks.cards` (`src/storage/course.ts`) и `reading.marks.cards` (`src/storage/readings.ts`, карточка передаётся как есть).

Совместимость: прежний клиент между выкладкой контента и обновлением приложения поставит новую версию пакета без групп, а после обновления версия совпадёт. Признак переустановки — локальный, без каталога: в поставленном греческом пакете есть слово с таблицей (`paradigm`) или карточка подсказки — в `marks.cards` или в `readings[].marks.cards` — с формами глагола (`hasParadigm(greek, forms)`: тот же признак, что у сборки, переносится из `content/build/paradigm.ts` в `src/domain/verb-forms.ts`), у которых нет `group`. Сборка гарантирует обратное: у каждого такого места группа есть, у είμαι — `other` (решения 1–2), поэтому у пакета новой сборки признак ложен и повторной установки нет. В `applyCards` для слов — то же правило, что для таблицы: `!!card.group && !stored.group`.

Отвергнуто: счётчик `groups` в записи каталога по образцу `paradigms` — ещё одно поле у десятков из 99 греческих уроков, а каталог 38 258 из 40 000 растёт с каждым модулем английских курсов; локальный признак даёт то же без байтов каталога. Вычислять группу и признак на клиенте из `paradigm` — две реализации правил, и у карточек подсказки таблицы нет.

### 5. Метка — плашка `VerbGroupLabel` перед рядом форм

Один компонент в `src/shared/` (рядом с `VerbForms.tsx`), вставляется:

- в `WordForms` — перед рядом форм (лист слова, экран по ссылке, знакомство, раскрытие, узнавание после ответа); у `verbsOnly` метка идёт вместе с формами;
- в подсказку `WordTaps` (уроки и тексты для чтения) — перед строкой форм, и при пустой строке форм (форма без греческих букв) метка остаётся;
- в `VocabularyList` — в начале строки форм под словом; в имени кнопки строки метка идёт после слова и перед формами: «Произнести: έρχομαι, глагол на -μαι, неправильное прошедшее, … приходить».

Текст: группа («гр. A», «гр. B -άω», «гр. B -ώ», «на -μαι»), при `irregular` — « · неправ. прош.» через срединную точку, у `other` — только «неправ. прош.». Диктор: «группа A», «группа B, тип на -άω», «группа B, тип на -ώ», «глагол на -μαι», с добавкой «, неправильное прошедшее», у `other` — «неправильное прошедшее». Метка видна всегда, и до m05-1 (решение пользователя): m02-1 уже обещает «весь этот тип мы разберём в модуле 05».

Вид по DESIGN.md: подпись интерфейса Manrope (`Label`, 600, 12.5px), цвет «карандашной подписи» `muted-foreground`, рамка 1 px `border`, скругление 10 px — ступень шкалы «варианты урока и строки словарика» (`Shapes`), без фона: справочная пометка учебника, а не статус (ни зелёного, ни янтаря). Самая длинная метка «на -μαι · неправ. прош.» при нехватке места переносится своей строкой перед рядом форм (`flex-wrap`), без горизонтальной прокрутки. В DESIGN.md — раздел «Verb group label» в Components.

Доступность: видимый текст `aria-hidden`, рядом `sr-only` с полной фразой («гр.» и «прош.» диктор читал бы буквами). Греческое и в видимой метке, и в тексте для диктора (-άω, -ώ, -μαι) — в `<span lang="el">`, видимое — Literata, как требует правило «печать против интерфейса». Латинские A и B в тексте для диктора проверяются на устройстве русским голосом VoiceOver и TalkBack (задача 5.2); если голос читает их не как «а» и «бэ», текст для диктора меняется на русскую запись названия буквы — видимая метка не меняется.

Отвергнуто: метка рядом с заглавным словом — в подсказке и списке там Literata 17–20 px и кнопка звука, на 390 px строка ломается; цветовые плашки по группам — правило Never-Color-Alone и тихий интерфейс; скругление 6 px — вне шкалы `Shapes`.

### 6. Заметки карточек

`note` μιλάω — «также μιλώ», μπορώ — «μπορείς, μπορεί…; μπορώ να + глаг. — модуль 16», у ευχαριστώ заметка убирается; правка в строках лексикона `docs/course/lexicon/*.tsv` и в карточках. Заметка κοιμάμαι («спряжение на -άμαι: κοιμάσαι, κοιμάται…») остаётся: метка «на -μαι» подтип не называет.

### 7. Проверки

## Risks / Trade-offs

- [Метка до m05-1: μιλάω, λέω, ζω, έχω, είμαι, μένω вводятся в m01–m04, и учащийся видит «гр. B -άω» раньше, чем узнаёт о группах] → решение пользователя «Всегда»; m02-1 уже обещает разбор типа в модуле 05.
- [«Неправ. прош.» у глаголов с чередованием основы (μένω → έμεινα), которые часть грамматик считает правильными] → для учащегося курса правило одно — m14-1 (σ/ξ/ψ); остальное он запоминает, как велит m15-1. Список из 36 сверен вручную и закреплён тестом.
- [Критерий смотрит на окончание, а не на основу: новый глагол с правильным окончанием и сменой основы (как δίνω) получит метку правильного] → отчёт печатает признак и прошедшее каждого глагола, сверка нового глагола по отчёту — в `docs/course/format.md`; исправление — `irregular: true`.
- [Новый глагол с аористом не по правилу, но правильный по смыслу] → правило даст «неправ. прош.»; исправление — `irregular: false`.
- [«гр. B -άω» на προτιμώ, записанном на -ώ] → так же говорит m05-1 (αγαπάω = αγαπώ) и заметка μιλάω; диктор читает «тип на -άω».
- [Новый глагол с непредусмотренным спряжением] → `verbGroup` возвращает `null`, сборка падает с указанием поля `group`, отчёт печатает группу каждой таблицы для сверки.
- [Пересечение с `greek-tap-forms` в `cardDescriber`, `MarkCard` и `readings.ts`] → реализация начинается от `main` после его мержа; тест «поля `marks.cards` и `readings[].marks.cards` совпадают со словом» ловит потерю поля при слиянии.
- [Повторная загрузка пакетов] → у учащегося перекачиваются пакеты с глаголами (обычное обновление версии); прогресс не меняется, тест переустановки это проверяет.

## Migration Plan

Выкладка обычная: контент и приложение одной сборкой. Клиент, который успел поставить пакеты прежней версией приложения, после обновления переставит их по локальному признаку (решение 4). Откат: возврат коммита — прежний клиент поле игнорирует, пакеты без поля прежней версии ставятся как раньше.
