## Goals / Non-Goals

**Goals:**

- Одна классификация для всех мест: группа считается сборкой из той же таблицы, что видит учащийся в «Все формы», и не расходится с ней.
- Прежний клиент не ломается; новый получает группы без ручных действий учащегося и без нового поля каталога.

**Non-Goals:**

- Группа как вход в упражнения, фильтр словаря, сортировка по группам.
- Типы аориста в метке (-σα, -ξα, -ψα, -ησα): метка говорит только группу настоящего времени и «неправ.», формы прошедшего показывает ряд форм.

## Decisions

### 1. Классификация по таблице настоящего времени

Функция `verbGroup(present)` рядом с `conjugate` в `content/build/paradigm.ts`, на вход — шесть форм настоящего из готовой таблицы:

| Признак (по порядку) | Группа | Глаголов |
| --- | --- | --- |
| «я» на -μαι, кроме είμαι | `mid` | 26 |
| «ты» на -άς | `B1` | 24 (вкл. προτιμώ, συναντώ) |
| «ты» на -είς/-εις и «мы» на ударное -ούμε | `B2` | 14 (вкл. ζω) |
| «я» на безударное -ω, «ты» на безударное -εις, «мы» на безударное -ουμε | `A` | 98 |
| иначе | `null` — нужна явная группа | 4 |

Почему по таблице, а не по заглавной: προτιμώ и συναντώ записаны на -ώ, но спрягаются как αγαπάω (προτιμάς); ζω без ударения спрягается как μπορώ (ζεις, ζούμε). Таблица у них явная и уже проверена (`PARADIGM_REPORT`), группа следует из неё. Отвергнуто: группа по окончанию заглавной (ошибётся на προτιμώ, συναντώ, ζω) и отдельная ручная разметка всех 166 карточек (две истины о спряжении).

Внутренние значения — `A`, `B1`, `B2`, `mid`, `other`: короткие, латиницей, не зависят от текста метки.

### 2. Явная группа — только там, где таблица молчит

Поле карточки `group` (в `WORD_FIELDS`, `content/build/sources.ts`) разрешено, только если у карточки есть таблица и `verbGroup` вернул `null`. Иначе — отказ («группа выводится из таблицы: A»), как у лишних данных в других полях: одна истина, и правка таблицы не оставит устаревшую ручную группу. Четыре явные (решение пользователя 23.10.2026, вопрос 3):

| Карточка | `group` | Основание |
| --- | --- | --- |
| λέω | `A` | ударение на основе (λέ-ω), по правилу m05-1 — группа A; «неправильный» в m02-2 — о прошедшем είπα (решение 3) |
| τρώω | `A` | то же: τρώ-ω, прошедшее έφαγα |
| ακούω | `A` | m05-1 (`which-group`) прямо называет α**κού**ω группой A; прошедшее άκουσα правильное |
| είμαι | `other` | настоящее είμαι, είσαι, είναι, είμαστε, είστε, είναι не следует ни одному образцу -μαι (нет -εται, -όμαστε, -ονται), а m05-2 («Глаголы на -μαι») είμαι не включает: метка только «неправ.» |

Таблица у λέω, τρώω, ακούω «сжатая» (λες, τρως, ακούς) — правило решения 1 её не узнаёт, поэтому группа явная. Фраза m08-1 «так же спрягаются λέω и ακούω» с этим не спорит; текст уроков изменение не правит.

Безличные (βρέχει, πρέπει, φυσάει, χιονίζει) — без группы: таблицы у них нет, а правило m05-1 («посмотрите на форму „я“») к ним не применимо. Неполные (`third`: αρέσω, υπάρχω, κοστίζω, ταιριάζω) — группа по шести формам таблицы, как у всех (`A`): формы строятся обычно, `third` только скрывает строки.

### 3. «Неправ.» — прошедшее не по правилам m14-1

Решение пользователя: метка «<группа> · неправ.» у всех глаголов с неправильным прошедшим. Признак выводится из первой формы прошедшего в таблице (`irregularPast(headword, past)` рядом с `verbGroup`) по правилам, которые учащийся знает из m14-1 и m15-1:

- глагол на -μαι: регулярно -θηκα / -τηκα (κοιμήθηκα, σκέφτηκα, βιάστηκα);
- остальные: регулярно -σα, -ξα, -ψα (αγόρασα, άνοιξα, δούλεψα, в том числе -ησα, -ασα, -εσα: μίλησα, πέρασα, κάλεσα — «особый случай на -ασα» m14-1), а также прошедшее = основа настоящего + -α с приращением έ- или без (περίμενα, νόμιζα, σήμαινα — имперфект там, где карточка даёт «прош.»; πρότεινα; σέρβιρα — заимствование на -ίρω);
- иначе — `irregular: true`.

Правило не видит два случая m15-1 и один ложный: поле карточки `irregular` их исправляет и, как `group`, отклоняется, если совпадает с правилом.

| Карточка | `irregular` | Почему правило ошибается |
| --- | --- | --- |
| κάνω | `true` | έκανα совпадает с «έ- + основа + -α», но m15-1 и m14-2 называют его неправильным (аорист без σ) |
| δίνω | `true` | έδωσα на -σα, но основа меняется (διν → δωσ); m15-1 в таблице неправильных |
| υπάρχω | `false` | υπήρχα — имперфект с внутренним приращением (υπ-άρχω → υπ-ήρχα), образуется регулярно |

Итог — 34 глагола «неправ.», каждый сверен с греческим (первая форма прошедшего по таблице сборки):

| Группа | Глаголы |
| --- | --- |
| A (31) | βλέπω → είδα, βρίσκω → βρήκα, βγαίνω → βγήκα, πηγαίνω → πήγα, πίνω → ήπια, καταπίνω → κατάπια, παίρνω → πήρα, λέω → είπα, τρώω → έφαγα, κάνω → έκανα, δίνω → έδωσα, φέρνω → έφερα, φεύγω → έφυγα, αποφεύγω → απέφυγα, μαθαίνω → έμαθα, καταλαβαίνω → κατάλαβα, ανεβαίνω → ανέβηκα, κατεβαίνω → κατέβηκα, βγάζω → έβγαλα, αναβάλλω → ανέβαλα, επαναλαμβάνω → επανέλαβα, παραλαμβάνω → παρέλαβα, προσλαμβάνω → προσέλαβα, μένω → έμεινα, στέλνω → έστειλα, παραγγέλνω → παρήγγειλα, πλένω → έπλυνα, παχαίνω → πάχυνα, έχω → είχα, θέλω → ήθελα, ξέρω → ήξερα |
| на -μαι (2) | έρχομαι → ήρθα, γίνομαι → έγινα |
| вне групп (1) | είμαι → ήμουν |

Сверка: сильные и супплетивные аористы (είδα, βρήκα, βγήκα, πήγα, ήπια, πήρα, είπα, έφαγα, έφερα, έφυγα, έμαθα, -λαβα, -βηκα, έβγαλα, -βαλα, ήρθα, έγινα) неправильны в любой грамматике; аористы с чередованием гласной основы на -να (έμεινα, έστειλα, παρήγγειλα, έπλυνα, πάχυνα) по правилу m14-1 не строятся и запоминаются — для учащегося это «неправ.»; είχα, ήθελα, ήξερα — прошедшее с нерегулярным приращением ει-/ή-, m15-1 прямо называет έχω и είμαι особыми. μπαίνω (μπήκα) из примера пользователя в курсе карточки не имеет. Правильными остались, среди прочих, ακούω (άκουσα), ζω (έζησα), περνάω (πέρασα), καλώ (κάλεσα), μπορώ (μπόρεσα), αφήνω (άφησα), καταθέτω (κατέθεσα), προτείνω (πρότεινα), σερβίρω (σέρβιρα), νομίζω, περιμένω, σημαίνω, υπάρχω.

Отвергнуто: только явное поле у 34 карточек (новый глагол с неправильным прошедшим без поля получил бы метку «правильного» молча; правило ловит его само) и полный вывод аориста из настоящего (основу аориста курс берёт из `forms`, вывести её надёжно нельзя — это то, что запоминает учащийся).

### 4. Поля `group` и `irregular` в пакете, переустановка без поля каталога

`PackageWord.group`/`irregular` и `MarkCard.group`/`irregular` — необязательные, значения проверяются при разборе (`ContentError` на незнакомое; `irregular` в пакете только `true`). Оба поля входят в `SHIPPED_FIELDS`: ревизия глаголов меняется, и `applyCards` перезапишет их у клиента, который ставит новую версию пакета. `cardDescriber` (`content/build/mark-courses.ts`) отдаёт оба поля, и `MarkCard` их несёт; `TapCard` (`src/storage/course.ts`) получает их из `pack.words` и `marks.cards`.

Совместимость: прежний клиент между выкладкой контента и обновлением приложения поставит новую версию пакета без групп, а после обновления версия совпадёт. Признак переустановки — локальный, без каталога: в поставленном греческом пакете есть слово с таблицей (`paradigm`) или карточка подсказки с формами глагола (`hasParadigm(greek, forms)` — тот же признак, что у сборки, переносится из `content/build/paradigm.ts` в `src/domain/verb-forms.ts`), у которых нет `group`. Сборка гарантирует обратное: у каждого такого места группа есть, у είμαι — `other` (решения 1–2), поэтому у пакета новой сборки признак ложен и повторной установки нет. В `applyCards` для слов — то же правило, что для таблицы: `!!card.group && !stored.group`.

Отвергнуто: счётчик `groups` в записи каталога по образцу `paradigms` — ещё одно поле у десятков из 99 греческих уроков, а каталог 38 229 из 40 000 растёт с каждым модулем английских курсов; локальный признак даёт то же без байтов каталога. Вычислять группу и признак на клиенте из `paradigm` — две реализации правил, и у карточек подсказки таблицы нет.

### 5. Метка — плашка `VerbGroupLabel` перед рядом форм

Один компонент в `src/shared/` (рядом с `VerbForms.tsx`), вставляется:

- в `WordForms` — перед рядом форм (лист слова, экран по ссылке, знакомство, раскрытие, узнавание после ответа); у `verbsOnly` метка идёт вместе с формами;
- в подсказку `WordTaps` — перед строкой форм, и при пустой строке форм (форма без греческих букв) метка остаётся;
- в `VocabularyList` — в начале строки форм под словом.

Вид по DESIGN.md: подпись интерфейса Manrope (`Label`, 600, 12.5px), цвет «карандашной подписи» `muted-foreground`, рамка 1 px `border`, скругление 6 px, высота в строку форм, без фона — справочная пометка учебника, а не статус (ни зелёного, ни янтаря). Греческое в метке (-άω, -ώ, -μαι) — `lang="el"` Literata, как требует правило «печать против интерфейса». Видимый текст `aria-hidden`, рядом `sr-only` с полной фразой: «гр.» диктор читал бы буквами. В DESIGN.md — раздел «Verb group label» в Components.

Текст: группа («гр. A», «гр. B -άω», «гр. B -ώ», «на -μαι»), при `irregular` — « · неправ.» через срединную точку, у `other` — только «неправ.»; диктор: «группа A», «группа B, тип на -άω», «группа B, тип на -ώ», «глагол на -μαι», с добавкой «, неправильный», у `other` — «неправильный глагол». Самая длинная метка «на -μαι · неправ.» (около 110 px) при нехватке места переносится своей строкой перед рядом форм (`flex-wrap`), без горизонтальной прокрутки. Метка видна всегда, и до m05-1 (решение пользователя): m02-1 уже обещает «весь этот тип мы разберём в модуле 05».

Отвергнуто: метка рядом с заглавным словом — в подсказке и списке там Literata 17–20 px и кнопка звука, на 390 px строка ломается; цветовые плашки по группам — правило Never-Color-Alone и тихий интерфейс.

### 6. Заметки карточек

`note` μιλάω — «также μιλώ», μπορώ — «μπορείς, μπορεί…; μπορώ να + глаг. — модуль 16», у ευχαριστώ заметка убирается; правка в строках лексикона `docs/course/lexicon/*.tsv` и в карточках. Заметка κοιμάμαι («спряжение на -άμαι: κοιμάσαι, κοιμάται…») остаётся: метка «на -μαι» подтип не называет.

## Risks / Trade-offs

- [Метка до m05-1: μιλάω, λέω, ζω, έχω, είμαι, μένω вводятся в m01–m04, и учащийся видит «гр. B -άω» раньше, чем узнаёт о группах] → решение пользователя «Всегда»; m02-1 уже обещает разбор типа в модуле 05.
- [«Неправ.» у глаголов с чередованием основы (μένω → έμεινα), которые часть грамматик считает правильными] → для учащегося курса правило одно — m14-1 (σ/ξ/ψ); остальное он запоминает, как велит m15-1. Список из 34 сверен вручную и закреплён тестом.
- [Новый глагол с аористом не по правилу, но правильный по смыслу] → правило даст «неправ.», отчёт печатает признак каждого глагола; исправление — `irregular: false` в карточке.
- [«гр. B -άω» на προτιμώ, записанном на -ώ] → так же говорит m05-1 (αγαπάω = αγαπώ) и заметка μιλάω; диктор читает «тип на -άω».
- [Новый глагол с непредусмотренным спряжением] → `verbGroup` возвращает `null`, сборка падает с указанием поля `group`, отчёт печатает группу каждой таблицы для сверки.
- [Пересечение с `greek-tap-forms` в `cardDescriber` и `MarkCard`] → реализация начинается от `main` после его мержа; тест «группа у `marks.cards` совпадает с группой слова» ловит потерю поля при слиянии.
- [Повторная загрузка пакетов] → у учащегося перекачиваются пакеты с глаголами (обычное обновление версии); прогресс не меняется, тест переустановки это проверяет.

## Migration Plan

Выкладка обычная: контент и приложение одной сборкой. Клиент, который успел поставить пакеты прежней версией приложения, после обновления переставит их по локальному признаку (решение 3). Откат: возврат коммита — прежний клиент поле игнорирует, пакеты без поля прежней версии ставятся как раньше.
