## 1. Цепочка предков

- [x] 1.1 Индекс `sync:ancestors` (id, часы, формат, своё, подтверждено) и тексты `sync:ancestor:<id версии>` в `meta`; ключи снимаются по префиксу при восстановлении копии (`backup.ts`); прежние сборки их не читают; адаптер возвращает текст версии вместе со снимком (M-g). Проверка: юнит-тесты; тест восстановления — конфликт `restored` без предка.
- [x] 1.2 Запись звена во всех путях в одной транзакции с изменением часов: применение версии облака (меняется только опора, свои публикации остаются — N2); применение слияния (опора — версия облака или `merge(предок, [своё подтверждённое, ...ветви облака])` — N1); публикация — `beforeWrite` получает готовый текст публикации (без второго сжатия) и пишет звено с `sync:publishing`; подтверждение, `settlePublishing`, `nothingUnpublished` (звено — прочитанная `mine`); сходимость (содержание кандидата, часы `mergeClocks`). Проверка: тест на каждый путь; инвариант «`sync:clock` = объединение часов опоры и последнего своего подтверждённого звена» после каждого.
- [x] 1.3 Неподтверждённое звено: подтверждается, если часы какой-либо ветви облака содержат его номер, — как `settlePublishing` (часы, `applied`, отметка по метке записи; M-a); иначе удаляется с `sync:publishing`. Своя компонента часов локальной ветви — `max(sync:clock[me], sync:issued)`. Проверка: тест — указатель убран уборкой с `force`, чужая ветвь его видела, слияние без удвоения статистики.
- [x] 1.4 Выбор предка: самый поздний, покрываемый всеми ветвями, с поэлементным минимумом часов ветвей = часам предка; иначе предка нет. Проверка: юнит-тесты (почти одновременная публикация, потерянный ответ, три устройства).
- [x] 1.5 Предел цепочки: опорное звено + последние три подтверждённые свои публикации, обрезка при подтверждении и смене опоры (M-e). Проверка: тест — долгая серия публикаций при застывшем чужом указателе, звеньев не больше четырёх; ветвь с отсечённым предком — окно.

## 3. Координатор

- [x] 3.1 Сходимость: сравнение кандидата с локальным снимком и звеньями цепочки; без отметки и равно локальному — принять часы и записать звено; равно звену при отметке — расширить часы звена и всех более поздних своих звеньев (M-c), отметка остаётся. Проверка: тест одновременного слияния (лишних публикаций нет, следующее расхождение сливается без окна); тест перекрёстного слияния с ответом после публикации.
- [x] 3.2 Слияние: применение с новой отметкой изменений, обычная публикация с `resolves`, `decide(depth + 1)`; снимок до слияния — одна строка «До объединения» с уникальным id. Проверка: тест «Занятия на двух устройствах офлайн» — без окна; тест сбоя между применением и публикацией и ошибки CloudStorage — ответы не теряются, новая версия облака сливается от опорного звена.
- [x] 3.3 `remote`: сливает устройство со своими неопубликованными изменениями при общем предке; чистое — не публикует, применяет результат авторов (только если все ветви покрывают его часы; иначе сливает как автор — M-h); статус чистого устройства — текст в тоне PRODUCT.md. Проверка: тест трёх устройств (наблюдатель не публикует), тест `remote` с изменениями.
- [x] 3.4 Без предка (`initial`, `restored`, ветви без общего предка, предок отсечён, первый обмен после обновления) — окно; без Web Locks — без слияния, как сейчас. Проверка: тесты на каждый случай.
- [ ] 3.5 Выбор в окне распространяется на другие устройства как удаление изменений отвергнутой ветви. Проверка: тест; описание в `docs/sync.md`.
- [ ] 3.6 Ошибка в `merge` — конфликт с отчётом, данные не меняются. Проверка: тест с подменённой функцией.
