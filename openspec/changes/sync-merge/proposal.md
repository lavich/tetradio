## Why

Окно «Прогресс разошёлся между устройствами» требует от учащегося выбрать одну версию целиком; ответы другой откладываются. После `sync-reliability` (#325) окно появляется только при настоящем расхождении — занимались на двух устройствах, и одно не успело отправить ответы, — но и тогда учащийся не может осмысленно выбрать: обычно на обоих устройствах сделано нужное. Issue #324.

## Требование пользователя

29.10.2026: «а автомерж можно сделать после правок? … то есть ответов» → «да» (заведена задача #324); «делай #324».

## What Changes

Предлагаемый объём:

- Устройство хранит **общего предка** — снимок последней версии, синхронизированной здесь (применённой или опубликованной), — в локальной таблице `syncVersions` с ролью `base`.
- При расхождении версий, происходящих от предка, координатор **сливает** их трёхсторонне (предок / здесь / облако) по правилам для каждого поля снимка и публикует результат как новую версию, покрывающую все ветви (`resolves`). Окна выбора нет.
- Правила слияния детерминированы и симметричны: результат не зависит от того, какое устройство сливает, — одновременное слияние на двух устройствах сходится без окна.
- Окно выбора остаётся для расхождений без общего предка: `initial`, `restored`, версия облака не происходит от предка, предка ещё нет (первый обмен после обновления).
- Формат облака не меняется: результат слияния — обычный снимок форматов 5/6; прежние версии приложения применяют его как обычную версию.
- Тесты: свойства слияния (идемпотентность, симметрия, сохранение ответов), два и три устройства, офлайн с обеих сторон, одновременное слияние, прежняя сборка рядом, атаки на потерю ответов.

Не входит: история ответов в облаке и точный пересчёт FSRS по объединённой истории (истории в облаке нет); слияние без общего предка.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `account-sync`: «Надёжная синхронизация» — автоматическое слияние расхождений с общим предком; окно выбора — только без предка.

## Impact

`src/sync/coordinator.ts` (решение и публикация слияния), новый `src/sync/merge.ts` (чистая функция слияния снимков), `src/sync/snapshot.ts` (сохранение предка при применении и публикации), `src/features/backup/backup.ts` (восстановление снимает предка), `docs/sync.md`, тесты `tests/sync-merge*.test.ts`. Формат облака, база IndexedDB (схема) и копия данных не меняются: предок — строка существующей таблицы `syncVersions`, которая в копию не входит.
