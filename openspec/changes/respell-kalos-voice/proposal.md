# Proposal

## Why

Голос Chirp 3 HD (el-GR) ставит ударение в «Καλώς» на первый слог (КА-лос), а верно — на второй (κα-ΛΩΣ), во всех записях. Текст карточек правильный (U+03CE, NFC); повторный синтез даёт разные записи, но ударение неверно везде. Пользовательские произношения (IPA) для el-GR не поддерживаются (API: 400 «custom pronunciations are not supported for locale el-GR»), разложенная форма и ώ с оксией (U+1F7D) голос нормализует к тому же тексту. Не помогли «Καλός ήρθατε!», дефис «Κα-λώς», «Καλως» без тонос, многоточие.

Пользователь прослушал варианты написания только для синтеза и выбрал удачный: заглавными «ΚΑΛΏΣ ΉΡΘΑΤΕ!» (фраза p329). Проверка 18.10.2026 на длинных предложениях и разных голосах (Kore, Puck, Erinome, Gacrux): с одним словом заглавными «ΚΑΛΏΣ ήρθατε στη γειτονιά!», «Καλημέρα σας και ΚΑΛΏΣ ήρθατε…» остальные слова фразы остаются обычными.

Озвучиваемых записей со словом (замер 18.10.2026 по исходникам, целое слово без учёта регистра) ровно 14, все в манифесте: реплики m08-test/dinner#1, m15-m1/excursion#1, m24-2/new-neighbour#1; фразы p012, p315, p329; предложения текстов r-m01-tilefono#5, r-m02-gnorimia#48, r-m06-diamerisma#10 и #44, r-m08-kyriaki#21, r-m12-perioxi#54, r-m13-pafos#56, r-m15-synentefxi#33. В таблицах и вариантах заданий m01-3, m08-3, m14-3 и в reading-блоке m24-m3 слово не озвучивается. Поле на каждую запись такие места и новые уроки не покрывает.

Решение пользователя 18.10.2026: ударение в «Καλώς» должно быть на втором слоге; из прослушанных кандидатов принято написание заглавными одного слова «ΚΑΛΏΣ» в общем словаре переписывания карты голосов.

## What Changes

Требование пользователя — «Καλώς» звучит с ударением на втором слоге. Предлагаемый объём:

- В `content/voices/<язык>.yaml` необязательное поле `respell`: слово → написание для облачного синтеза. Для el: `Καλώς: ΚΑΛΏΣ`.
- Замена применяется к целому слову без учёта регистра, только в тексте для облачного синтеза (скрипт озвучки и хэш записи в манифесте). Текст на экране и синтез речи устройства не меняются.
- Эти 14 записей становятся устаревшими (хэш считается по тексту для синтеза) и переозвучиваются; сначала `--check` с точным списком, затем озвучка; правка словаря, новые mp3 и манифест идут одним PR, иначе 14 записей в проде звучат синтезом устройства. Записи без слова и английский курс не трогаются.

Не входит: другие слова с неверным ударением, правки текстов уроков, смена голосов.
