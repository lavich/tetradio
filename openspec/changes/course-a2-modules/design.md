# Design

## Context

Модули 01–08 сделаны конвейером «лексикон → карточки → автор → независимый редактор → публикация»: авторы и редакторы работают параллельно в отдельных рабочих копиях git, ветки вливаются по одной с пересборкой контента. Формат — docs/course/format.md, проверки — сборщик (публикация только полного модуля, лишние поля — ошибка) и `npm run lexicon:check`.

## Decisions

1. **Тот же конвейер для 09–24.** Партии по восемь модулей: авторы параллельно, затем редакторы; каждый модуль вливается отдельно, после — картинки (`pictures:sync`), unit и e2e.
2. **Контрольные точки — уроки `kind: test`.** K1 — урок модуля 08, M1 — модуля 15, M2 — 20, M3 — 24; в модели модуля появляется необязательное поле `checkpoint` с идентификатором такого урока, полка открывает точку после своего модуля. Модель модуля и 24 номера программы не меняются.
3. **Пробник = формат экзамена.** Чтение и аудирование — задания choice/match/gap/text по структуре docs/exam-a2.md, запись звучит дважды; письмо — два текста 80–100 слов с образцом и критериями; речь — три части. Итог — по навыкам против 60 %, письмо и речь — самопроверка.
4. **Дата экзамена.** Общая дата КΕΓ с источником и датой проверки; пометка «дата на Кипре не подтверждена» вместо обратного отсчёта, пока пользователь не подтвердит местную дату.

## Risks

- Языковые ошибки моделей → независимая проверка каждого модуля, журнал правок; перед экзаменом — выборочная проверка носителем.
- Перегрузка уроков → редактор оценивает время и срезает лишнее, ориентир 60 минут.
- Отрыв от пройденного → авторы видят лексикон и уроки предыдущих модулей; незнакомые слова — только с глоссами.
