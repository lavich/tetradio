# Proposal

## Why

Основа A1 (модули 01–08) опубликована. Чтобы курс вёл к экзамену A2, нужны модули 09–24 по программе, контрольная A1 после модуля 08 и пробники в формате ΚΕΓ — иначе учащийся не видит своей готовности по четырём навыкам.

## What Changes

- Наполнить модули 09–24 (docs/curriculum.md) тем же конвейером, что 01–08: лексикон → карточки → уроки автора → независимая языковая и методическая проверка → публикация.
- Добавить контрольные точки: K1 (контрольная A1 после модуля 08), пробники M1 (после 15), M2 (после 20), M3 (после 24) в полном формате экзамена A2 (docs/exam-a2.md): 4 задания чтения, 4 аудирования, два текста письма, три части речи.
- Картинки для конкретных слов новых модулей (docs/course/pictures-map.tsv).
- Показ даты экзамена: общая дата ΚΕΓ и явная пометка, что дата на Кипре не подтверждена.
- Итоговый аудит программы: каждый результат обучения связан с уроком и проверкой, словарь посчитан по идентификаторам.

## Capabilities

### Modified Capabilities

- `course-content`: полнота курса, контрольные точки и пробники, достоверность экзаменационной информации.

## Impact

Контент в `content/`, отчёты проверки в `docs/course/review/`. Код меняется минимально: место контрольной точки в модуле и ссылка на неё с полки, строка о дате экзамена. Синхронизация прогресса — отдельное изменение `course-progress-sync`.

## Non-goals

Автоматическая оценка письма и речи, живые записи носителей для каждого диалога, изменение платформы и формата блоков.
