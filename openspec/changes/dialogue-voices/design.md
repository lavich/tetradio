# Design

## Сервис синтеза

| | Google Cloud TTS, Chirp 3 HD | Azure Neural TTS |
|---|---|---|
| Греческие голоса | 30 (14 женских, 16 мужских) | 2: Athina (ж), Nestoras (м) |
| Хватит ли на диалог из 5–6 человек | да | нет |

**Решение: Google Chirp 3 HD**, если на прослушивании греческий звучит естественно (проверка — 10 реплик разными голосами до озвучки курса). Иначе Azure: два голоса плюс сдвиг тона и темпа через SSML для третьего и далее говорящего. Цены и условия использования синтезированного звука в учебном приложении проверяются перед запуском и записываются в `docs/voices.md`; оценка — единицы долларов на весь курс.

## Файл на реплику, а не на диалог

- Подсветка текущей реплики работает без разметки по времени.
- Исправленную реплику переозвучиваем отдельно; версия файла (хэш в имени) меняется только у неё — после #66 устройство перекачивает именно её.
- Повтор отдельной реплики в будущем не требует нарезки.

Минус — больше запросов при первом проигрывании (до ~15 файлов на диалог); проигрыватель докачивает следующую реплику, пока звучит текущая.

## Голоса персонажей

`content/voices.yaml`: имя персонажа → голос (`Δέσποινα: Aoede`). В курсе 78 персонажей; голоса назначаются по полу из имени, у самых частых — вручную, остальные — детерминированно из пула нужного пола. Сборка проверяет: у каждого говорящего есть голос; в одном диалоге у разных говорящих разные голоса. Реплика без говорящего (диктор) — отдельный нейтральный голос.

## Скрипт озвучки

`node scripts/voice-dialogues.ts [урок]` — читает уроки, для реплик без файла или с изменившимся текстом (хэш текста + голос) синтезирует m4a в `content/audio/<урок>/<блок>-<n>.m4a`, записывает ссылку в урок. Ключ сервиса — из переменной окружения, в репозиторий не попадает. Файлы коммитятся в репозиторий (~13 МБ), сборка отдаёт их как медиа пакета с версией в имени.

## Воспроизведение

`playDialogue` по каждой реплике: есть файл → `ensureAsset` и `<audio>` с `playbackRate` для медленного режима; файла нет или он не скачался → системный голос (`castOf`, как сейчас). Лимит прослушиваний и открытие транскрипта не меняются.

## Уборка медиа

После установки или обновления пакетов удаляются записи `db.assets`, на которые не ссылается ни один установленный пакет. Иначе каждая переозвучка оставляет копию на устройстве.

## Спецификация

Требование «Полноценные учебные модули» меняется: звук аудирования — записи реплик с источником, синтез устройства — запасной путь.

## Открытые вопросы

- Сервис: Google Chirp 3 HD или Azure — решается прослушиванием (задача 1.1).
- Какой источник указывать у записи и разрешают ли условия сервиса такое использование — фиксируется в `docs/voices.md` до озвучки курса.
