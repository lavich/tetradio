## Goals / Non-Goals

**Goals:**

- Каждый модуль `e02`–`e08` проходится целиком, четыре навыка и контрольная, как `e01`.
- «Пробный звонок рекрутера» после `e08` собирает ступень в одну проверку с итогом по навыкам.
- Каждый модуль — законченный шаг и отдельный PR; `main` после любого PR собирается и проходит тесты.
- Устные задания ведут к банку ответов собеседования: каждый модуль добавляет один типовой вопрос из программы со своим образцом и критериями.
- Два потока (IT и путешествия) не ломают друг друга общими файлами.

**Non-Goals:**

- Ступень B2 (`e09`–`e16`, точка `e16-c2`).
- Правка сборки, формата каталога и пакетов, базы, облака, клиента (кроме предела `catalogGzip`, решение 4); текст «Сегодня» в конце курса.
- Американские и другие варианты языка у персонажа; запись живых голосов; паузы между репликами собеседника в сцене; тексты для беглого чтения.

## Decisions

### 1. Контент; проверки — тестами на настоящем контенте, в новом файле

Код сборки не меняется, поведение закрепляется тестом на настоящем контенте: новый файл `tests/english-it-content.test.ts` (хелперы `realContent`, `completeLessons`, `installLessons`, `memoryFetcher` из `tests/helpers`), вместо новых блоков в `tests/course-content.test.ts`: этот файл правит поток курса для путешествий в каждом PR (`STAGE`, `WRITING`), и общий файл дал бы конфликт в каждом PR обоих потоков. `STAGE` — список опубликованных модулей: каждый PR добавляет свой модуль в конец списка и в `WRITING`, и тест красный до контента. Правила ступени (на примере `e01` они проходят, поэтому тест сначала фиксируется на `e01` — группа 0):

- **Модуль.** `status: published`, `lessonIds` — `eNN-1`, `eNN-2`, `eNN-3`, `eNN-test`, `crib` задан, `eNN-test` — `kind: test`; модули вне `STAGE` — черновики, `content.partial` пуст.
- **Карточки.** Слова `ew…` — по 35 на модуль подряд (`ew{35·(N−1)+1}…ew{35·N}`), только в `eNN-1` (18) и `eNN-2` (17), каждое в одном уроке; фразы `ep…` — по 25 (`ep{25·(N−1)+1}…`), в `eNN-1` (8), `eNN-2` (8) и `eNN-3` (9), каждая в одном уроке; в `eNN-test` карточек нет; у слова IPA, у фразы перевод и `requested-generation`.
- **`eNN-1`**: объяснение с таблицей, `vocabulary`, не меньше четырёх заданий. **`eNN-2`**: чтение и аудирование, к каждому задание, `plays: 2` у всего аудирования.
- **`eNN-3`**: письмо — `register` и границы слов по `WRITING`, образец укладывается в границы задания, критерии не пусты; не меньше двух устных заданий, у каждого образец и критерии; среди них хотя бы одно с репликой интервьюера в «» в `prompt` (банк ответов; знак вопроса не требуется: *Walk me through your CV* — просьба). Длительность: `seconds` ≤ 60 у всех устных в `e02`–`e04`; в `e05`–`e08` не больше 120 и хотя бы одно 60–120 (программа, «Речь растёт к цели»: ответ 30–60 с → рассказ 1–2 минуты; у `e01` 90 и 45 с — до этого теста, он на `e01` проверяет только структуру). В `e05`–`e08` есть `roleplay`, перед каждой `roleplay` — аудирование без задания (решение 9).
- **`eNN-test`**: оцениваемые задания к чтению и к аудированию.
- **Говорящие** — в карте `en` и не из говорящих `english-travel` (обратная проверка к `IT_NAMES` теста путешествий; решение 6).
- **Точка.** `e08` — `checkpointId: e08-c1`; пакет `e08-c1` — `kind: test`, заголовок «Пробный звонок рекрутера» без «C1» и «CEFR» (проверка `/\b(C1|CEFR)\b/i`), не меньше 10 оцениваемых пунктов на чтение и на аудирование, не меньше пяти пар «аудирование без задания → `roleplay`», письмо `formal` 80–120 слов с образцом, `speaking` с `part: interview`, карточек нет. Тест «следующий шаг» ставит и проходит уроки `e01`–`e08` и проверяет, что следующий шаг — `e08-c1` (`nextStep`, `src/storage/course.ts:251-263`); при непройденной `e03-test` следующий шаг — она.
- **Число слов образца** считается функцией клиента `wordCount` из `src/domain/course.ts:151` (пунктуационные токены не слова), а не копией из теста путешествий.
- **Однозначность ключей** тестом не проверяется (проверяется смысл, форма не помогает); она — пункт чек-листа рецензии (решение 10): в `match`, `gap` и `text` второй верный ответ недопустим, `text` принимает естественные варианты перевода, `choice` — ровно один верный вариант.
- Карточки ступени нигде не повторяют карточки курса для путешествий: сборка отклоняет повтор текста между курсами одного языка и повтор слова или фразы внутри курса (`content/build/cards.ts:198`, `:220`, `:243`); отдельный тест не нужен, сверка по смыслу — вручную (решение 7).

### 2. Порядок и нарезка PR

Один модуль — один PR (решение пользователя 21.10.2026): `e02` → `e03` → … → `e08` → точка → документы → озвучка. Внутри модуля: тест (красный) → сверка карточек → карточки, уроки и персонажи одним шагом → `npm run content` и `npm test` → два независимых ревью (контент и язык; тесты и сборка) → полная проверка CI → PR → мерж по зелёному CI. Перед каждым PR — `git fetch && git rebase origin/main`; конфликты в `content/voices/en.yaml`, `content/build/budgets.ts` и `tests/course-content.test.ts` разрешаются объединением обеих сторон. Модуль опирается на пройденную лексику предыдущих: тексты используют карточки прошлых модулей без глосс, глоссы — для нового и для слов вне списка. Группа 0 содержит только тест-каркас и базовый замер: ни архивации, ни MODIFIED не требуется.

### 3. Устройство уроков модуля

Как у `e01`: `eNN-1` — 2–3 объяснения грамматики и лексики с таблицами и типичной ошибкой русскоговорящего, `vocabulary`, 4–6 заданий (выбор, соединение, пропуски, перевод `text`), 18 слов и 8 фраз; `eNN-2` — «как читать / слушать», чтение (тексты с глоссами) с заданием «верно / неверно» и заданием на грамматику текста, аудирование `plays: 2` на 8–12 реплик с заданием, 17 слов и 8 фраз; `eNN-3` — схема ответа и банк фраз, `vocabulary` из 9 фраз, задания на подбор, письмо с образцом, критериями и `register`, 2–3 устных задания, сквозное повторение. `eNN-test` — вступление на 10–15 минут, чтение (5–6 пунктов) и аудирование (5–6) с `graded`, грамматика, слова и перевод с `graded`. Объяснения и пояснения ошибок — по-русски, вопросы к текстам и аудио — по-английски, примеры — из IT: разработка, команда, собеседование. Тон русских текстов — по `PRODUCT.md`, «Brand Commitments»: спокойный и точный, без восклицаний, без «не X, а Y», без оценочных слов; требование входит в запрос на генерацию и в чек-лист рецензии; образец `e01` этому тону не вполне следует (в `content/lessons/e01-3.yaml` есть «не … и не …», «лучший вариант»), поэтому его тон не копируется.

### 7. Без пересечений с курсом для путешествий

- Сборка отклоняет совпадение текста карточки между курсами одного языка и повтор пары «текст + перевод» внутри курса (решение 1). Близкие по смыслу карточки сборка не ловит: сверка вручную охватывает карточки `e01`, `t01`–`t14` (с планом) и модули ступени между собой.
- Места пересечения тем: переспрос (`e05`) — у курса для путешествий в `t09` только разговорные (*Sorry, what?*, *You lost me*), у IT — деловые (*Could you elaborate on that?*, *Do you mean…*); мнение и несогласие (`e15`) — вне этого изменения; планы (`e07` — *will*, *going to*) — у путешествий в `t11` только приглашения (*Are you up for it?*, *I'll swing by*), у IT — карьера и мотивация; модальные (`e08`) — у путешествий *would rather* в `t10`/`t13` без карточки-рамки, у IT — вежливые просьбы и условия найма; профессия и роли (`e01`) — в small talk `t08` у путешествий без карточек; опыт (`e02`) — у путешествий *Have you ever been to…?* и *Neither have I*, у IT — карьера и сроки; *a thread, buffer, a glitch, patchy, a screenshot* — слова курса путешествий (`t14`), в IT-карточки не входят (в текстах — с глоссой).
- Близкие пары по функции, решённые при сверке: переспрос у IT — деловые *Could you clarify the question?*, *Could you put that another way?* (разговорные *Sorry, what?*, *You lost me*, *Sorry, you were saying?* — у `t09`); связь и видеозвонок — у `t14` (*You're breaking up*, *patchy*, *a glitch*), у IT только *a screen share*, *Could you share the question on screen?*; назначение встречи у IT — *Could we schedule a call for early next week?* (у `t11` *How about Friday?*); срок ответа — *I'd like some time to review the details.* (у `t11` *I'll let you know by Thursday.*); интерес — *I'd like to understand the team's roadmap.* (у `t12` *I'd love to hear about it.*).
- Внутри IT-курса по одной карточке на смысл: *a notice period* и *I can negotiate an earlier start…*, одна фраза про «больше ответственности» на `e02` и `e07`, фразы `e05` про уточнение разведены по функциям (переспросить, уточнить, выиграть время, показать экран).
- Совпавшее слово или фраза остаётся за курсом, где оно уже есть, здесь — текст с глоссой.

## Risks / Trade-offs

- [Объём: 29 уроков и 420 карточек сгенерированы моделью, без носителя] → ревью после каждого модуля; программа просит пробное собеседование с носителем перед реальным (`docs/curriculum-english-it.md`, «Что не входит»); план этого не заменяет.
- [Два потока правят `content/voices/en.yaml`, `content/build/budgets.ts`, `tests/course-content.test.ts`] → IT-тест в отдельном файле, предел каталога поднимается один раз с общим запасом, имена IT-персонажей зарезервированы, конфликты — объединением; перед каждым PR `git fetch && git rebase origin/main`.
- [Имя IT-персонажа совпадает с именем из `t09`+ и роняет тест путешествий] → резерв имён (решение 6) и обратная проверка в IT-тесте; сверка списка после `rebase` перед каждым PR.
- [Повтор голоса у разных персонажей: учащийся может принять Nadia за Bridget курса для путешествий] → разные курсы и диалоги; другие варианты — отдельное изменение (больше голосов или `en-GB`/`en-US`).
- [Каталог выходит за 25 000] → решение 4: явный подъём предела до 32 000 с записью замера.
- [Аудио перед сценой звучит целиком, без пауз на ответ] → как у путешествий: `prompt` объясняет порядок, текст реплик открыт после двух прослушиваний.
