# Design

## Контекст

- Урок — блоки: объяснение (`body`, разметка `**…**`), чтение (`text` + `glosses` автора), аудирование (транскрипт открывается после ответа), упражнения (`prompt`, `options`, `answer`), письмо и речь (`prompt`, `model`).
- Карточка слова: `greek` (с артиклем у существительных), `russian`, `ipa`, `forms` — строка вида «мн. τα ψωμιά» или «аор. έμεινα; буд. θα μείνω»; у прилагательных — три рода.
- Озвучка — синтез речи устройства (`speakPhrase`), записей нет.
- В чтении уже есть глоссы: точечное подчёркивание, нажатие показывает перевод строкой рядом.

## Исследование: как найти слово в тексте

Греческий изменяет слова: в тексте «φίλο», «φίλοι», «μένουμε», а в карточке «ο φίλος», «μένω».

| Вариант | Как | Плюсы | Минусы |
|---|---|---|---|
| A. Точное написание и формы из карточки | лемма без артикля + каждая форма из `forms`; сравнение без учёта регистра, с NFC и конечной ς | просто, без ложных совпадений | пропустит падежи и лица, которых нет в `forms` (φίλο, μένουμε) |
| B. A + окончания по части речи | для сущ./прил./глаголов генерировать частые окончания по шаблону (-ος/-ο/-οι/-ου…, -ω/-εις/-ει/-ουμε/-ετε/-ουν) | ловит большинство форм A2 | возможны ложные совпадения (разные слова с одной основой); нужна проверка ударения |
| C. Явная разметка автора | в YAML урока слова помечаются, например `[[φίλο|w034]]` | точно, нет ложных совпадений | большая ручная работа по 99 урокам; агент-автор может разметить при генерации |
| D. B при сборке + отчёт | сборщик ищет вхождения по B, пишет найденное в пакет и печатает спорные места; автор правит исключения | точность близка к C, без ручной разметки | сложнее сборщик |

Замер на курсе (01.10.2026, 60 уроков со словами, 921 слово урока): 884 слова (96 %) хотя бы раз встречаются в тексте своего урока в точном написании или в форме из `forms` (вариант A); ещё 11 — по частым окончаниям (B); 26 в тексте урока не встречаются. Замер считает слово, а не каждое вхождение: формы вроде «φίλο», «μένουμε» внутри текстов A пропускает, их добирает B.

Рекомендация: **D** — поиск при сборке контента (не в браузере), результат в пакете урока (`highlights`: блок, поле, смещение, id карточки). Браузеру не нужно разбирать морфологию, а спорные места видны при сборке.

## Исследование: где выделять и как не выдать ответ

| Где | Выделять | Подсказка |
|---|---|---|
| Объяснение | да | звук + перевод |
| Чтение | да (глоссы автора важнее) | звук + перевод |
| Транскрипт аудирования | только после ответа (текст закрыт до ответа) | звук + перевод |
| Условие задания (`prompt`) | да | **до проверки — только звук**, перевод после проверки (иначе «Что значит το ψωμί?» решается подсказкой) |
| Варианты ответа | нет (выбор варианта уже произносит предложение) | — |
| Образцы письма и речи | да | звук + перевод |

Открытый вопрос 1: правило для заданий — «до проверки только звук» (рекомендация) или «перевод всегда»?

## Исследование: какие слова выделять

- **Только слова этого урока** (`items`) — меньше шума, видно, что учить сейчас.
- **Слова урока + все слова пройденных уроков** — помогает повторять, но страница пестрит.
- **Все слова курса, встреченные в тексте**.

Открытый вопрос 2: какой набор (рекомендация — слова урока; прошлые — без выделения, но по нажатию тоже звучат? см. вопрос 3).

## Взаимодействие и вид

- Выделение: точечное подчёркивание 1.5 px цветом чернил (`--primary`) с отступом 3 px — как глоссы чтения, чтобы был один знак «нажимается».
- Нажатие: звук сразу, подсказка-облачко над словом (на телефоне — над словом, не перекрывая строку; на компьютере — также по наведению с задержкой?). Внутри: слово с артиклем (Literata), транскрипция, перевод, «ещё раз». Закрывается нажатием вне, Esc, прокруткой.
- Доступность: слово — кнопка с подписью «Произнести и перевести: …», фокус с клавиатуры, Enter открывает.
- Звук без греческого голоса: подсказка с переводом и строкой «нет греческого голоса».

Открытый вопрос 3: нужна ли подсказка по наведению на компьютере, или только нажатие?

## Риски

- Ложные совпадения в варианте B/D (омографы, служебные слова) — отчёт сборщика и список исключений.
- Перегруженный текст объяснений — выделять только первое вхождение слова в блоке?
- Размер пакетов растёт на `highlights` — оценить на всём курсе.
