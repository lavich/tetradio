# Proposal

## Why

Учащемуся трудно запоминать формы глагола (пример — μένω: μένω, έμενα, έμεινα, θα μείνω). Формы в карточке уже есть у всех 162 глаголов греческого курса, но показываются сырой строкой мелким курсивом: «аор. έμεινα; буд. θα μείνω». Из неё не видно ни того, что у глагола две основы, ни того, что окончания общие для всех глаголов, а полного спряжения по лицам нет нигде.

Решение пользователя (12.10.2026), из трёх вариантов показа («ряд форм», «ряд + смена основы», «ряд + таблица по лицам») — **ряд + таблица по лицам**: основные формы глагола рядом «μένω → έμεινα → θα μείνω» с понятными подписями и выделенными окончаниями — в словаре, в списке слов урока и в подсказке по нажатию; в словаре — ещё раскрывающаяся таблица «я / ты / он… — сейчас / было».

Дополнение пользователя (12.10.2026): каждую форму в ряду и в таблице можно нажать и услышать; голос — **синтез устройства** (не записи).

## What Changes

- **Ряд основных форм** вместо строки форм у глагола: заглавная форма и формы из карточки по порядку, подписи простыми словами вместо сокращений (аор. → «было», буд. → «будет», повел. → «делай»), окончание каждой греческой формы выделено цветом. Три места: лист слова в словаре, список слов урока, подсказка слова по нажатию. У английского глагола — тот же ряд (drive → drove → driven) без выделения окончаний. Формы не-глаголов (мн. ч., роды прилагательного) остаются строкой.
- **Таблица спряжения** на листе греческого глагола, свёрнутая по умолчанию («Все формы»): шесть лиц, столбцы «сейчас» (настоящее) и «было» (аорист или, если у глагола нет аориста в карточке, прошедшее из карточки); окончания выделены.
- **Озвучка по нажатию**: форма в ряду на листе слова и в подсказке, форма в таблице — кнопка, которая произносит её синтезом устройства; без голоса — подсказка «нет голоса». В списке слов урока строка и так произносит слово, формы там не кнопки.
- **Таблица строится при сборке курса** правилами из заглавной формы и форм карточки; для неправильных глаголов и спорных случаев таблица задаётся в карточке явно. Глагол, для которого не получилась ни правилами, ни явно, не проходит сборку.

Не входит (следующие шаги из того же обсуждения): упражнение «вставь форму», интервальное повторение по формам, записи форм голосом курса, будущее и повелительное по лицам.

## Capabilities

### Modified Capabilities

- `course-content`: у греческого глагола в карточке пакета — таблица спряжения (настоящее и прошедшее по лицам).
- `app-sections`: ряд основных форм глагола в словаре, списке слов урока и подсказке; таблица спряжения на листе слова.
